# 测试指引

本文件补充[根指引](../../../AGENTS.md)，适用于本目录的 Java 测试与辅助类。命令及运行范围使用[测试指南](../../../docs/guides/testing.md)，不另建一份任务清单。

## 什么值得测试

- 以可观察行为、跨模块合同、数学不变量、资源所有权、失败恢复、兼容性或真实缺陷组织测试；不按生产类逐一配同名测试，也不以覆盖率数字作为新增用例的充分理由。
- 先扩展已有领域测试/参数化用例。简单默认值、getter/setter、无分支委托不单独建测试，除非承载公开合同或已发生的回归。
- 一组新增用例在变更说明或已有合同条目中说明：防哪种回归、现有更便宜覆盖为何不足、失败如何定位。不要求每个测试方法额外写文档或长注释。
- 期望值来自独立解析、参考实现、固定已解释样本或不变量。不要调用同一生产 helper 同时计算实际值和唯一期望值。
- 断言结果与必要边界；避免固定私有字段名、无关 helper 顺序和大段源码字符串。检查公开 API、包依赖和受控 GL 入口的架构合同仍然有效。

## 分层与隔离

- JVM 用例不创建 GLFW window、GL capabilities、shader、texture 或 framebuffer；能在纯逻辑层证明的合同优先留在此层。
- 真实 GL 用例使用 `@EnabledIfSystemProperty(named = "haikalat.glSmoke", matches = "true")`，默认不执行；需要读回时核对所选任务实际开启读回，并对像素/数值断言。创建窗口或成功编译 shader 不能替代效果正确性。
- GL 用例可位于 integration 包或为包内访问与生产类型同包。保持默认单 fork/串行与 GPU owner/context 约束；普通 JVM 用例不因此全局串行化。
- 使用明确随机种子、有界 fixture 和事件驱动等待；不使用任意 sleep 掩盖竞态。等待需有期限，超时输出实际状态和预期事件。
- 在 `finally`/既有 fixture 清理中恢复系统属性、静态状态、回调及 context，释放自己拥有的资源；不释放借用资源，不影响后续 case。
- shader/include、共享表面或公共资源协议变更需覆盖直接消费者；场景/视觉只用于需要场景上下文的合同。长测与性能不自动加入日常路径。

## 合并和删除

- 先按用例组标明 `KEEP` / `MERGE` / `RETIRE` / `REWRITE` 与理由，再逐组调整；记录放现有计划或变更说明，不新增重复的全仓测试数据库。
- 合并保留不同故障模式、独立参考和真实消费者；删除仅针对合同已退役、重复覆盖或无独立断言价值的用例，并核对剩余合同/替代覆盖。
- 数学公式、NaN/Inf 与边界拒绝、防御性拷贝、候选发布/失败、resize、历史失效、关闭和宿主借用的必要覆盖不能被简单 smoke 替代。
- 不为减少文件数设置删除配额，不因测试慢、失败或难修直接禁用/删除；先定位产品、测试还是环境问题。
- 用例迁移后检查相关 Gradle filter、focused 必需 case、报告核对和文档引用。替代覆盖实际执行后再宣称精简完成；合同被删除则记录其退役依据。

## 失败与交付

- 提供 case ID、候选/配置、必要的期望与实际数值、JUnit XML 和日志；GL 失败补充可用的设备/驱动、尺寸、帧与 pass 身份。诊断只收集定位所需数据。
- 重试遵循根指引：未经修复的正确性失败保持失败；已确认的可恢复环境故障最多定向复跑一次，同故障不继续循环。
- 过滤为空、必需 GL 被守卫跳过、未运行、环境无效和超时不能计为通过。框架正常排除的其他层测试与本次必需用例的意外 skip 分开解释。
- 修复后运行受影响合同及直接消费者，记录覆盖保持情况；不因局部失败自动追加完整发布或性能矩阵。
