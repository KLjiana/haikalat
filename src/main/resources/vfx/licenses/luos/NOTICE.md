# Luos texture provenance

- Author: Luos
- Source pages: https://www.patreon.com/luos and the author's public VFX texture giveaway pages
- Acquired for project review: 2026-07-26
- Packs retained here: `Luos_FreeGiveAway` and `Luos_Noise_V2`

The author's accompanying terms allow use in commercial and non-commercial
projects and do not require attribution. The images must not be sold as assets,
sold after editing, or redistributed on their own.

Project boundary: use these textures only as part of an implemented visual
effect; do not expose the original packs as downloads or package this repository
as an asset distribution. Keep pixel data unchanged where practical and perform
color, UV, blending and distortion work in shaders.
