## 1. 技术与承诺

- 交付一个**动态** DDGI 探针网格：规则轴对齐探针、每探针六面深度栅格化、逐 texel 世界空间射线、辐照度图集、时域混合、每帧更新预算、带边界与可见性钳制的间接光查询。
- **不是静态烘焙**：每次探针更新都重新栅格化当前 `SceneFrame` 的 opaque/MASKED 几何深度，再用该深度做射线命中；移动物体会进入探针深度并改变辐照度。GL 用例 `staticBakeControlStaysFrozenUntilTheNextUpdate` 明确对照“不更新则逐位冻结，更新才变化”。
- **不使用硬件光追**：OpenGL 4.6 在此代码库没有光追 API；后端 `Framebuffer` 也没有 cubemap render target。因此射线机制是“探针为中心的六面深度栅格化 + 世界空间深度图射线步进”，不是 RTX/`rayQuery`，也不是屏幕空间命中。
- 适用范围：有限探针网格（单轴 1–8，总数 ≤ 64）、单主方向光、场景级 albedo 代理、常量天空项、上一帧探针图集一次弹射、当前相机可见场景的 opaque/MASKED 几何。
- 明确不支持：instanced renderer（不进探针深度，可能漏遮挡）、PBR 材质/自发光/阴影贴图/clustered 灯表消费、逐像素材质 albedo、MSAA 探针深度、探针体积自发光、屏幕外真实辐亮度捕获、完整多次弹射收敛、动态探针重排/层级 LOD、正式性能结论。

## 2. 射线机制（已实现，待真实 GL 验证）

### 2.1 机制

1. 探针 `p` 的六个 90° 面（+X/−X/+Y/−Y/+Z/−Z）用与 shadow caster 相同的 depth-only 顶点程序栅格化到**一张 2D 深度图集**：宽度 `probeCount * 6 * R`、高度 `R`，探针 `p` 面 `f` 位于像素列 `[p*6*R + f*R, p*6*R + (f+1)*R)`。每面使用同一探针位置、`perspective(90°, 1, near, far)` 与对应 face look-at；绘制前只清除该探针的列区间（scissor + clear），未调度探针的深度保持不变。
2. 重光照阶段每个辐照度 texel 发一条世界空间射线：方向由六面 tile 的 face + UV 得到，步进 `raySteps` 次；每步通过当前探针深度图集取最近表面距离，`recorded < t` 即命中，命中位置取 `clamp(recorded, near, maxRayDistance)`。
3. 命中处的法线由探针深度图集相邻 texel 重建（`cross(pRight - hit, pUp - hit)`，朝向探针翻转；退化时回退 `-rayDirection`）。
4. 命中辐亮度 = 解析主方向光 `albedo/π * max(dot(n, -L), 0) * lightRadiance` + 上一帧探针图集在该命中点方向的一次弹射 `albedo * probeRadiance(hit, -ray)`；未命中为 `skyRadiance`。
5. 结果按 `mix(raw, previousSameTexel, hysteresis)` 混合并 clamp 到 `[0, maximumIrradiance]`，写入双缓冲辐照度图集的写目标，帧末交换。
6. 查询（`DdgiIndirectPass`）对可见表面做 8 探针三线性权重 + 法线侧权重 + 探针深度可见性门 + 网格边界淡出，采样辐照度图集，乘场景级 albedo 与 intensity 后加性写回。

### 2.2 可行性依据与限制

- 可行性来自现有后端能力：`Framebuffer` 的 depth texture、任意 viewport/scissor 子矩形、`texelFetch(sampler2D)`、RGBA16F color target、`glBlitFramebuffer`；不新增 backend 类型，不假设 cubemap FBO。
- 限制 1：`depthFar = maximumRayDistance + spacing`，因此探针只能看到该距离内的表面；更远的方向按天空处理（有界，不无限泄漏）。
- 限制 2：每 texel 单射线、命中法线来自深度差分，薄物体、掠射角、深度不连续处法线与命中可能有误差。
- 限制 3：只消费一个主方向光与场景级 albedo，不读取材质/自发光/shadow map，因此“间接光颜色”是受限估计而非完整光照传输。
- 限制 4：探针深度栅格化使用本 pass 自己的 depth-only 程序与 `SceneDeformationDefaults`；不绘制 instanced renderer，和 shadow caster 集合不完全一致。
- 限制 5：深度清除依赖 GL 默认 clear depth `1.0`（本仓库生产代码不修改 `glClearDepth`；测试 fixture 显式设为 1.0）。
- 限制 6：`IRRADIANCE_FACE_RESOLUTION` 固定为 4（每探针 6×4×4=96 texel），质量档通过 `depthFaceResolution`、`raySteps`、`updateBudget`、`hysteresis` 调整；不承诺视觉质量等级。

## 3. 输入 / 输出

| 项目 | 内容 |
|---|---|
| 配置 | `DdgiSettings`（GL-free record）：`enabled`、`intensity`、`surfaceAlbedo`、`skyRadiance`、网格原点/`spacingMetres`、`probesX/Y/Z`、`updateBudget`、`hysteresis`、`maximumRayDistance`、`raySteps`、`depthFaceResolution`、`borderFadeMetres`、`maximumIrradiance`。`disabled()` 为精确 no-op。 |
| 每帧更新输入 | `CommandBuffer`、只读 `SceneFrame`（复用 shadow caster 的 opaque/MASKED renderer 与 `SceneDrawBinding`）、主光传播方向（世界空间、归一化）、主光辐亮度（有限、非负、≤ 100）。 |
| 探针输出 | 探针深度图集（`GL_DEPTH_COMPONENT24`，`Texture2D` 深度附件），辐照度图集（RGBA16F，`rgb` = 入射辐亮度，`a` = 1），双缓冲；探针中心 `origin + (index + 0.5) * spacing`。 |
| 查询输出 | `DdgiIndirectPass` 自有全尺寸单采样 RGBA16F 目标；先 blit 调用方场景颜色，再加性叠加 `probeRadiance * surfaceAlbedo * intensity`。 |
| 坐标/单位 | 世界空间米。深度图集存 NDC 深度，shader 内部线性化。共享世界法线使用有符号的八面体坐标 `[-1, 1]`（`SceneBufferChannel.NORMAL`）。没有 velocity/jitter 语义。 |
| 分辨率 | 探针深度面 `R` 可配 4–32；辐照度面固定 4；间接消费者与场景颜色同尺寸（≤ 16384），要求单采样深度。 |

## 5. 生命周期与事务

| 项目 | 内容 |
|---|---|
| GPU owner | `DdgiProbeVolume` 拥有深度图集 FBO、两张辐照度图集 FBO、3 个 shader program、1 个 screen mesh、`SceneDeformationDefaults`；`DdgiIndirectPass` 拥有 1 个 shader、1 个 screen mesh、1 个颜色目标。 |
| 创建 | 构造函数先完整准备所有候选资源；任一失败按逆序 close 已创建候选并抛出，不发布半成品。disabled settings 在分配前抛 `IllegalArgumentException`（精确 no-op，GL 用例核对 live resource 数不变）。 |
| resize | `DdgiIndirectPass.resize` 先完整分配候选 target，再发布并 close 旧 target；分配失败/非法 extent 保留旧 target。`DdgiProbeVolume` 的探针图集尺寸由 settings 冻结，改网格需新建 owner。 |
| 关闭 | 两者 `close()` 幂等、聚合关闭失败、置零纹理/目标访问；`DdgiIndirectPass` 不关闭借用的 volume。 |
| 发布前失败 | 候选构造失败不会替换旧 pass；调用方保留旧代。 |
| 历史 | 双缓冲辐照度图集只在成功 update 后交换；未调度探针保持上次图集与深度。禁用/关闭不保留探针资源。 |

### 6.3 真实 GL 用例（已编写，NOT_EVALUATED）

`DdgiProbePassGlTest`（`@EnabledIfSystemProperty(named = "haikalat.glSmoke", matches = "true")`）：

1. `movingObjectChangesProbeDepthAndIrradiance`：真实几何栅格化；移动 box 后探针 -Y 深度变近且辐照度变化。
2. `staticBakeControlStaysFrozenUntilTheNextUpdate`：不 update 的读回逐位不变；同一场景变化经 update 才变化。
3. `updateBudgetRefreshesOnlyScheduledProbes`：budget=1 时只写调度探针 tile，未调度 tile 精确 0；下一帧轮转。
4. `indirectPassQueriesInsideBoundsAndRejectsOutside`：边界内像素与独立参考一致；网格外像素精确保持背景。
5. `indirectPassRejectsProbeOccludedReceivers`：探针深度记录的遮挡板后接收者为 0，未遮挡接收者仍有间接光。
6. `hysteresisMatchesTheIndependentTemporalBlend`：两个 volume（h=0.5 与 h=0）逐 texel 对照 `0.5*previous + 0.5*raw`。
7. `disabledSettingsAllocateNothingAndCloseIsIdempotent`：disabled 无资源；resize 事务性；close 幂等且释放全部 live resources。

执行命令（待 GPU 队列）：

```powershell
.\gradlew.bat glSmoke --tests "*DdgiProbePassGlTest"
```

首次 GPU 队列（提交 `b4d37d0`）实际结果：7 个用例中 6 PASS、1 FAIL；`hysteresisMatchesTheIndependentTemporalBlend` 报 `expected 0.039978027 but was 0.019989014`（恰好一半），其余 6 个用例 PASS 且无 GL error。

诊断：这是**测试 oracle 缺陷，不是 shader 双重混合**。relight 的命中辐亮度包含“上一帧探针图集的一次弹射”；blended volume 的首帧因 `h=0.5` 对零历史混合，其历史是 `0.5*raw1`，而 raw volume 的历史是 `raw1`。第二帧两者的 raw incident 因弹射项不同而不再相同，所以 `0.5*first + 0.5*rawSecond` 不是合法期望；实际值的一半正来自半强度历史产生的半强度弹射。修复保留独立公式断言，改为**把命中点放到探针网格外**（地面 y=1.0，网格 y∈[1.5,3.5]），border clamp 使 relight 弹射项精确为 0，于是两 volume 第二帧的 raw 只含与历史无关的 direct/sky，公式逐 texel 成立；另加 `changed >= 4`，要求 fixture 中存在 raw 显著变化的 texel，防止“两边都不变”式假通过。修复提交与重跑状态见交付说明；当前仍为 `NOT_EVALUATED`，不能据此声称 GL PASS。

### 6.4 结构审查失败恢复回归（2026-11-13）

  探针的 `+Z`/`-Z`/`-Y` 面深度均为 1.0（“无表面”值）而不是 0.25，被调度探针面向立方体的

- 剩余限制：只验证单探针预算、无方向光之外的材质/阴影；未覆盖提交中途部分执行、连续多次

## 7. 预算与内存

- 探针深度图集：`probeCount * 6 * R * R * 4 B`。默认 18 探针 / R=16 ≈ 108 KiB；上限 64 探针 / R=32 = 1.5 MiB。
- 辐照度图集：每探针 12×8 RGBA16F = 768 B，双缓冲 1.5 KiB/探针；默认 18 探针 ≈ 27 KiB，上限 64 探针 ≈ 96 KiB。
- 每帧 GPU 更新：`B` 个探针 ×（6 次场景深度栅格化 + 96 texel × `raySteps` 次深度采样 + 96 次图集写）。默认 `B=2`、`raySteps=24`：约 12 次探针面栅格化、4608 次深度采样/帧（不含场景 draw 数）；上限 `B=8`、`raySteps=64` 时同式线性增长。
- CPU 每帧：预算档期 O(B)，uniform 上传为常数；无同步 GPU 读回、无 `glFinish`。
- 正式性能、显存峰值、draw/材质切换未测（`NOT_EVALUATED`）；无预算或帧率承诺。质量档建议：Low `budget=1, R=8, rays=12`；Medium 默认；High `budget=4, R=16, rays=32`，均需在真实场景重测后确认。

## 10. 回退与降级

- 关闭：不构造 `DdgiProbeVolume`，不产生任何图集/shader/mesh/draw；`DdgiSettings.disabled()` 精确无副作用。
- 质量降级：减小 `probesX/Y/Z`、`updateBudget`、`depthFaceResolution`、`raySteps`、`maximumRayDistance`；减小 `intensity`/`maximumIrradiance`；扩大 `borderFadeMetres` 收紧边界外影响。
- 预算不足：降低 `updateBudget` 只延长完整重访周期（`ceil(probeCount/budget)` 帧），不改变单探针算法。
- 失败：候选构造/resize 失败保留旧资源；关闭聚合失败但保持幂等标记。
- 互斥：与 #45 VCT 默认互斥选用；本实现不借用 VCT 资源，不与 #39 SSGI 自动去重（两者同时开启会重复间接光，需 Integrator 做依赖/质量选择）。

## 11. 生产接线（Integrator，`codex/render-wiring-b3`）

生产入口（默认 `DdgiSettings.disabled()`，禁用时不创建 probe volume、indirect pass、atlas、program 或 draw，拓扑 key 与基线逐字节一致）：

| 名称 | 语义 |
|---|---|
| `RenderPipeline.ddgi(settings)` | build 前配置；已有代次时抛 `IllegalStateException`。 |
| `RenderPipeline.ddgi()` | 当前请求值；不暴露 GPU 句柄。 |
| `RenderPipeline.applyDdgi(settings)` | 帧边界事务：设置相等直接返回；否则重建完整候选代（volume/indirect pass 均烘焙设置），失败保留旧代与旧设置。 |
| `RenderFeatureSettings.ddgi(...)` / `ddgi()` | builder、`defaults()`、`toBuilder()` 与统一批量入口。 |
| `RenderFeature.DDGI` | `RenderFeaturesControl.activities()` 的 `ACTIVE`/`DISABLED`/`PAUSED_BY_MASTER`/`NO_ELIGIBLE_LIGHT`/`UNAVAILABLE`。 |
| `PipelineTopology.ddgi` | 仅当 settings active、HDR、非 MSAA/TAA 且场景存在方向光时进入拓扑 key；否则请求保持不可用且不改变图。 |

图顺序与合同：

```text
GeometryPass (opaque/MASKED forward)
  -> DdgiProbePass        (recordUpdate: 预算档期、探针深度/辐照度图集)
  -> DdgiIndirectPass     (blit 当前 HDR scene colour + ONE/ONE 间接光; 读单采样 depth + NORMAL)
  -> post-process HDR chain / TAA
```

- 主光取自场景第一盏方向光；传播方向与 `color*intensity` 辐亮度直接传入 `recordUpdate`，超过
  `DdgiSettings.MAXIMUM_LIGHT_RADIANCE_COMPONENT` 时帧前失败而不是静默夹取。
- 共享 surface 为 DDGI 请求单采样 `DEPTH` + `NORMAL`；两个 pass 都不写共享深度，间接 pass 只拥有
  一个 pass 私有目标并通过图节点 blit 回 HDR 颜色链（一次全屏颜色桥接，和体积粒子桥一致）。
- `RenderFeaturePolicy` 对 MSAA/TAA 做软 `UNAVAILABLE`，对无方向光做 `NO_ELIGIBLE_LIGHT`；对
  `ddgi.active() && vct.active()` 与 `ddgi.active() && postProcess.ssgi().active()` 硬拒绝。
- `PipelineFeaturePolicy` 在装配期再次拒绝非单采样/缺 depth/normal/DDGI+VCT 的外来拓扑。
- resize 在候选代装配期创建新的 indirect target；probe atlas 由设置冻结，不随窗口 resize。旧代退役失败
  保留新代并报告退役失败，不伪报回滚。
