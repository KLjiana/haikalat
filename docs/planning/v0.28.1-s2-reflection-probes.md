# 0.28.1 S2 #18 技术卡：Local Reflection Probes（静态预计算局部反射探针）

日期：2026-11-12。状态：首版生产实现完成；定向 JVM 合同已执行通过；Orchestrator 串行 GPU 已执行现有 acceptance/lifecycle 两个 case，2/2 PASS；复审后新增 nonzero environment rotation GL 回归与 mixed active/disabled 回归，等待串行重跑。对应 46 项路线图 #18，执行计划见 [multi-agent full delivery](haikalat-multi-agent-full-delivery.md) 与 [realtime rendering roadmap](realtime-rendering-roadmap.md)。

## 适用范围

- 支持：有限数量（最多 2 个）静态反射探针；每个探针从 HDR 文件经 `PbrEnvironmentLoader` 预计算（与全局 IBL 相同的 equirect → cube、irradiance、prefilter、BRDF LUT 路径）；box 或 sphere 影响区 + `blendDistance`；每探针强度、环境旋转、质量档；GL-free 选择/权重/重叠归一化；PBR forward 的 specular IBL 局部校正与权重混合；无探针时精确回退全局 `PbrEnvironment`。
- 不支持：每帧实时 cube 捕获/重烘焙；超过 2 个同时影响同一 receiver 的探针；逐像素/逐对象自动探针集合（当前按调用方提供的代表世界点选择）；局部漫反射 irradiance、局部 BRDF LUT、clearcoat 层的局部探针；探针遮挡（box capture / depth hull）、box 内视差真实几何；SSR/平面反射与探针的自动仲裁；探针流式加载或 resize 重建（探针是启动期静态资源，不依赖 framebuffer 尺寸）。
- 本 Worker 不修改 `RenderPipeline`、`RenderFeaturesControl`、feature policy 或构建/筛选文件；接线点见文末。

## 真实消费者与调用方式

| 项目 | 内容 |
|---|---|
| 数值描述 | `ReflectionProbeSettings`（GL-free record）：`name`、`enabled`、`position`、`shape`（BOX/SPHERE）、`halfExtents`、`radius`、`blendDistance`、`quality`、`intensity`、`rotationRadians`、`hdrResource`。工厂 `box(...)`/`sphere(...)`；`disabledCopy()` 保留描述但不占 GPU。 |
| 资源 owner | `ReflectionProbe`（包内）：拥有一个 `PbrEnvironment`，只向消费者暴露 prefiltered specular cubemap 与最大 mip。 |
| 集合 owner | `ReflectionProbeSet`：构造期校验（数量、重名、空值）、事务式加载（任一探针失败关闭已创建探针与共享 sampler 后原样抛出）、`close()` 逆序释放、幂等；共享一个 mipmapped cube sampler。 |
| 选择 | `ReflectionProbeSelector`（GL-free）：按世界点计算每个活跃探针的连续权重，排序、截断到 2、归一化并返回剩余全局权重；`localCorrectionDirection(...)` 提供与 shader 一致的 box/sphere 投影方向。 |
| 材质绑定 | `PbrMaterials.bindReflectionProbes(MaterialInstance, ReflectionProbeSet, Vector3fc)`：选探针、上传固定 `uReflectionProbe*` uniform、把 prefiltered cubemap 绑定到冻结的 unit 22/23。`MaterialInstance.textureCube(...)` 是新增的 cube override 入口。 |
| 真实 shader | `src/main/resources/shaders/render3d/pbr/pbr-forward.frag` 同时被普通 forward、透明/体积雾变体和 benchmark 参考材质使用；`uReflectionProbeCount` 为 0 时执行原有全局 IBL 采样。 |
| 应用侧示例 | 每 draw 前：`PbrMaterials.bindReflectionProbes(instance, probes, receiverWorldPoint);`；无探针/影响区外传空选择即可自动回退。 |

```java
ReflectionProbeSet probes = ReflectionProbeSet.load(device, MyApp.class, List.of(
        ReflectionProbeSettings.box("lobby", new Vector3f(0, 1.5f, 0),

                1.0f, 0.0f, "/environments/lobby.hdr"),

```

## 选择与权重合同

对每个活跃探针（`enabled && intensity > 0`）先求有符号距离 `d`：

```text
box:    q = abs(p - centre) - halfExtents
        d = length(max(q, 0)) + min(max(q.x, max(q.y, q.z)), 0)
sphere: d = length(p - centre) - radius
```

`d < 0` 在影响区内，`d == 0` 在影响区边界，`d > 0` 在 blend 壳层：

```text
inside:  inset = clamp(-d / coreDepth, 0, 1)     // coreDepth = min(halfExtents) 或 radius
         w     = 0.5 + 0.5 * smoothstep(inset)
outside: t     = clamp(d / blendDistance, 0, 1)
         w     = 0.5 * (1 - smoothstep(t))       // blendDistance == 0 时 w = 0
```

- 中心 `w = 1`，影响区边界 `w = 0.5`，blend 末端 `w = 0`。两侧在边界处都取 0.5，因此跨边界、跨两个重叠探针的手递都是连续的；这是有意不采用“区内恒为 1”的简化，否则重叠区进入瞬间会从 100% 跳到 50/50。
- 选择器按 `weight` 降序、中心距离升序、描述顺序升序排序；取前 2 个。若权重和 `S > 1`，探针权重归一化为 `w/S`、全局权重 0；否则探针保持原权重、全局权重 `1 - S`。
- 无活跃候选（全部在影响区+blend 外、禁用或强度 0）返回 `Selection.globalOnly()`：probe 权重 0、全局权重 1，PBR 消费路径不采样任何探针 cubemap。
- `blendDistance == 0` 是公开的硬边界（边界外权重 0，边界内 0.5），需要连续混合时必须配置正 blend distance。
- `ReflectionProbeSelector.influenceWeight` 是 package-private 实现；JVM 测试用独立 double 参考重算同一公式，不以生产 helper 生成唯一期望值。

## 局部校正

shader 对每个被选中的探针把世界空间反射向量 `R` 与探针影响体求交：

- box：slab 求交，取最近的 `t >= 0`；点在盒内时取出射面。
- sphere：二次方程，取最近的正根；点在球内时取出射根。
- 命中后采样方向为 `normalize(P + R*t - probeCentre)`，即“从探针中心看向命中点”；未命中（点在 blend 壳层且射线背离体积）回退到原 `R`。
- 随后应用探针自己的 `rotationRadians`，再按 `roughness * maxLod` 采样 prefiltered cubemap。
- **旋转合同**：传给局部求交的 `R` 必须是**世界空间**反射方向（anisotropic 开启时是 tangent-plane warp 后的世界方向）。`uEnvironmentRotation` 只作用于全局 `uPrefilteredMap` 采样；探针自己的 rotation 在 `reflectionProbeRadiance` 内最后应用。反例：box 原点 half 1，world point (2,0,0)，world reflection (-1,0,0)，global rotation π/2；若先把反射转成 (0,0,-1)，会错过盒并错误回退，而正确结果应命中 +X 面。
- 这是局部近似：影响体不是捕获深度壳，没有遮挡/视差/背面信息；对 box 内复杂场景只消除“环境在无穷远”的主要误差。

## Shader 合同

冻结 uniform（全部为普通 uniform，无 UBO/SSBO/逐帧读回）：

| 名称 | 含义 |
|---|---|
| `uReflectionProbeCount` | 0/1/2；0 时所有探针代码被 `if` 跳过 |
| `uReflectionProbeGlobalWeight` | 全局环境残余权重 |
| `uReflectionProbe0` / `uReflectionProbe1` | samplerCube，专用 unit 22/23；无探针时也必须写 sampler uniform，不能用 GL 默认 unit 0 |
| `uReflectionProbe{0,1}Position` | 探针世界位置 |
| `uReflectionProbe{0,1}Extents` | box 半径；sphere 只用 `.x` 作为 radius |
| `uReflectionProbe{0,1}Shape` | 0 = BOX，1 = SPHERE |
| `uReflectionProbe{0,1}Weight` | CPU 选择器输出的归一化权重 |
| `uReflectionProbe{0,1}Intensity` | 探针强度，乘在 prefiltered radiance 上 |
| `uReflectionProbe{0,1}Rotation` | 探针环境旋转（弧度） |
| `uReflectionProbe{0,1}MaxLod` | `prefiltered.mipLevels - 1` |

混合点位于原有全局采样之后：

```glsl
vec3 prefiltered = textureLod(uPrefilteredMap, reflection,
        prefilterRoughness * uPrefilterMaxLod).rgb;
if (uReflectionProbeCount > 0) {
    // local correction + CPU weights
    prefiltered = (prefiltered * globalWeight + probeRadiance) / weightSum;
}
```

- 只有 `prefiltered`（specular IBL radiance）被局部替换。diffuse IBL 仍取全局 irradiance；BRDF LUT 仍为全局 LUT；clearcoat 的 IBL 仍取全局 prefiltered；环境强度/ao/gtao 在后续统一乘上。这是首版明确的能量近似。
- 探针局部求交使用独立的 `worldReflection`（anisotropic 时取 warp 后的世界方向）；`reflect` 的全局旋转版本只用于全局 `uPrefilteredMap`。探针自身 rotation 在 `reflectionProbeRadiance` 内应用，因此 `uEnvironmentRotation` 不会改变局部校正命中。
- mip 合同：`PbrEnvironment` 的 prefilter 把 `roughness = mip / (mipLevels - 1)` 写入 mip；消费端用 `lod = clamp(roughness * maxLod, 0, maxLod)`，与全局 IBL 的 `roughness * uPrefilterMaxLod` 完全同构。
- 禁用/无探针路径：`PbrMaterials` 默认写入 `uReflectionProbeCount = 0`、`uReflectionProbeGlobalWeight = 1`，并把 probe sampler uniform 指向专用 unit 22/23。即使不采样探针也必须这样做：shader 静态声明了两个 samplerCube，若保持 GL 默认 unit 0 会与 base-color 的 sampler2D 同 unit，PBR draw 可能因 sampler 类型冲突失效。**这是本包 GPU 调试最终定位到的真实生产 bug**：`PbrMaterials` 曾只在绑定探针时写 sampler uniform，导致禁用/无探针状态下 PBR-only emitter 完全不绘制；修复后 PBR 默认路径恢复。该 probe-aware PBR shader 因此需要上下文至少暴露 24 个 fragment texture unit；目标桌面 GL 4.6 暴露 32，`ReflectionProbeSet.load` 在不满足时明确失败。shader 的 count 分支不执行，输出与引入前相同。GL 用例会把“用探针后 clearOverrides”与原始基线做逐字节比较。
- 不每帧 CPU 读回；选择只读 CPU 侧探针描述与物体代表点，权重以 uniform 上传。

## 质量档与 mip

| 档位 | environmentSize | irradianceSize | prefilteredSize | brdfLutSize | irradianceSamples | prefilterSamples | brdfSamples |
|---|---:|---:|---:|---:|---:|---:|---:|
| TEST | 16 | 8 | 16 | 16 | 32 | 64 | 64 |
| LOW | 128 | 16 | 64 | 64 | 128 | 256 | 256 |
| MEDIUM | 256 | 32 | 128 | 128 | 256 | 512 | 512 |
| HIGH | 512 | 32 | 256 | 256 | 512 | 1024 | 1024 |

每探针保留 `PbrEnvironment` 的 radiance/irradiance/prefiltered/BRDF LUT 四类纹理；首版消费 prefiltered，其余纹理为复用现有预计算路径的保留成本。2 个 HIGH 探针约 2 × (512²×6×8B + 256²×6×8B + 64²×6×8B + 256²×8B) ≈ 32 MB 量级；未做正式显存测量，不能据此宣称预算。需要更省显存时应把 `PbrEnvironment` 拆成 probe-only 预过滤路径（后续项，不在本卡范围）。

## 资源、失败与生命周期

- `ReflectionProbeSet.load` 先做纯 CPU 校验（数量 ≤ 2、name 非空且唯一、字段有限/有界），再检查 fragment texture unit 数 ≥ 24（普通与体积雾 PBR 变体中 22/23 都空闲），然后创建共享 sampler 并逐个预计算。任一探针失败：关闭已创建探针（逆序）、关闭 sampler、把清理异常作为 suppressed 附到原失败上抛出；不会返回部分集合，也不会覆盖已有全局 environment。
- mixed active/disabled 集合使用 **index-aligned null 槽**：`probes` 与 `settings` 等长，disabled/intensity=0 槽为 null 且不拥有 GPU 资源；`activeProbeCount` 统计非 null、`probe(index)` 返回 null、`close` 跳过 null、selector 只考虑 active settings。加载成功路径不能用 `List.copyOf`（会拒绝 null 槽）。
- 探针纹理只借给材质绑定，不转移所有权；`MaterialInstance`/`Material` 永不关闭探针纹理。`close()` 逆序关闭探针 environment，再关闭 sampler；重复 `close()` 无操作；关闭后 `select` 抛 `GlException`。
- 探针不拥有 framebuffer/attachment，不参与 `RenderPipeline.resize` 的候选发布；GL 用例在 resize 前后都渲染并比较探针贡献。资源 owner 仍是调用方（`ReflectionProbeSet`），必须在 pipeline 停止借用后关闭。
- 加载失败回滚与 close 幂等由真实 GL 用例覆盖；JVM 只覆盖加载前校验与选择数学。

第二轮复审修复（Rotation）：shader 保留独立的 `worldReflection` 做探针 box/sphere 求交；`uEnvironmentRotation` 只旋转全局 `uPrefilteredMap` 采样方向；探针自身 rotation 仍在 `reflectionProbeRadiance` 内应用。`full-scan-reference.frag` 同步。

## 已知限制

1. 静态预计算、无实时捕获/动态场景更新；HDR 变化需重新 `load`。
2. 最多 2 个探针同时影响一个 receiver；选择和权重按调用方提供的单个世界点计算，不是逐像素探针选择（shader 只做逐像素局部校正方向与固定权重混合）。跨大物体/探针边界时需由调用方拆分或按对象中心接受近似。
3. 只有 specular prefiltered radiance 局部化；diffuse irradiance、BRDF LUT、clearcoat IBL 仍全局；没有探针遮挡、box 内真实视差、局部 AO。
4. 未与 SSR/平面反射/水体反射做自动仲裁；同一表面的反射来源选择仍由调用方/后续集成决定。
5. `ReflectionProbeSet` 不可变；修改探针启用/质量/影响区需重新加载整个 set。没有 resize/流式候选发布。
6. 未做正式性能、显存、长测或多硬件测量；GL 正确性尚未执行。
7. 局部探针需要至少 24 个 fragment texture unit（unit 22/23 在普通与体积雾 PBR 变体中均空闲；0-21 已被材质/shadow/IBL/GTAO/体积雾占用）。这是 **PBR forward shader 的硬要求**：`PbrMaterials.create`/`createWithBindings` 在更小的 context 上创建期抛 `GlException`，`ReflectionProbeSet.load` 也明确失败。目标 RTX 3050 Laptop 桌面 GL 4.6 通常暴露 32 个；不满足时不能静默降级。
8. 未提供 `RenderFeaturesControl` 全局开关；首版由调用方是否调用 `bindReflectionProbes` 决定。集成接线由 Integrator 完成。

## Integrator 接线点

1. **逐对象/逐 draw 绑定**：在 forward/transparent 材质绑定后、draw 前，按 receiver 世界点调用 `PbrMaterials.bindReflectionProbes(instance, probes, point)`。`MaterialInstance` 的 cube override 会在每次 `bind` 时重放；不要在 pipeline 借用探针纹理时关闭 set。
2. **公共 API 清单**：`docs/architecture/public-api/README.md` 增加 `ReflectionProbeSettings`、`ReflectionProbeSet`、`ReflectionProbeSelector`（`render3d.allowlist` 已加 advanced 分类）；`ReflectionProbe` 为包内实现。
3. **assets.tsv**：把 `pbr-forward.frag` 旧行更新为上表新 SHA-256 和新特性说明；test-only fixture 不追加。
4. **功能控制**：若需要 `RenderFeaturesControl` 开关/依赖校验（例如无 PBR 材质时拒绝、禁用时释放探针），由 Integrator 在 feature policy 中接线；本包未修改这些文件。
5. **GPU 验证**：在串行 GPU 队列运行 `.\gradlew.bat glSmoke --tests "*ReflectionProbeGlTest"`，归档 JUnit XML 与读回结果；未跑前保持 NOT_EVALUATED。
