策略级组合由 `RenderFeatureInteractionMatrixTest` 固定：

- 全部关闭时 topology key 与基线逐字节一致。
- 水面 + 平面反射 + 焦散可同时进入拓扑并通过 `PipelineFeaturePolicy`。
- 云 + 烟雾在 HDR 单采样下同时 active；MSAA 下两者都保持不可用且不改变 key。
- 发束在单采样下 active，MSAA 下不可用（避免共享颜色 renderbuffer 分配失败）。
- OIT 声明集合与随机透明可同时声明；同一集合重叠仍由 pipeline 的 fail-closed 校验拒绝。
- LDR 下云/烟雾保持不可用，key 与基线一致。

## 4. 组合规则

- AA：TAA 与 MSAA 互斥；OIT/随机透明/焦散/云/烟雾/发束要求单采样；DDGI/VCT 拒绝 TAA。
- 间接光：SSGI 与 DDGI/VCT 互斥；DDGI 与 VCT 互斥；都由请求期与装配期双重 fail-closed。
- 透明：OIT 与随机透明对同一 `OitSurface` 互斥；不相交集合允许共存。
- 水面：折射与有限水面互斥；焦散要求水面 active 且首个方向光向下。
- 默认：所有新组件 `disabled()` 是精确 no-op，拓扑 key 与基线逐字节一致。

结果解释：

- 自动像素证据：上表计数来自实际执行，只证明“组合可装配/执行、pass 存在、像素有限且
  非退化、关键特性开关确实改变/恢复图像”。它不证明画面“好看”或与人工参考一致。
- 人工视觉：`NOT_EVALUATED`。本轮没有人工对截图/交互画面的签收，也不把自动像素断言
  当作视觉验收。
- 不支持组合（按生产拒绝断言，未强行组合）：
  - `SSR + finite water`：`PipelineFeaturePolicy.validateSsrComposition` 抛
    `IllegalStateException`，统一特性请求返回 `FAILED` 且保留 water generation；SSR
    仅以 post-only（无水面/折射）验证存在性与精确关闭。
  - `SSGI + DDGI` 与 `SSGI + VCT`：`RenderFeaturePolicy` 以“indirect light”原因拒绝，
    请求状态 `FAILED`，不进入装配。
- 子组合取舍：战斗组不强制 contact/cloud shadows（需要 PBR 材质，由材质与阴影组覆盖），
  也不在共享 HDR VFX 阶段强塞 projected decal（需要 color-only 目标视图，由
  `ProjectedDecalGlTest` 覆盖）；粒子组在 OIT 与 stochastic 中选择 OIT，并记录二者对同一
  surface 集合的互斥合同仍在策略测试中；体积烟雾以 cloud layer 代表，smoke 的真实 GL
  pipeline 由其专项用例覆盖。
- 计数边界：NVIDIA 在冷启动程序首次特化时输出 4 条 `id=131218` MEDIUM 性能提示，
  由 `config/gl-debug-policy.tsv` 的 `render3d/s6-interaction-matrix` 行（max 4，
  2027-05-13 复核）限定；GL 错误与正确性消息不在豁免范围。
