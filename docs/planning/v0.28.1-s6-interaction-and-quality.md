## 1. 目的与边界

- 按执行计划 §7.2 选择高风险代表组合，不建立 46 个开关的笛卡尔积。
- 每个组合验证“能同时装配、顺序/互斥正确、默认关闭是精确 no-op”；高风险特性在组合内
  单独关闭/重开，以像素 delta（确定性场景同时要求逐字节恢复）证明其真实贡献。

## 4. 组合规则

- AA：TAA 与 MSAA 互斥；OIT/随机透明/焦散/云/烟雾/发束要求单采样；DDGI/VCT 拒绝 TAA。
- 间接光：SSGI 与 DDGI/VCT 互斥；DDGI 与 VCT 互斥；都由请求期与装配期双重 fail-closed。
- 透明：OIT 与随机透明对同一 `OitSurface` 互斥；不相交集合允许共存。
- 水面：折射与有限水面互斥；焦散要求水面 active 且首个方向光向下；SSR 不与有限水面或
  单层折射组合。
- 材质：MASK 由非零 alpha cutoff 进入 MASKED 队列；thin/clearcoat/anisotropic/POM 是同一
  PBR 前向材质的独立设置；`disabled()` 是各项的精确 no-op。
- 默认：所有新组件 `disabled()` 是精确 no-op，拓扑 key 与基线逐字节一致。
