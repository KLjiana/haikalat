## 范围与归属

- 归属：`render3d.shadow` 的配置、`render3d.lighting.FrameLightBinder` 的上传职责，以及现有唯一
  `pbr-forward.frag` 的消费端；不新增 manager、factory、Pass、纹理或 GPU 资源。
- 首版只调制一个“已选中的方向光”，即现有 `uDirectionalShadowFrameLightIndex` 指向的灯。点光、
  聚光、未进入方向光阴影选择的其他方向光以及非 PBR 材质明确不消费；启用但没有方向光阴影或
  PBR 消费者时由 `RenderFeaturePolicy` 在候选准备前拒绝，而不是静默忽略。
- 默认关闭。`ShadowSettings` 原四参数、五参数和六参数（带接触阴影）构造器保留，
  `cloudShadows()` 为 `CloudShadowSettings.disabled()`；既有场景和默认输出不变。

## 显式控制

| 控制 | 默认 | 合法范围 | 说明 |
|---|---|---|---|
| `enabled` | `false` | — | 总开关；`active() = enabled && strength > 0` |
| `coverage` | `0.55` | `[0, 1]` | 归一化云量；越大，阈值越低、遮蔽越密 |
| `softness` | `0.35` | `[0, 1]` | 云边半影宽度；0 为窄过渡，1 为宽过渡 |
| `scale` | `0.12` | `(0, 4]` | 世界空间噪声频率；越大云块越小 |
| `speed` | `1.2` | `[0, 20]` | 云层沿固定世界风向的滚动速度，世界单位/秒 |
| `strength` | `0.65` | `[0, 1]` | 被云遮挡时直射光最大衰减比例 |

`CloudShadowSettings` 校验全部有限性、范围和 `scale > 0`；`enabled=false` 或 `strength=0` 时
`active()=false`，`FrameLightBinder` 上传 `uCloudShadowEnabled=0`，PBR 在噪声采样前返回精确
`1.0`，图像不变。

## 输入、输出与合成

- 输入：`vWorldPosition`、接收面法线 `n`、指向选中光源的单位方向 `l`、`uCloudShadow*` 六项
  设置和来自帧时间的 `uCloudShadowTime`。
- 输出：仅把选中方向光的 `visibility` 乘以 `cloudShadowVisibility(n, l)`；随后仍走原有
  `directBrdf`。emissive、IBL（irradiance/prefiltered/BRDF LUT）、AO、背景和其他灯完全不受影响。
- 云项是乘性透射率：`visibility = cascaded * contact * cloud`，因此不会被已存在阴影二次压暗，
  也不会把任何像素变亮。

## 世界空间投影与算法

对选中方向光 `l`，以世界原点为过点、`l` 为法线建立投影平面：

```text
reference = abs(l.y) < 0.999 ? (0,1,0) : (1,0,0)
tangent   = normalize(cross(reference, l))
bitangent = cross(l, tangent)
uv        = (dot(worldPosition, tangent), dot(worldPosition, bitangent))
uv       += (0.8, 0.6) * uCloudShadowTime * uCloudShadowSpeed
```

`uv` 只依赖世界位置、光源方向和帧时间，不读取 `gl_FragCoord`、`uCameraPosition` 或
`uStableViewProjection`，所以相机平移/旋转不会让云影粘屏。云层沿固定世界风向滚动；不依赖
体积云、深度附件或历史缓冲。

噪声为三倍频 2D value noise（每倍频 4 次 hash，共 12 次 hash，`CLOUD_SHADOW_OCTAVES=3`）。
`coverage` 映射到阈值 `mix(0.78, 0.22, coverage)`，`softness` 映射到半影宽度
`mix(0.004, 0.28, softness)`，云密度为
`smoothstep(threshold - edge, threshold + edge, noise)`，最终
`visibility = 1 - clamp(strength) * density`。所有循环边界和采样次数是编译期常量。

## 帧时间、相机与失效

`FrameLightBinder.bind` 从传入的 `ShadowFramePlan` 读取 `FrameTiming(frameSequence, deltaSeconds)`。
该字段由 `ShadowCacheState.prepare` 从 `RenderFrameContext.frameSequence()/deltaSeconds()` 填入，
随一帧影子计划传播，因此不需要修改 `RenderPipeline` 调用点或装配逻辑。

`CloudShadowFrameTime` 在每个新的 `frameSequence` 最多累加一次 `deltaSeconds`（上限 0.1 s，
首帧为 0）；同一帧的多次材质/状态绑定不会重复推进。序列回退时从 0 重建。内部用 double 累计、
上传 float。`ShadowFramePlan` 的新 canonical 构造器保留原十参数重载并填入
`FrameTiming.NONE`，旧调用方无需修改；`ShadowFramePlan` 仍为 internal。

功能开关走现有 `RenderFeaturesControl` 批次/代次发布；首版不提供逐帧热改。代次重建时
`FrameLightBinder` 与 `CloudShadowFrameTime` 重建，云层时间从 0 开始，这是已知的有限首版行为。

## 资源生命周期与成本

- 无新纹理、FBO、shader、Pass 或 GPU 资源；`CloudShadowSettings` 是纯值对象，随
  `ShadowSettings`/`RenderFeatureSettings` 发布。
- `FrameLightBinder` 每次材质/帧状态绑定上传 7 个标量 uniform（1 个 int、6 个 float）；
  关闭时只上传 `uCloudShadowEnabled=0` 和惰性时间值，shader 在噪声前返回。
- 成本：每条被选中方向光照亮且面向光源的 PBR 片元最多 12 次 hash 和 1 次 `smoothstep`；
  关闭/零强度为 0 次 hash。没有额外 draw、采样或带宽。
- 修改设置走现有候选代发布；关闭不会释放其他消费者的共享资源，因为没有专属资源。

## 独立参考与限制

- JVM 期望来自显式参数边界、default-off/no-op 合同和公开的 world-space 输入约束，不复用生产
  shader 公式计算期望值；GL 测试使用真实 PBR 消费者读回线性 HDR，并对比固定世界点而非把当前
  输出当真值。
- 本版不是体积云、不是纹理云图、不提供风速/风向画布、不处理月影或多方向光独立遮罩；只消费
  现有方向光阴影选择结果。无方向光阴影时启用会被策略拒绝，而不是退化为“第一盏方向光”。
- 太阳方向变化会转动投影基，云图案随光源方向改变；这是方向光投影的预期行为，不是世界空间
  失效。固定风向与单一全局 `CloudShadowSettings` 是有界首版约束。
- 没有 GL/GPU 证据前不宣称 shader 编译、相机平移不粘屏或精确 no-op 在硬件上通过。
