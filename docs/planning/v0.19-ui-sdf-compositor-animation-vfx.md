# v0.19.x UI 深化：SDF 图元、现代动画、Compositor 与 UI VFX

> 状态：0.19.4 已实现并通过 JVM/ModernUi GL 门禁；offscreen subtree replay/cache reuse 保留为后续 advanced 收敛项
>
> 当前基线：`0.19.4`
>
> 目标小版本：`0.19.1`、`0.19.2`、`0.19.3`、`0.19.4`
>
> 主题：让 retained-mode UI 具备现代面板、圆角、动效、玻璃拟态和屏幕空间 VFX，
> 同时保持现有字体、输入、双槽/三槽 snapshot、typed command 和无桌面 CI 合同。

## 1. 总体结论

现有 UI subsystem 已经具备继续深耕的基础：

- `UiDocument`、Yoga layout、widget/event/focus 已形成稳定 retained tree；
- `UiDisplayList` 与 `UiBatcher` 已将逻辑树和 GL draw 解耦；
- `UiRenderer` 使用独立 shader、persistent mapped vertex ring 和 typed `CommandBuffer`；
- glyph atlas、Latin/CJK shaping、Windows IME 和异步 snapshot 已有真实 GL 验收；
- `UiAnimationSystem` 已支持 visual/layout 两条确定性 transition 通道；
- `core.graph.RenderGraph` 已提供通用 managed color target、pass dependency 和 attachment id。

当前限制也很集中：

- `ComputedStyle.radius` 已存在，但 `UiPainter` 仍以四条矩形边绘制 border；
- UI shader 只有 SOLID、TEXTURED、GLYPH、DEBUG_OUTLINE 四类；
- 普通 UI 顶点只有 position/UV/color，缺少 SDF shape 参数；
- UI 当前在最终 backbuffer overlay pass 中直接绘制，没有可选离屏 layer；
- `UiAnimationSystem` 每个节点每类 channel 只保留一条 transition，没有 transform、sequence、
  stagger、shared element 或 property track；
- 现有 VFX 是场景 HDR 路径，带深度、Bloom、自动曝光和世界空间语义，不能直接拿来画 UI。

因此本计划不重写 UI，而是沿已有边界增加四条明确路径：

```text
普通 quad / glyph
        \
         -> UiDisplayList / UiBatcher -> UiRenderer
SDF shape /

UI animation -> immutable snapshot -> paint/layout/SDF/effect properties

selected UiLayer -> RenderGraph managed target -> blur/shadow/glow -> UI composite

UiEffectInstance -> deterministic screen-space effect snapshot -> UI VFX pass
```

推荐完整顺序：

```text
0.19.1 SDF primitive foundation
        ↓
0.19.2 property animation and interaction motion
        ↓
0.19.3 UiLayer compositor and post effects
        ↓
0.19.4 screen-space UI VFX
```

## 2. 范围与非目标

### 2.1 v0.19.x 必须完成

- SDF 圆角矩形、胶囊、圆/椭圆、环形和进度图元；
- independent corner radius、border、gradient 和像素级抗锯齿；
- 保持普通 image/glyph 路径不携带 SDF 负载；
- transform、decoration、effect strength 等属性轨道；
- sequence、parallel、stagger、repeat、reverse 和 interruption；
- hover/pressed/focus/disabled 状态动效；
- enter/exit 与 popup/menu/tooltip 过渡；
- 可选 FLIP layout transition；
- 可选 UI 离屏 layer；
- drop shadow、inner shadow、blur、backdrop blur、glow 和颜色滤镜；
- 线性空间、premultiplied alpha 和 UI tone-mapping 边界；
- 轻量 screen-space UI VFX；
- 固定种子、确定性 update、节点 anchor、clip 和生命周期；
- 真实 GL、像素、resize、DPI、失败清理和性能门禁；
- 新增 `ModernUiDemo` 作为综合展示和验收入口。

### 2.2 明确不做

- 不把所有 glyph 迁移为 SDF/MSDF；
- 不在 v0.19.x 引入完整 CSS parser、CSS selector、浏览器级 cascade；
- 不把 UI 变成 ECS、场景脚本或通用 component registry；
- 不让 UI 依赖 `subsystems.render3d`、`subsystems.postprocess` 或具体 3D pass 常量；
- 不直接复用世界空间 `VfxRenderer`、场景深度或自动曝光；
- 不对整个 backbuffer 做全屏 UI blur；
- 不为每个普通 quad 增加大块 SDF/滤镜参数；
- 不在 UI shader 中继续堆叠无边界的 `uMode` 分支；
- 不自动迁移既有动画状态到任意重建的 widget tree；
- 不在首版做 GPU particle simulation、indirect compact 或 UI physics；
- 不实现 SVG renderer、复杂矢量路径和任意布尔 SDF；
- 不把彩色 Emoji、完整 BiDi 或 variable-font UI 误标为本阶段目标。

## 3. 版本与依赖关系

| 版本 | 主要内容 | 是否依赖前一段 |
|---|---|---|
| `0.19.1` | SDF shape、圆角控件、渐变和 SDF 参数批处理 | 无 |
| `0.19.2` | transform/property tracks、状态动效、sequence/stagger、FLIP | 推荐依赖 `0.19.1` |
| `0.19.3` | UiLayer、离屏 target、阴影、blur、backdrop、glow | 依赖 SDF mask，推荐依赖 `0.19.2` |
| `0.19.4` | UI VFX、流光、dissolve、粒子、trail、UI effects bridge | 依赖 snapshot、animation、compositor |

每个版本都可以独立发布：

- `0.19.1` 即使没有后续 compositor 也必须是可用 UI；
- `0.19.2` 不得要求后处理才能使用动画；
- `0.19.3` 的后处理必须对未使用 layer 的 UI 零额外 render target；
- `0.19.4` 的 VFX 不得改变普通 UI 的渲染颜色空间和输入行为。

## 4. 架构边界

### 4.1 依赖方向

延续 v0.11 的兄弟 subsystem 合同：

```text
subsystems.ui
  ├─ core.graph / core.command / backend 的正式资源与命令
  ├─ 自己拥有 UiRenderer、UiCompositor、UiEffectRenderer
  └─ 不依赖 render3d、postprocess、Scene、Camera、Material、PostProcessTargets

subsystems.render3d / subsystems.postprocess
  └─ 不依赖 UiSystem、UiRenderer、UiEffect 或 widget

宿主 Demo / application
  ├─ 创建 RenderPipeline 和 UiSystem
  ├─ 通过中立 attachment/options 提供 backdrop source（如果存在）
  └─ 在 RenderGraph topology seal 前完成 UI layer/pass 注册
```

`UiSystem` 可以使用 `RenderGraph` 的通用 pass、managed color attachment、
`PassResources.colorAttachment(...)` 和 `CommandBuffer`，但不得引用具体 3D pass 名称。

### 4.2 Backdrop source 合同

backdrop blur 需要一个可采样的场景颜色来源。最终 backbuffer 本身不是可直接采样的纹理，
因此 UI 不能偷偷在 overlay pass 中读取 default framebuffer。

建议新增 UI 中立类型：

```java
public record UiBackdropSource(
        String passName,
        String colorTextureName,
        int width,
        int height
) {}
```

规则：

- source 由宿主 application 从当前 RenderGraph 的通用描述中提供；
- `subsystems.ui` 只按逻辑 pass/resource name 查询 attachment id；
- UI 不知道该 source 来自 geometry、tone mapping 还是其他 subsystem；
- 没有 source 时 backdrop blur 必须明确禁用或降级为普通 translucent panel；
- UI 不得引用 `PostProcessTargets.TONE_MAPPING_PASS` 等具体常量；
- source 的尺寸、颜色格式、resize 和生命周期由 RenderGraph owner 保证；
- source 只在当前 graph/frame 有效，不能存为跨 graph 的永久 native id。

### 4.3 资源所有权

| 资源 | owner | 规则 |
|---|---|---|
| SDF shader/program | `UiRenderer` | GL thread 创建/关闭 |
| SDF instance ring | `UiRenderer` | ring fence 跟随最后一次 SDF draw |
| UiLayer target | `UiCompositor`/RenderGraph | graph close/resize 时释放 |
| blur/shadow intermediate | `UiCompositor` | target 失败时逆序释放 |
| effect texture/noise | UI effect asset owner | UI renderer 只借用 |
| effect particle buffers | `UiEffectRenderer` | GPU-only 时独占，首版以 CPU snapshot 为主 |
| glyph atlas | `UiGlyphAtlasGpu` | 保持现有 owner/lease |
| immutable UI snapshot | update/snapshot exchange | 不持有 GL handle，只保存逻辑资源 ID |

SDF 参数、layer description、animation state 和 effect state 都必须进入 snapshot；快照不得
持有 `Texture2D`、`Framebuffer`、`ShaderProgram` 或 OpenGL integer handle。

## 5. 统一 UI 数据模型

### 5.1 保留现有 display list 路径

现有普通类型保持：

- `SOLID_QUAD`
- `TEXTURED_QUAD`
- `GLYPH_RUN`
- `DEBUG_OUTLINE`
- `PUSH_CLIP`
- `POP_CLIP`
- `PAINT_BOUNDARY`

新增：

- `SDF_SHAPE`
- `LAYER_BEGIN`
- `LAYER_END`
- `EFFECT_ANCHOR`（建议首版作为 effect arena 元数据，不一定产生独立 draw）

不把 layer/effect 指令强行塞进普通 `UiBatcher` 的 texture batching；它们是顺序边界，
必须可观察、可统计和可诊断。

### 5.2 参数 arena

普通 quad 继续使用当前紧凑 vertex ring。SDF 和 effect 使用单独 arena：

```text
UiDisplayList
  ├─ ordinary quad arrays
  ├─ primitive command arrays
  ├─ SdfPaintArena
  ├─ UiLayerArena
  └─ UiEffectArena
```

每个 arena 都必须支持：

- 可复用 mutable recording storage；
- `freeze()` 后 immutable snapshot；
- snapshot exchange slot 原地覆写；
- 容量上限和高水位诊断；
- 超限时确定性失败，不自动无限增长；
- 记录/消费线程边界；
- 无每 primitive 临时对象分配的正常路径。

### 5.3 颜色与 alpha

所有 UI paint 都继续使用 premultiplied alpha：

- SDF coverage 乘以 premultiplied color；
- blur/shadow 对 premultiplied color 和 alpha 一起处理；
- 不对 RGB 做非 premultiplied blur；
- UI overlay 默认保持最终 tone mapping 之后；
- gradient interpolation 在线性颜色空间完成；
- backbuffer sRGB 编码只由现有 framebuffer state 负责；
- shader 不重复 gamma；
- 半透明边缘必须有像素 A/B，防止黑边和白边。

## 6. `0.19.1`：SDF 图元基础

### 6.1 目标

让现有控件不再依赖多块矩形拼接，真实使用 `ComputedStyle.radius`，并为后续 layer mask、
shadow、glow 和 UI VFX 提供连续 coverage。

### 6.2 图元范围

首版正式支持：

| 图元 | 参数 |
|---|---|
| rounded rect | width/height、四角 radius、fill、border |
| pill | 由 rounded rect 的 max radius 规范化 |
| ellipse/circle | center、half-size |
| ring | inner/outer radius、start/end angle |
| progress arc | radius、thickness、start/end angle |
| rounded line | endpoints、width、cap style |
| linear gradient rect | start/end、2～4 color stops |
| radial gradient rect | center、radius、color stops |

不在首版支持：

- 任意 signed distance function expression；
- SDF union/subtract/intersection 编辑器；
- SVG path；
- 纹理和 SDF 混合的无限层；
- 每个 corner 独立不同的渐变坐标系；
- MSDF glyph。

### 6.3 SDF 数学与抗锯齿

`ui-sdf.frag` 使用局部 quad 坐标计算 signed distance：

- rounded box 使用四角半径；
- ellipse/ring 使用解析距离；
- coverage 使用 `smoothstep` 与 `fwidth(distance)`；
- border 使用 outer distance 与 inner distance 的差；
- radius 自动限制到 half extent；
- 极小尺寸保持至少一个可见 coverage；
- NaN、负尺寸、负 border 和超大 radius 在 CPU 侧拒绝；
- shader 内再次 clamp，避免坏 snapshot 产生未定义输出。

coverage 语义：

```text
alpha = fillCoverage * fillAlpha
border = max(outerCoverage - innerCoverage, 0)
finalPremultiplied = (fillColor * fillCoverage + borderColor * border) * opacity
```

### 6.4 SDF 数据布局

不建议给每个普通顶点增加十几个浮点字段。建议新增专用 instanced path：

```text
static unit quad VAO
  +
UiSdfInstanceRing:
  rect.xywh
  cornerRadius.xyzw
  borderWidth
  shapeType
  gradient parameters
  fill/border premultiplied colors
  clip/layer index
```

使用已有 typed `drawElementsInstanced`，并复用 UI renderer 的 GPU fence 语义。

规则：

- 相同 SDF shader family、blend mode、clip/layer state 才能 batch；
- `PAINT_BOUNDARY` 不能跨越；
- 普通 quad 和 SDF batch 不强制合并；
- SDF ring slot 只在最后一个 SDF draw 后插入 fence；
- record 失败时 abort 当前写入；
- `UiRenderer.close()` 逆序关闭 SDF ring、VAO、shader；
- SDF batch 统计独立记录 draw、instance、bytes 和 ring wait。

### 6.5 样式 API

保持 `ComputedStyle` record 的现有组件，避免为新增组件破坏已有 source compatibility。

新增独立值对象：

```java
public record UiSdfDecoration(
        UiSdfPaint fill,
        UiSdfPaint border,
        float borderWidth,
        UiGradient gradient,
        UiShadowStyle shadow
) {}
```

建议初始 API：

- `UiNode.sdfDecoration()` / `sdfDecoration(...)`
- `UiSdfPaint.solid(UiColor)`
- `UiSdfPaint.linearGradient(...)`
- `UiSdfShape`
- `UiGradient`
- `UiGradientStop`
- `UiShadowStyle`（仅描述，不负责后处理）

`UiShadowStyle` 在 `0.19.1` 可以记录并显示为 unsupported/disabled；真正 blur shadow 在
`0.19.3` 的 compositor 完成。不要在 SDF fragment 里做固定半径多次采样的伪 shadow。

### 6.6 控件迁移顺序

1. `Panel`
2. `Button`
3. `Toggle`
4. `Slider`
5. `TextField`
6. `Popup/Menu`
7. debug outline

迁移原则：

- 同一个控件先保留 solid fallback；
- SDF 失败或超限时只回退该 primitive，不丢失整帧；
- fallback 结果颜色和 alpha 必须可预测；
- 控件 widget 不接触 shader/program；
- `UiPainter` 只生成逻辑 SDF 命令，不调用 OpenGL。

### 6.7 SDF clip

`0.19.1` 分两级：

- 矩形 clip 继续走现有 scissor 快速路径；
- 单层 rounded clip 可以作为 SDF instance coverage；
- 多层 rounded clip 暂时不声称完整支持；
- 需要多层圆角、blur 或 backdrop 的 subtree 必须使用 `UiLayer`，留给 `0.19.3`；
- 不用 stencil stack 作为 v0.19.1 的隐式旁路，因为它会破坏 snapshot 统计和 layer 语义。

### 6.8 `0.19.1` 验收

纯 JVM：

- radius clamp；
- 四角 radius；
- ring/arc 参数；
- gradient stop 排序和边界；
- SDF arena freeze/replace；
- SDF batch key；
- NaN、负尺寸、超限；
- fallback 行为；
- display list boundary 不被跨越。

真实 GL：

- 1 px、2 px、非整数 DPI 圆角；
- 旋转/resize 后 coverage；
- fill/border A/B；
- 半透明 SDF 叠加；
- 100、1,000、10,000 个 SDF shape；
- SDF 与 glyph/image 混合；
- frame failure 后 ring fence；
- shader 无 HIGH/MEDIUM 新告警；
- 关闭时 GL resource 回到基线。

## 7. `0.19.2`：现代动画与交互过渡

### 7.1 现有动画边界

当前 `UiAnimationSystem`：

- owner thread 单线程；
- visual/layout 两个 channel；
- 新 transition 会替换同一 node/channel 的旧 transition；
- 支持 linear/cubic/spring、pause/resume/cancel；
- visual 会整体生成 `ComputedStyle`；
- layout 只在 unit/离散字段兼容时插值。

保留这些行为，新增 property track，而不是删除原 API。

### 7.2 属性轨道

新增 `UiPropertyTrack`，首版支持：

- opacity；
- foreground/background/border color；
- radius；
- border width；
- SDF gradient stop/offset；
- shadow strength；
- effect strength；
- translation x/y；
- scale x/y；
- rotation；
- transform origin；
- scroll offset；
- progress/value。

每条 track 必须标记：

```text
VISUAL       -> 只 dirty paint
LAYOUT       -> 触发布局
HIT_TEST     -> 更新命中区域
COMPOSITOR   -> 更新 layer/effect
```

默认把 transform、opacity、radius、color 视为 visual/compositor，避免每帧重新 Yoga layout。

### 7.3 VisualTransform

新增独立 `UiVisualTransform`，不修改 `UiStyle`：

```java
public record UiVisualTransform(
        double translateX,
        double translateY,
        double scaleX,
        double scaleY,
        double rotationRadians,
        double originX,
        double originY
) {}
```

规则：

- scale 必须有限且非零；
- rotation 使用 radians；
- origin 默认 bounds center；
- transform 在 paint snapshot 阶段应用；
- hit-test 使用逆 transform；
- clip 使用同一 transform 语义；
- 不把变换写进 Yoga 尺寸；
- 子节点继承父 visual transform，但布局尺寸不被视觉 transform 改写；
- 非可逆 transform 必须拒绝，而不是让事件落到错误节点。

### 7.4 Timeline、sequence 和 group

新增确定性 timeline：

- `UiTimeline`
- `UiAnimationSequence`
- `UiAnimationGroup`
- `UiStagger`
- `UiAnimationTrigger`

行为：

- fixed update 与 interactive real delta 都支持；
- sequence 内每一步的开始/结束有稳定 sequence；
- parallel group 完成条件固定为 ALL/ANY；
- stagger 根据 stable child order，不依赖 HashMap；
- repeat/reverse 不重复发出错误的 completion；
- cancellation 只发一次；
- replacement 记录 replaced reason；
- pause/resume 不重置 elapsed；
- time seek 只允许 explicit debug/test 入口；
- large delta 经过现有 bounded delta 规则，不跳过清理。

### 7.5 状态驱动动画

新增 `UiInteractionState`：

```text
NORMAL
HOVERED
PRESSED
FOCUSED
DISABLED
SELECTED
INVALID
LOADING
```

状态样式不直接依赖 widget 类型。`Theme` 提供 token/transition spec，widget 只发布状态变化。

规则：

- hover/press/focus 使用相同状态机；
- pointer capture 丢失时取消 pressed；
- focus lost 时不残留 focus animation；
- disabled 不接受 pointer transition；
- prefers-reduced-motion 时使用 duration=0 或低幅度替代；
- 状态变化和动画启动 sequence 进入诊断；
- 状态动画不能绕过用户显式 animation cancel。

### 7.6 Enter/exit 与 popup

`UiNode` 销毁前允许注册 exit transition：

1. 节点进入 EXITING；
2. 保持 paint，但从 hit-test 取消；
3. 动画完成后真正 detach/close；
4. close 失败时继续清理后续节点；
5. snapshot 不发布已关闭 node。

Popup/Menu/Tooltip：

- enter/exit 均有稳定 anchor；
- anchor 消失时 cancel 并关闭；
- overlay layer 的 z-order 由 display list boundary 保证；
- 不依赖额外 window；
- popup animation 不改变 layout owner thread。

### 7.7 FLIP layout

首版只对显式 opt-in 节点开启：

1. layout 前保存 first rect；
2. layout 后取得 last rect；
3. 计算 inverse transform；
4. 在 visual transform 中播放到 identity；
5. hit-test 使用 last layout，视觉上使用过渡矩阵；
6. 动画完成后清除 FLIP state。

禁止默认对整棵树启用 FLIP。布局重排、字体变化和 scroll container 变化先保留静态
fallback，避免出现文本测量和命中语义错位。

### 7.8 `0.19.2` 验收

纯 JVM：

- property track 插值；
- transform inverse hit-test；
- sequence/group/stagger；
- repeat/reverse；
- replacement/cancel/close；
- state transition；
- reduced motion；
- enter/exit；
- FLIP first/last/inverse；
- visual/layout dirty flag；
- fixed-step 与 large-delta 一致性。

真实 GL：

- 1,000 个 animated controls；
- SDF radius/color/transform 同时动画；
- popup enter/exit；
- resize/DPI 下 transform；
- input hit-test 与视觉位置一致；
- UI snapshot 在异步 triple slot 下不读写竞态；
- 无每帧大规模临时对象；
- animation effect 不导致 glyph atlas 重建；
- 无 GL error 和 ring fence 漏记。

## 8. `0.19.3`：UiLayer Compositor 与后处理

### 8.1 设计目标

只对需要效果的 subtree 创建离屏 layer，其他 UI 继续直接走现有 backbuffer overlay：

```text
普通 UI -----------------------------> backbuffer overlay
SDF panel + shadow -------------------> layer target -> composite
毛玻璃 panel -------------------------> backdrop source
                                         -> downsample
                                         -> blur
                                         -> rounded mask
                                         -> layer composite
```

### 8.2 Layer 数据

新增 `UiLayerDescription`：

- stable layer id；
- parent layer id；
- logical bounds；
- framebuffer scale；
- opacity；
- blend mode；
- clip/mask mode；
- effect flags；
- backdrop source requirement；
- z-order；
- cache policy；
- dirty revision。

layer 只来自显式 `UiNode` decoration 或 `UiDisplayList` begin/end，不自动为每个 Panel 建层。

### 8.3 Layer 生命周期

`UiCompositor` 只在 render thread/RenderGraph topology setup 中管理 GPU target：

- 首次使用时创建；
- resize 时按 scale 重新创建；
- hidden layer 可以跳过 record；
- dirty=false 时可复用上一帧 layer；
- source size/format 改变时失效；
- graph close 时逆序关闭全部 intermediate；
- 创建失败时该 layer 回退到直接 UI draw；
- 不能让一个 layer 失败导致整个 UI overlay 消失。

建议上限：

| 配置 | 默认 |
|---|---:|
| 活动 layer | 64 |
| 单帧新增 layer | 8 |
| 单 layer 像素 | 4K×4K |
| blur radius | 0～64 logical px |
| blur downsample | 1/2/4 |
| 中间 target 总像素 | 16M |
| cache idle frames | 120 |

### 8.4 RenderGraph 接入

`UiSystem.attachTo(...)` 保持现有兼容入口，新增 options 入口：

```java
ui.attachTo(graph, dependencyPass,
        UiAttachmentOptions.builder()
                .backdropSource(backdropSource)
                .enableCompositor(true)
                .build());
```

规则：

- topology seal 前注册 compositor passes；
- layer pass 使用 `RenderGraph.PassBuilder.createColor(...)`；
- blur pass 只依赖 UI-owned logical names；
- composite pass 最终写回 backbuffer；
- `UiSystem` 不引用 render3d/postprocess 常量；
- no-compositor 时不创建 layer target；
- UI pass 名称使用 `UiOverlayPass`、`UiLayer/<id>`、`UiBlur/<id>` 等 UI-owned namespace；
- 资源名字包含 stable layer id，禁止使用 hash iteration 顺序；
- resize 由 graph resize 统一触发，UI 不自己创建第二个 window-sized graph。

### 8.5 效果范围

首版提供：

- drop shadow；
- inner shadow；
- single/double axis blur；
- backdrop blur；
- bloom-like UI glow；
- brightness/contrast/saturation；
- color tint；
- rounded mask；
- opacity and blend mode。

效果顺序固定：

```text
source/backdrop
  -> optional downsample
  -> blur
  -> shadow/glow
  -> rounded mask
  -> color transform
  -> layer composite
  -> crisp text/foreground overlay
```

文字默认在 layer composite 后重新绘制，避免 blur 把小字号文字变糊。需要把文字一起模糊
的节点必须显式 `blurContent=true`。

### 8.6 颜色空间

- layer color target 默认 `SRGB8_ALPHA8`，只用于不需要 HDR/filter 的普通 layer；
- blur/filter target 视实现选择 `RGBA16F` 或线性 `RGBA8`；
- 采样 sRGB 时由纹理采样自动解码；
- 计算、blur、gradient 和 premultiplied composite 使用 linear；
- 回写 sRGB target 时由 framebuffer state 编码；
- 不把 UI layer 送入场景 tone mapping、auto exposure 或 scene Bloom；
- UI glow 是独立的 LDR/linear layer效果；
- 任何颜色空间转换必须在测试中有 A/B 像素证明。

### 8.7 Backdrop blur 语义

backdrop blur 不是“模糊自身 layer”，而是：

1. 从 host 提供的 scene color source 采样；
2. 按 layer bounds 裁剪；
3. downsample/blur；
4. 用 panel SDF mask 取样；
5. 叠加半透明 fill/border；
6. 绘制 crisp child content。

没有可采样 backdrop source 时：

- 不读取 backbuffer；
- 不执行 undefined texture bind；
- 明确记录 `BACKDROP_SOURCE_UNAVAILABLE`；
- fallback 为 translucent fill 或普通 opaque panel；
- 不能以黑色纹理静默代替。

- source unavailable fallback；
- target budget；

- color transform math；
- premultiplied blur reference；
- layer close/retire。

真实 GL：

## 9. `0.19.4`：UI VFX

### 9.1 设计原则

UI VFX 是 screen-space subsystem，不是世界 VFX 的别名：

- 不依赖 Scene、Camera、depth texture 或 world transform；
- 不使用当前 `subsystems.render3d.vfx.VfxRenderer`；
- 可以复用 `core.curve` 的 curve/gradient/path 数学；
- 可以复用资产身份和 texture cache 的逻辑原则，但 GPU owner 独立；
- 首版以 deterministic CPU simulation + batched screen-space draw 为主；
- GPU particle/compute 另立版本。

### 9.2 Effect 定义

新增 `UiEffectDefinition`：

- type；
- duration/lifetime；
- seed；
- anchor mode；
- local bounds；
- clip policy；
- blend mode；
- color/gradient；
- curve tracks；
- texture/noise reference；
- max particles；
- reduced-motion fallback；
- HDR/blur policy。

新增 `UiEffectInstance`：

- definition；
- target `UiId`；
- start sequence；
- elapsed；
- deterministic random state；
- current particles/segments；
- active/cancelled/completed；
- diagnostic counters。

### 9.3 首版 effect 类型

推荐顺序：

1. `SHIMMER`：按钮、卡片、loading；
2. `RIPPLE`：点击/触摸反馈；
3. `DISSOLVE`：图片、面板、奖励卡；
4. `SPARK`：点击和确认；
5. `CONFETTI`：奖励/成就；
6. `TRAIL`：拖拽、技能条、数值变化；
7. `SCANLINE/GLITCH`：诊断和少量主题效果。

每个 effect 必须有固定最大容量和没有纹理时的 fallback。

### 9.4 Anchor 与 clip

Anchor 模式：

- node bounds；
- content bounds；
- edge/corner；
- pointer position；
- explicit logical point；
- path progress。

规则：

- effect snapshot 只保存 `UiId` 和逻辑坐标；
- update 线程解析 anchor；
- render snapshot 中保存已解析的屏幕空间值；
- node detach 时 effect 收到 cancel；
- hidden node 不更新粒子；
- clip policy 为 INHERIT、NODE_BOUNDS、NONE；
- rounded clip 由 SDF mask/layer compositor 提供；
- effect 不能偷偷绘制到 layer 外部。

### 9.5 UI VFX render path

首版分三类：

```text
analytic effect  -> SDF/gradient shader
sprite effect    -> UI texture batch/atlas
particle/trail   -> UiEffect instance ring
```

- analytic effect 复用 SDF 参数 arena；
- sprite effect 复用 image sampler，但不暴露 texture owner；
- particle/trail 使用单独 instance buffer；
- 每个 effect family 独立 shader variant；
- 不再把所有 effect 变成 `uMode` 分支；
- effect draw 与普通 UI 之间保留明确 paint boundary；
- layer effect 在 layer 内执行，global overlay effect 需显式授权。

### 9.6 动画与 VFX 联动

UI animation 和 UI VFX 只通过稳定 signal：

```text
UiAnimationSignal:
  source UiId
  sequence
  type START / MARKER / COMPLETE / CANCEL
  normalizedTime
  payload
```

- animation system 不直接创建 effect；
- `UiEffectBridge` 在 application/UI orchestration 层消费 signal；
- VFX 不修改 animation state；
- bridge 必须防止同一 sequence 重复触发；
- cancel、replacement、close 都有明确 effect cleanup；
- `reduced-motion` 可将 effect 替换为 opacity/color feedback。

### 9.7 `0.19.4` 验收

纯 JVM：

- fixed seed；
- lifetime/over-life；
- curve sampling；
- anchor detach；
- clip policy；
- cancel/complete/replacement；
- max particle capacity；
- signal dedup；
- reduced-motion fallback；
- snapshot freeze/consume。

真实 GL：

- shimmer/ripple/dissolve；
- spark/confetti；
- trail；
- SDF shape + effect 混合；
- layer effect + crisp text；
- resize/DPI；
- hidden/visible toggle；
- effect failure cleanup；
- texture missing fallback；
- 3600 帧稳定性；
- no GL error/HIGH/MEDIUM drift；
- UI VFX 不进入 scene auto-exposure/Bloom。

## 13. 性能门槛

### 13.1 基础 UI

- 无 SDF/layer/effect 时，普通 UI draw/quad 性能不得回退超过 5%；
- 普通 glyph path 不增加 SDF instance bytes；
- snapshot stable frame 不创建每 primitive 对象；
- `UiBatcher` 不因 disabled layer 产生额外 batch；
- SDF instance ring 不出现未 fence slot；
- 4K 下 UI frame CPU p95 增长不超过既定预算。

### 13.2 SDF

建议基线：

- 10,000 个 SDF shape；
- 不超过 2 个 shader family；
- 不超过 32 个 SDF draw；
- instance upload bytes 线性增长；
- no per-shape GL call；
- ring wait p99 可观察且不持续增长。

### 13.3 Compositor

- 无活动 layer 时 target count 增量为 0；
- 一个静态 layer 在 clean frame 复用 target；
- blur 使用 downsample；
- layer 总像素超过预算时确定性降级；
- backdrop source 不存在时不创建无效 target；
- blur/glow 只对选中 layer 执行，不影响普通 UI。

### 13.4 VFX

- 默认每个 effect 类型有最大实例数；
- 100、1,000、10,000 effect instance 有独立数据；
- inactive/hidden effect 不更新；
- 3600 帧后 CPU heap、GPU bytes、effect count 回到稳定范围；
- effect 不触发 scene exposure/history/bloom；
- reduced motion 不仅隐藏 draw，还停止不必要 simulation。

## 15. 失败和回退策略

### 15.1 SDF 失败

- 参数非法：JVM 构造阶段失败；
- arena 超限：该 primitive 回退 solid；
- shader 初始化失败：整个 SDF path disabled，普通 UI 继续；
- SDF ring 写入失败：abort current write，保留上一 snapshot；
- draw 失败：按现有 UI renderer cleanup/fence 规则处理。

### 15.2 Animation 失败

- 不兼容 layout track：拒绝该 track，不破坏其他 visual track；
- 非法 transform：拒绝启动；
- node 已关闭：立即 cancel；
- timeline exception：停止该 timeline，继续更新其他 timeline；
- callback 失败：记录 diagnostics，不能阻断 snapshot publish。

### 15.3 Compositor 失败

- target 分配失败：layer fallback direct；
- backdrop source 缺失：translucent/no-backdrop fallback；
- blur budget 超限：降低 downsample 或关闭 blur；
- mask 失败：矩形 clip fallback；
- graph topology 错误：UiSystem attach 失败，不能半注册；
- close 失败：继续关闭其余 targets 并 suppressed。

### 15.4 VFX 失败

- texture 缺失：solid/analytic fallback；
- effect capacity 满：丢弃低优先级新实例；
- anchor 无效：cancel effect；
- shader variant 失败：禁用该 effect family；
- animation bridge 重复 signal：sequence 去重；
- VFX owner close：停止 update，清空未发布 snapshot。

## 20. 最终建议

正式实施时不要把四个方向平均铺开。建议每个小版本都有一个可见主题：

- `0.19.1`：圆角、渐变、现代控件；
- `0.19.2`：状态反馈、弹窗、菜单和进场动画；
- `0.19.3`：玻璃拟态、阴影、模糊和层合成；
- `0.19.4`：流光、点击反馈、奖励粒子和 HUD VFX。

最重要的架构取舍是：

1. SDF 是图元基础，不等于把所有字体改成 SDF；
2. animation 只修改 snapshot 属性，不直接操纵 GL；
3. compositor 只处理显式 layer，不模糊整个 backbuffer；
4. UI VFX 是 screen-space、LDR、deterministic，不复用世界 VFX 的 HDR 语义；
5. 普通 UI 路径永远保留，所有新效果都必须可降级。

这样做完，项目会得到一条可持续扩展的现代 UI 生产线，而不是一个越来越大的 UI fragment
shader。
