## 技术卡

| 字段 | 内容 |
|---|---|
| 技术 ID／用户场景 | #15 Depth-Based Particle Collision。让已有 GPU 粒子 active set 的 update dispatch 消费**同帧、同相机、同视口**的受控不透明场景深度，在粒子穿透可见表面时做有界的位置修正与速度响应。首版默认关闭，不替代游戏物理，也不对 CPU 粒子做逐帧深度读回。 |
| 当前基础／差距 | #27 已有 `GpuParticleSystem`（particle/counter/active-index 三个 SSBO、原子活跃追加、间接 draw、reset/update/draw 三段）、`GpuParticleSettings/Emission`、`gpu-particle-indirect.comp`；#26 已给同一 owner 增加排序代。差距：update shader 没有深度输入、没有投影/厚度/恢复系数、没有碰撞响应、没有离屏/无效深度回退、没有 CPU 参考。本包**直接扩展 #27 owner**，不复制第二套粒子系统，不修改 #27 的 update shader。 |

| 生命周期 | 构造：校验 collision 边界；`enabled` 时链接 `gpu-particle-collision.comp`，任一资源失败逆序关闭已创建资源。`resized(newCapacity)` 沿用 sort+collision；`resized(newCapacity, sorting, collision)` 用于替换代；候选完整创建后由调用方发布并退役旧 owner。`reset()` 语义与 #27 相同（丢弃未提交发射、游标/seed 归零、下一帧逐槽清零）。深度纹理与 extent 可在每次 record 变化（例如 resize 后），owner 不持有它。`close()` 幂等，关闭后 `record/emit/settings/statistics/collisionSettings/reset/resized` 抛 `GlException`。 |

## 碰撞合同

1. **深度来源与帧对应**：只接受**单采样**深度纹理，且必须是当前帧、当前 `view`/`viewProjection`、
   当前深度视口同一份不透明深度。`sceneWidth/sceneHeight` 必须与纹理及调用方视口一致；调用方
   负责保证同帧，owner 不查询纹理尺寸、不做 GPU 同步。MSAA 原始深度（`sampler2DMS`）不在
   compute 路径采样，须由 Integrator 使用共享表面的单采样 `DEPTH` 视图或解析副本。
2. **只对不透明深度**：`opaqueDepthOnly` 必须为 `true`；构造期拒绝 `false`。透明表面、粒子自身
   或不完整深度不作为本版输入。碰撞不会把粒子拉出“墙后”，因为那需要另一侧表面信息。
3. **投影**：`clip = uViewProjection * vec4(world,1)`；`clip.w <= 1e-6`（眼后/眼点）→ 自由飞行；
   `uv` 不在 `[0,1)`（离屏）→ 自由飞行；`texelFetch` 深度 ≥ 1（clear/远平面）→ 无表面。
4. **表面重建**：`inverse(viewProjection)` 把 `(uv, depth)` 反投影为世界点；法线由相邻 texel 世界
   位置叉积并用相机方向定向；边界/无效/退化叉积回退为“朝向相机的法线”。
5. **有界厚度**：`penetration = dot(particleWorld - surfaceWorld, normal)`。只接受
   `penetration < 0 && -penetration <= thickness` 的“表面后方带宽内”命中。深于 thickness 的粒子
   视为在墙体另一侧，保持自由飞行（不拉回）。该带宽作用于屏幕空间最近可见表面平面，不是实体厚度。
6. **响应**：命中后先沿法线推到表面相机侧 `skin = max(1e-3, thickness * 1e-3)`；
   `vn = dot(v, normal)`，仅当 `vn < 0` 时
   `v' = (v - vn*normal) * (1 - friction) - normal * (restitution * vn)`。
   `restitution=1` 为弹性反弹，`0` 为法向归零的滑动；friction 独立缩放切向分量。
7. **有界搜索**：`maximumSearchSteps` 是每粒子最多深度**采样位置数**（中心 + 至多 `steps-1` 个
   固定黄金角环形 tap）；每个位置另取 4 个邻域 texel 重建法线。`searchRadiusPixels` 是这些 tap 的
   屏幕半径；超出 depth viewport 的 tap 直接跳过。默认 1 步、0 半径，只采样粒子自身 texel 及其
   法线邻域；搜索是薄几何/轮廓附近的回退，不是 ray march。
8. **采样模式**：`TEXEL_CENTRE` 点采样；`CONSERVATIVE_MIN_2X2` 取包含中心 texel 的 2×2 邻域最小
   深度（更靠近相机者优先），用于薄物体，最多 4 次 fetch。两者都走 `texelFetch`，不做线性过滤。
9. **无 CPU 同步**：不调用 `glGetTexImage`/`glReadPixels`/`glMapBuffer` 读深度或活跃计数，不根据
   GPU 计数决定 draw；所有决策在 update compute 内完成。
10. **禁用/回退的轨迹一致性**：disabled owner 使用未修改的 `gpu-particle-indirect.comp`，不设置
    任何碰撞 uniform，不链接碰撞 program。enabled owner 在 record 无深度（id ≤ 0）时同样使用该
    program。enabled 且有深度但未命中（全远、离屏、厚度外）时只允许粒子状态逐字节不变；GL 用例
    对此做 byte-for-byte 断言。

## 明确限制与未验证项

1. **屏幕空间/单表面**：只见当前相机可见的不透明深度；离屏、相机后方、clear/far 深度、
   被遮挡而不可见的几何都不参与碰撞。碰撞是“最近可见表面平面”近似，不是体积或精确形状。
2. **只对不透明深度**：透明表面、粒子自身、半透明排序后的深度不支持；
   `opaqueDepthOnly=false` 在构造期拒绝。
3. **单采样**：compute 路径只采样单采样深度纹理；MSAA 原始深度需 resolve 或使用共享表面的
   单采样视图。不承诺 MSAA 逐 sample 行为。
4. **无连续碰撞/复杂形状**：没有运动子步、射线/SDF/三角形求交、厚度方向双表面或凸包；深于
   thickness 的粒子视为墙后并保持自由飞行，因此不会处理“完全穿过薄墙”的另一侧。
5. **法线近似**：由相邻 texel 深度重建，轮廓/深度不连续/退化处回退为朝向相机法线；不对
   backface、薄板、多层透明做特殊处理。
6. **搜索是有界回退**：`maximumSearchSteps/searchRadiusPixels` 是固定环形 tap，不是 ray march；
   数值 oracle 只覆盖中心 texel 路径，搜索 tap 路径没有 GL 覆盖，保持 `NOT_EVALUATED`（仅有
   shader 源合同）。
7. **无 GPU 读回/统计**：不使用 `glGetTexImage`、`glReadPixels`、buffer map 或同步 fence 读深度
   或活跃计数；没有碰撞命中计数，统计仍只有录制请求量。
