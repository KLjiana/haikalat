## 技术卡

| 字段 | 内容 |
|---|---|
| 技术 ID／用户场景 | #13 折射；单层玻璃/护盾材质的折射率与厚度近似。首版不默认开启，不替代 #14 水面系统。 |
| 当前基础／差距 | 已有 `Material`、PBR 材质工厂、按 `BlendMode.ALPHA` 的透明排序、RenderGraph 共享颜色附件与体积雾透明 pass。缺少一个“先复制场景颜色、再绘制折射材质”的单层材质合同与有界参数。 |
| 首版范围 | 单层玻璃/护盾：可配置 IOR、世界空间厚度、粗糙透射（最多 4 tap）、透射权重、Fresnel 反射权重；采样玻璃 pass 之前已解析的场景颜色快照，按 IOR/厚度得到屏幕空间偏移。 |
| 不支持 | 多层玻璃互相折射、逐层厚度/深度、真实 BTDF、多次散射、彩色色散、焦散、屏幕外延长、正交相机的折射承诺、水下/水面（#11/#14 独立）。 |
| 模块与控制 | `core.material.RefractionSettings`（GL-free 值对象，公开 advanced）；`Material.refraction(...)` 保存材质合同；`render3d.pbr.PbrMaterials.createGlass(...)` 创建使用专用 fragment stage 的材质；`render3d.pbr.RefractionPass` 记录快照复制与玻璃绘制。没有新增 manager/factory/interface。默认 `RefractionSettings.disabled()`，不创建 pass、shader 或附件，普通 PBR/透明路径完全不变。 |
| 材质要求 | 玻璃材质强制 `BlendMode.ALPHA`、`MaterialModel.METALLIC_ROUGHNESS`，因此继续参与既有透明队列的远到近排序。管线在普通 forward/transparent/volume-reactive 流中跳过 refraction-enabled 材质，只在折射 pass 中绘制。 |
| 输入：颜色合同 | `RefractionPass` 之前的场景颜色：标准路径为 geometry pass 完成后的 `sceneColor`（不透明 + 非玻璃透明），体积雾路径为 volumetric transparent pass 完成后的 `sceneColor`。快照固定为单采样、linear HDR（LDR 时为 sRGB8 但采样解码到线性），由 RenderGraph 拥有；玻璃只采样该快照，绝不采样它正在写的 `sceneColor`。 |
| 输入：相机 | `CameraBlock` 的 projection/view（与 PBR 共用），相机世界位置由 pass 逐帧写入 `uCameraPosition`；不需要额外的 CPU 矩阵或深度读回。 |
| 输出 | 写共享 `sceneColor`（与 producer 相同颜色/样本数）与共享深度（GL_LEQUAL，depthMask=false），着色器输出 `alpha = 1`，用完整单层结果替换可见背景。 |
| 偏移公式 | `incident = normalize(worldPos - camera)`；`refracted = refract(incident, n, 1/ior)`；`refractedWorld = worldPos + refracted * thickness`；投影到 UV 后减去 `gl_FragCoord.xy / extent`。总 offset 长度超过 `0.25 UV` 或投影在相机后方时回退为“不偏移”。`n` 在法线朝向相机时翻转，避免退化朝向产生反向弯曲。 |
| 厚度衰减 | `tint = exp(-(1 - baseColor.rgb) * thickness * 1.5)`，与快照采样相乘；白色基色的玻璃不产生额外着色，深色/厚玻璃按 Beer-Lambert 风格近似加深。该式是艺术近似，不是真实吸收系数。 |
| 粗糙透射范围 | `roughness=0` 为单次采样；`roughness>0` 使用 4 个固定黄金角 tap，半径 `roughness * 0.02 UV`，以 `gl_FragCoord` 派生的确定性旋转，不引入时域噪声或历史。它是屏幕空间模糊近似，不模拟真实微表面 BTDF。 |
| Fresnel 反射 | 由 IOR 推导 `F0 = ((ior-1)/(ior+1))²`，`reflection = baseColor * Fresnel * uRefractionReflection`；首版不额外采样环境/BRDF，不参与直接光照或阴影。 |
| 透明排序 | 玻璃材质必须为 ALPHA；既有 `RenderQueueSorter` 按相机深度远到近绘制，所有玻璃对象在同一折射 pass 内按该顺序提交。overlap 的较近玻璃覆盖较远玻璃。 |
| 离屏/边界回退 | 折射后的 UV 只要任一轴离开 `[0,1]`，该次采样直接读取当前像素（pass-through）；不 clamp、不拉伸屏幕边缘。所有 tap 独立执行同一回退。 |
| 多层限制与反馈禁止 | 单次快照 + 单个玻璃 pass 意味着玻璃之间的重叠区域只显示最前一层，后层不会折射前层；这是显式合同而非缺陷。快照 pass `RefractionSourceCopy` 写独立纹理 `refractionSceneColor`，玻璃 pass `RefractionPass` 只读该纹理并写 `sceneColor`，图结构上满足“不采样正在写的附件”。 |
| 参数校验 | IOR ∈ `[1.0, 2.5]`；thickness ∈ `[0, 2]` 世界单位；roughness/transmission/reflection ∈ `[0, 1]`；全部要求有限。非法值在 `RefractionSettings` 构造期拒绝。 |
| 零/禁用路径 | `RefractionSettings.disabled()`（默认）不进入折射 pass；把玻璃材质换成普通 PBR/透明材质即可完全回到旧路径。`enabled=true` 且 transmission/reflection 为 0 时仍会绘制，但输出等于当前像素背景（精确 pass-through），用于验证零值合同。 |
| Pass 关系 | 标准：`GeometryPass → RefractionSourceCopy → RefractionPass → (MSAA HDR resolve) → 后续后处理`。体积雾：`… → VolumetricTransparentPass → RefractionSourceCopy → RefractionPass → 后处理`。后处理的 scene-color producer 在启用时改为 `RefractionPass`，LDR present/FXAA/TAA 也依赖实际 producer。 |
| 资源与失败 | 不新增独立 GPU owner：快照附件由 RenderGraph 创建/释放；玻璃 shader 与 PBR 一样由调用方拥有；`RefractionPass` 无 GL 资源。候选失败按既有 generation 清理；关闭世代后旧 pass 不执行。resize 走既有候选图重建。 |
| 装配期语义 | 是否存在玻璃材质在 `pipeline.build()` 时决定；运行期修改材质的 refraction 设置/队列成员需要重新 build。与 volumes 共享的颜色/深度附件由既有 graph 合同校验，不读回 GPU。 |
| 成本／回退 | 每次启用新增 1 个全屏快照 blit/resolve 与每个玻璃 draw；roughness>0 时每像素最多 4 次场景色采样。无历史、无 GPU 读回、无 `glFinish`。未做正式 GPU 测量，成本状态 `NOT_EVALUATED`；回退是禁用 refraction 或降低/关闭效应。 |
| 参考与许可 | 算法为项目自写 Snell + 屏幕投影近似；无第三方 shader 或资产。测试参考实现位于 `src/test`（不进入生产包）。shader 指纹见下。 |

## 已知限制与未验证项

1. **单层**：所有玻璃共享同一张折射前快照，玻璃之间不互相折射；相交/多层玻璃只显示最前层。没有逐层深度、厚度或吸收累积。
2. 没有基于场景深度的前景拒绝。若折射采样落在比玻璃更近的物体上，会显示该屏幕像素；这是屏幕空间折射的固有近似（#11 水面需要单独的深度拒绝合同）。
3. 首版反射只有 Fresnel 基色项，不采样 IBL、方向光高光或阴影；玻璃不参与透明阴影近似。base color 同时作为透射 tint，艺术控制与物理参数有意分离。
4. 粗糙透射是 4 tap 屏幕空间扩散，不是真实微表面 BTDF；强 roughness/高对比背景可能出现采样纹，且无时域抖动或降噪。
5. 正交相机/非透视投影没有专门支持；`uProjection` 的投影除法在正交下仍可工作，但没有验证或承诺。
6. MSAA 路径通过共享 multisample 颜色纹理与单采样快照 resolve 实现，体积雾路径复用其 transparent pass 后插入玻璃 pass；两者都**尚未在本工作包的真实 GL 用例中单独覆盖**（当前 GL 用例为 NONE AA、标准非体积路径）。
7. 折射设置与“场景是否含玻璃”是装配期拓扑输入；每帧切换玻璃材质需要重新 `build()`。没有逐帧 CPU/GPU 诊断计数或可调质量档。
8. 真实 GL 用例已编写但本工作包未执行时不能记 PASS；JVM 结果不能代替像素/管线证据。

## 交付说明

使用方式：用 `refraction-forward.frag` + `pbr-forward.vert` 创建 shader，调用 `PbrMaterials.createGlass(shader, properties, bindings, fallbacks, refractionSettings)` 创建玻璃材质；把材质加入 `Scene` 后正常 `build()/execute()`。材质为 ALPHA，正常参与透明队列排序；管线自动增加快照和折射 pass。未调用 `createGlass` 或使用默认设置时，行为与引入本功能前一致。
