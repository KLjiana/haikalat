## 技术卡

| 字段 | 内容 |
|---|---|
| 技术 ID／用户场景 | #20 SSR；为 PBR 金属/光滑表面提供屏幕空间内的锐利反射，替代仅由 IBL 预过滤环境给出的模糊反射。首版默认关闭。 |
| 当前基础／差距 | 已有共享表面深度/法线/运动通道、HDR 颜色链、GTAO、TAA、DOF/运动模糊与 PBR/IBL 前向着色。缺少逐像素材质粗糙度、屏幕空间反射 ray march、命中置信度与环境/IBL 回退。 |
| 首版范围 | 纯空间路径：每像素一条有界反射 ray，命中置信度，低于阈值或不可信时**不改变**输入颜色（前向 PBR 的 IBL 高光仍是环境回退）。不拥有历史、不做重投影/降噪（留给 #34），不做平面反射、探针或 GI。 |
| 输入 | HDR 颜色链中的 resolved 线性 HDR RGB（RGBA16F）；共享**单采样**设备深度（`SCENE_DEPTH`）、世界空间几何法线（`SCENE_NORMAL`，signed oct）与新增加的材质粗糙度（`SCENE_ROUGHNESS`，R8）；借用的 PBR 预过滤环境 cubemap 及其 intensity/rotation/maxLod；帧相机矩阵（inverse raster projection、inverse view、view、stable view-projection）。 |
| 输出 | 全尺寸 RGBA16F `ssrColor`；`Fresnel × confidence × (screenRadiance − environmentRadiance)` 叠加到输入颜色。无命中像素写入原始颜色（精确），因此禁用或全拒绝时与基线一致。 |
| 模块与控制 | `subsystems.postprocess.ssr.SsrPass`（program + `ScreenQuad`）；`SsrSettings`/`SsrEnvironmentSource` 为 postprocess 域 advanced 值/合同；`PbrSsrEnvironment` 是 render3d pipeline 的包内适配器；`PbrMaterialBinder` 新增借用绑定入口。`PostProcessSettings` 增加 `ssr` 组件。不新增 manager/factory/chain。 |
| 坐标与深度 | UV 为 OpenGL 栅格 UV（原点左下，与 SceneColor 一致）；view space 为相机原点、-Z 前向。像素深度经 `inverseJitteredProjection` 还原到 view 空间，再经 `inverseView` 还原世界位置。反射方向在世界空间计算；march 沿世界距离前进，每步用 **stable** view-projection 投到屏幕，射线深度用 `uView` 与当前像素的 view 深度比较。 |
| MSAA/解析 | 只消费共享表面的单采样视图：MSAA 时由 `SceneSurfaceResolvePass` 按最近深度样本解析 depth/normal/roughness；非 MSAA 时直接借用光栅附件。不读多采样附件，也不假设未解析的深度。 |
| 厚度与遮挡 | 每步取 `rayViewDepth − sceneViewDepth`：≤ `thickness` 为命中；更大值视为被厚物体遮挡，立即结束且不贡献反射。深度/法线/粗糙度使用 `texelFetch` 点采样，避免轮廓深度被线性过滤后制造假命中；颜色命中点可用线性过滤。 |
| 命中置信度 | `depthConfidence(1 − sep/thickness) × edgeConfidence(smoothstep(edgeFadePixels)) × facing(−dot(hitNormal, ray)) × grazing(smoothstep(0.05,0.25,nDotV)) × distanceConfidence(1 − smoothstep(0.75,1,along))`。低置信度经 `smoothstep(minimumConfidence,1,confidence)` 软阈值；低于下限写回输入颜色。 |
| 环境/IBL 回退 | 粗糙度 > `roughnessCutoff`、背景、背面、掠射、离屏、超出 `maxDistance`、超出厚度窗口或低于置信度下限时，pass 输出与输入**完全相同**；前向 PBR 已加入的 IBL 高光即环境回退。屏幕命中会用 `rotateEnvironment(reflected)` 与粗糙度 mip 的预过滤环境对比，按 `Fresnel(f0=0.04)` 替换该环境贡献，避免再叠加一份反射能量。 |
| 资源与生命周期 | `SsrPass` 只拥有 program 与 quad，加入 `PostProcessPipeline.owned`；无历史、无 GPU 读回、无 `glFinish`。环境 cubemap、深度/法线/粗糙度均为借用；关闭或禁用时不创建 program/Pass/target。候选代可借用相同设置的 `SsrPass`；`transferResourcesTo` 沿用既有所有权转交。 |
| 成本／回退 | 每帧 1 次全屏 draw、1 张全尺寸 RGBA16F 附件；每像素 ≤ `maxSteps`（≤64）次 march + 4 次二分细化，纹理读取为 4 张单采样表面 + 每次命中 1 次环境采样。未做 GPU 计时，性能状态 `NOT_EVALUATED`。回退为关闭 SSR（精确基线）或保留更低的步数/距离上限。 |
| 验证范围 | JVM：`SsrSettingsTest`（边界/禁用 no-op）、`SsrRayReferenceTest`（独立 CPU ray/step/置信度参考的手算用例）、`SsrContractTest`（表面通道/格式/Pass 名与 shader 有界结构）；`PipelineTopologyTest` 与 `RenderFeatureControlTest` 的直接消费者断言。真实 GL：`SsrPassGlTest` 在解析式地板+发光墙场景上断言反射方向/区域、边界、粗糙度与短距离回退和禁用基线；**待 GPU slot 执行**。 |

## 相关参数

| 参数 | 默认 | 校验 |
|---|---|---|
| `enabled` | false | 关闭时不创建任何资源或 Pass |
| `maxDistanceMetres` | 12.0 | [0.05, 1000] |
| `maxSteps` | 32 | [1, 64]，与 shader `SSR_MAX_STEPS` 一致 |
| `thicknessMetres` | 0.5 | [0.001, maxDistance]；builder 自动收敛到 maxDistance |
| `roughnessCutoff` | 0.4 | [0, 1] |
| `minimumConfidence` | 0.15 | [0, 0.95]，保证 `smoothstep` 非退化 |
| `strength` | 0.9 | (0, 1] |
| `edgeFadePixels` | 24 | [0, 256] |

`worldStepMetres() = maxDistance / maxSteps`；`resolvesStepsWithinThickness()` 公开步长是否能
解析厚度窗口，便于宿主报告空间路径的已知近似。

## 通道扩展

`SceneBufferChannel.ROUGHNESS` 追加在现有通道之后（不改变既有布局的 color slot）；格式 R8，
名称 `sceneRoughness` / `sceneRoughnessMS`，producer 为 `SceneSurfacePass` /
`SceneSurfaceResolvePass`。只有请求该通道的布局才分配存储。首版粗糙度来自 PBR 材质的标量
`uRoughnessFactor`；非 PBR 材质写 1（完全粗糙，不参与反射），metallic-roughness 贴图的逐 texel
变化尚未写入该通道。

## Pass 顺序与配置拒绝

HDR 链顺序：`Geometry → [HdrResolve] → [Fog] → [VfxComposite] → [ScreenDistortion] → [TAA] →
SsrPass → [DepthOfField] → [MotionBlur] → AutoExposure/Bloom → ToneMapping → ...`。SSR 在时域
resolve 之后、景深/曝光/Bloom/tone mapping 之前读取线性 HDR，输出仍为线性 HDR。

拒绝路径：`PostProcessPipeline.assemble` 对 `ssr.active() && !hdr` 抛
`IllegalArgumentException("screen-space reflections require HDR tone mapping")`，对缺少
`SsrEnvironmentSource` 抛 `... require a bound PBR environment`；`RenderFeaturePolicy` 在统一
请求入口拒绝非 HDR 或没有 metallic-roughness 材质的请求；`PipelineFeaturePolicy` 对请求了
ROUGHNESS 却没有 PBR 材质的拓扑拒绝。禁用时 `PostProcessPipeline.passNamesFor` 与执行顺序完全
不变。

## 明确限制与未验证项

1. 仅空间路径：单 ray、固定步数、无 jitter/随机采样、无时域累积；粗糙表面只按
   `roughnessCutoff` 拒绝并把命中色向环境色混合，不提供随机锥采样或降噪。#34 之后可绑定该信号。
2. 粗糙度只来自 PBR 标量 `uRoughnessFactor`，不含 metallic-roughness 贴图逐 texel 变化；非 PBR
   表面视为完全粗糙。法线使用共享**几何**法线，不含 normal map 后的着色法线（与 v0.24.1
   协议一致）。
3. 置信度组合是首版经验公式，未与真实高样本参考做数值回归；深度/法线点采样避免轮廓假命中，
   但极薄几何、屏幕边缘和贴近相机的掠射路径仍可能出现 false positive/false negative。
4. 能量近似：用 `f0=0.04` 的 Fresnel 替换前向 IBL 高光，金属（高 f0）反射被低估；没有 BRDF LUT
   与逐材质 f0，因此不是物理正确的镜面能量重分配。
5. 真实 GL 未执行：shader 编译、像素断言与 `glGetError` 尚无当前设备证据；在 slot 执行前不得
   把本文当作 GL PASS 或发布就绪依据。
6. 未测性能、显存峰值或多硬件；`NOT_EVALUATED` 保留。每帧成本仅由步数、距离和全屏附件有界，
   不是实测毫秒数。
