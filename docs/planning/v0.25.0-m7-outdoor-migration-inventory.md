迁移顺序：

1. 保存旧单太阳 deterministic reference 与原始无雾 60/240/420 输出。需要继续运行的旧算法移入 demo/test reference；发行资源不保留第二套算法。
2. 所有正式 Demo 和面板改为 `VolumetricFogSettings`/`LightVolumeHints`。保留天空、方向灯、曝光、IBL 及窗口/序列合同。
3. `OutdoorEnvironmentSettings` 和 `VisualSettings` 去掉旧太阳算法入口；同步 allowlist、schema 2、预设、指南和当前能力矩阵。
4. 删除生产 Outdoor builder/resources/frame-state 和四个 pass/shader，收敛 PostProcess builder、generation、resize 与成功/失败转发；测试逐项迁移，保留失败恢复与唯一资源所有权覆盖。
5. 重新冻结候选；check/API/assets、适用 GL/质量/正式性能、九组无雾 HDR 回归及全项目 releaseReadiness 均取新指纹证据。

独立 `FogSettings/FogPass` 的后处理用例先检索后保留；新正式体积路径与其互斥。
`subsystems/postprocess/VolumetricLightPass` 与 `VolumetricLightSettings` 属于另一套 advanced 实验，本迁移不删除它们。
旧版发布报告保留原文，不能将历史 Outdoor 批量替换为 Froxel。
