## 技术卡

| 字段 | 内容 |
|---|---|
| 技术 ID／用户场景 | #17 各向异性高光；拉丝金属、拉丝塑料、头发/丝绸类条状高光的首版生产输入。默认关闭，不引入第二种材质系统或独立 Pass。 |
| 当前基础／差距 | 已有唯一 metallic-roughness PBR 路径（`PbrMaterials` → `Material` → `pbr-forward.frag`）、按粗糙度取 mip 的预过滤 IBL specular 与 BRDF LUT。缺少“在同一基色层上沿切线方向拉长 GGX 高光”的有界材质输入，也缺少缺失/退化切线时的明确回退。 |
| 首版范围 | 单层均匀各向异性：强度 `[0,1]`、切线空间旋转（弧度）、Burley 各向异性 GGX D 项与对应 Smith 可见性 V 项；直接光逐灯生效；IBL 使用有界拉伸近似。强度 0 精确走原有各向同性路径。可选与清漆同时启用，但清漆层保持各向同性。 |
| 不支持输入 | 各向异性方向贴图/强度贴图、逐像素切线旋转、`KHR_materials_anisotropy` glTF 加载、双轴独立贴图、真正的各向异性预过滤 cubemap/BRDF LUT、清漆层的各向异性、多次散射/薄膜补偿、缺失切线时的切线生成（只做确定性回退，不生成 UV 切线）。 |
| 模块与控制 | `core.material.AnisotropicSettings`（GL-free 不可变 record，公开 advanced）；`Material.anisotropic(...)` / `Material.anisotropic()`（默认 `disabled()`）；`pbr.PbrMaterials.createWithAnisotropy(...)` 与末位带 `AnisotropicSettings` 的 `createWithBindings(...)` 重载；唯一生产消费端 `pbr-forward.frag`。没有新增 manager、factory、Pass、纹理或 GPU owner。 |
| 材质默认 | 所有既有 `PbrMaterials` 工厂（含 glTF 路径 `GltfSceneAsset`）继续以 `AnisotropicSettings.disabled()` 构建：`uAnisotropicEnabled = 0`、强度/旋转 0。既有材质模板、绘制顺序与像素路径不变；GL 用例设计为验证强度 0 与未启用帧逐像素等价（尚未运行）。 |
| 输入格式与空间 | `strength`：有限 `[0,1]`，0 = 各向同性；`rotation`：有限弧度，任意有限值均接受（shader 用 `sin/cos`，方向按 2π 周期）。两者是**材质值**，不是 `RenderFeatureSettings` 拓扑开关。旋转 0 使拉伸轴对齐网格切线 `vTangent`；正旋转在切平面内向 handedness 修正后的副切线旋转：`T' = T·cosθ + B·sinθ`，`B' = B·cosθ − T·sinθ`。 |
| 切线帧 | `pbr-forward.vert` 输出 `vTangent`（已对几何法线正交化）与 `vTangentHandedness = aTangent.w · sign(det(model))`。frag 先把切线重新投影到**着色法线**（允许基础法线贴图扰动），再以 `B = normalize(cross(N, T)) · sign(handedness)` 重建正交帧。镜像 UV/负行列式由 handedness 取负直接翻转副切线，不产生左手帧。 |
| 退化回退 | `tangent` 缺失、为零、NaN/Inf 或与法线平行时，用与 `TangentGenerator` 退化分支同构的确定性轴：`reference = |N.z| < 0.999 ? (0,0,1) : (0,1,0)`，`T = normalize(cross(reference, N))`，再重建 `B`。主分支先用 `isnan(uAnisotropicRotation) || isinf(uAnisotropicRotation)` 显式失败关闭到各向同性，不进入三角函数/切帧；其余退化由 `!(dot > ε)` 比较处理，旋转后长度检查失败也失败关闭。显式有限守卫、帧内检查与失败时清零切线 out 参数是三道防线；清零可避免编译器推测执行另一 ternary 分支时把 NaN 带进已选中的各向同性结果。回退仍是有效各向异性帧，不会静默禁用效果，也不会无界归一化。**前提**：`uEnableNormalMap = 0` 或 `vTangent` 有限；若法线贴图开启且 `vTangent` 为 NaN，基础法线分支会先产生 NaN `n`，本回退无法恢复（既有路径缺陷，见限制 5）。 |
| 直接光 BRDF | 对每个灯：`h = normalize(v+l)`，Fresnel 继续用现有 `fresnelSchlick`。各向异性 alpha：`α = max(roughness², 0.002025)`，`at = max(α(1+strength), 0.002025)`，`ab = max(α(1−strength), 0.002025)`（`ANISOTROPIC_MIN_ALPHA = 0.045²`）。Burley D：`a2 = at·ab`，`v = (ab·T·h, at·B·h, a2·N·h)`，`D = a2·(a2/|v|²)²/π`。Smith 可见性（已含 `1/(4·NoV·NoL)`）：`V = 0.5 / (NoL·|(at·T·v, ab·B·v, NoV)| + NoV·|(at·T·l, ab·B·l, NoL)|)`；`specular = D·V·F`。漫反射、Fresnel 与清漆分割不变。 |
| IBL 近似（非精确） | 反射向量在切平面内按各向异性方向拉伸/压缩后重新归一化：`local.x *= 1 + 0.5·strength`，`local.y *= 1 − 0.35·strength`，再按现有环境旋转采样**同一个** `uPrefilteredMap`；mip 粗糙度用 `clamp(roughness·(1+0.5·strength), 0, 1)`。BRDF LUT 与 Fresnel 仍用各向同性形式。这是有界能量近似，**不是**精确各向异性 IBL：没有各向异性预过滤、没有拉伸后的能量重归一化，也没有第二套环境资源。 |
| 零值/禁用还原 | `uAnisotropicEnabled = 0` 或 `uAnisotropicStrength = 0` 时不构造切帧、不进入任何各向异性分支：直接光保持原 `directBrdf` 调用；IBL 保持原 `reflection = rotateEnvironment(reflect(-v,n))` 与 `roughness * uPrefilterMaxLod` 采样表达式；清漆、AO/GTAO、环境强度、发光和输出格式不变。所有新增分支都是正向 guard，没有 `uAnisotropicEnabled == 0` 特例。 |
| 参数校验 | `AnisotropicSettings` 构造期拒绝 `strength` 非有限或越界、`rotation` 非有限，抛 `IllegalArgumentException`；`Material.Builder.anisotropic(null)` 抛 NPE。非法值无法进入 builder 或模板。`MaterialInstance` 直接注入 NaN 旋转属于调试/越权路径，shader 会失败关闭回各向同性（GL 用例覆盖）。 |
| Pass 顺序 | 不新增 Pass。每帧仍只有既有 PBR forward：`main` 解基础色/粗糙度/金属度 → 基础法线贴图 → 清漆 setup → cluster debug 早退 → 一次性构造各向异性帧 → 逐方向光/局部灯累加（基色层各向异性 specular）→ 清漆凸组合 → 漫反射 IBL → 各向异性 specular IBL → 清漆 IBL 分割 → GTAO/AO/环境强度 → emissive/输出。强度 0 时该顺序退化为原顺序。 |
| GPU owner／资源 | 不新增 GPU owner。各向异性只是材质模板 uniform（`uAnisotropicEnabled`、`uAnisotropicStrength`、`uAnisotropicRotation`）与同一 fragment program 内的计算；没有新纹理、FBO、历史或回读。准备/提交即既有 `Material.Builder` 候选装配；退役即关闭既有 Material/shader，无新增生命周期。失败：非法设置装配期拒绝；切帧/旋转退化则失败关闭，不保留半启用状态。 |
| 成本／回退／质量档 | 启用时每片元一次切帧构造；每灯多一次各向异性 D/V 求值（与各向同性 D/G 同量级，多几次 `length`）；IBL 多一次归一化但采样数不变。默认关闭零成本。回退为 strength 降低/关闭。**不新增引擎质量档枚举**；建议材质预设 Low 0.35、Medium 0.65、High 0.9–1.0（同一分支成本，不宣称性能分档）。未做正式 GPU 成本测量，成本状态 `NOT_EVALUATED`。 |
| 参考与许可 | 算法为本项目自写 Burley anisotropic GGX + Smith 可见性（与现有 GGX/Smith/Schlick 形式同源），无第三方 shader 或资产。独立 double 参考位于 `src/test` 的 `AnisotropicReferenceMath`，不进入生产包，也不调用生产 helper。 |

## 独立 oracle 与验证范围

### 独立参考

`src/test/java/.../subsystems/render3d/pbr/AnisotropicReferenceMath.java` 是测试侧
double 精度独立实现：切帧（含缺失/退化切线与 handedness）、`at/ab` 权重、Burley
D 项、Smith V 项、Schlick Fresnel 与完整直接光组合。它手工重写公式，不调用
`AnisotropicSettings`、`PbrMaterials` 或 shader 源；固定样本期望值由独立推导得到，
`AnisotropicReferenceMathTest` 锁定，GL 用例再把它作为逐像素 oracle。

固定可复算样本（roughness 0.5、strength 0.5、`n=(0,0,1)`、`t=(1,0,0)`、
`b=(0,1,0)`）：

- `at = 0.375`、`ab = 0.125`；
- `D(h=n) = 6.7906109052542005`（即 `1/(π·at·ab)`）；
- `D(h=30° toward T) = 1.062749877214038`；
- `D(h=30° toward B) = 0.024203558584109434`；
- `V(30° toward T) = 0.4561161523465056`；
- `F(30°) = 0.04004143654313937`；
- 直接光 RGB（baseColor 0.5/0.4/0.3、无金属、白辐射度）分别为
  `0.08609586588758927 / 0.07081765083383386 / 0.05553943578007843`。

### 真实 GL（首轮 FAILED，修复待复跑；本包未运行 GPU）

类：`com.kaleblangley.haikalat.integration.AnisotropicGlTest`，单用例
`anisotropicDirectMatchesTheOracleAndRotationMovesTheHighlight`，运行命令
`.\gradlew.bat glSmoke --tests "*AnisotropicGlTest"`（由 Orchestrator 串行执行）。
覆盖：

1. 直接光逐像素对照独立 double oracle：各向同性基线、strength 0、strength 0.8
   旋转 0 与 π/2；要求各变体像素变化数达到阈值。
2. 强度 0 与未启用各向异性逐像素等价（1e-6 容差）；清除 overrides 后与初始帧
   逐字节一致。
3. 旋转方向：对高光差异图计算亮度加权二阶矩（按权重和归一化），rotation 0
   必须在切向 X 展宽、π/2 必须在副切向 Y 展宽，防止“换了均匀权重也算旋转”的
   空洞通过；参与像素门槛使用 `luminance > 1e-4` 的**像素计数**（>16），与曝光/
   绝对能量无关，不能再用绝对亮度和代替。夹具主光方向保证镜面反射点落在 quad 内，
   否则正差异区域为空、方向性断言无法执行（见下方真实执行记录）。
4. 退化切线：canonical 布局但 TANGENT 为零的网格 + 关闭基础法线贴图（完全缺失
   TANGENT 的 PBR 材质网格会被既有 `RenderPipeline.build()` 拒绝，已有
   `PbrEnvironmentGlTest` 覆盖）；逐像素对照 `tangent=null` 的确定性回退帧；
   断言无 NaN/Inf、亮度有界、明显区别于各向同性帧；注入 NaN 旋转后由主分支
   `isnan/isinf` 显式守卫失败关闭，必须与各向同性帧一致（不再只依赖 `cos/sin`
   之后的长度比较）。
5. IBL：黑基色 + `uRoughnessFactor = 0.2` 隔离出的纯 specular IBL，环境使用
   test-only 自写 `src/test/resources/environments/pbr/anisotropic-stripes.hdr`
   （64×32 RGBE、8 条方位条纹 + 地平线带、确定性、无第三方来源；不在
   `assets.tsv`，因为 release `assetManifestGuard` 只扫描 `src/main/resources`
   与 `src/demo/resources`），并将环境强度设为 2.0。检查有界、与各向同性 lookup
   有可见差异、随旋转变化；强度 0 精确回到各向同性 IBL。原共享
   `studio-small.hdr` 为 4×2、预过滤后近似常量，导致该项 0 像素差异，已确认是
   fixture 不敏感而非 shader 分支缺失（直接光阶段同一 `anisotropicStrength` 已
   通过 oracle；IBL 阶段黑基色下 specular 能量 >1e-3 且 `uEnableSpecularIbl`

## 需要 Integrator 接线/同步的点

1. `RenderPipeline`、`RenderFeaturesControl`、`RenderFeaturePolicy` 与
   `PipelineFeaturePolicy` **无需修改**：各向异性是材质值，不是帧拓扑开关。
2. 既有 `PbrMaterials` 调用方无需改动（默认 `disabled()`）；需要各向异性的调用方使用
   `PbrMaterials.createWithAnisotropy(...)`，或在完整 `createWithBindings(...)` 的末位

## 已知限制

1. IBL 是拉伸反射方向 + mip 加宽的近似，不是精确各向异性环境预过滤；能量未严格归一化。
2. 不支持各向异性方向/强度贴图和逐像素旋转；强度与旋转是整材质均匀值。
3. 不加载 `KHR_materials_anisotropy`；现有 glTF 严格扩展策略不变，资产中的该扩展不会
   自动变成 `AnisotropicSettings`。
4. 缺失切线只做确定性回退，不生成 UV 切线；PBR 材质网格在管线装配期仍要求
   TANGENT 语义（既有合同），完全缺失 TANGENT 会在 build 期被拒绝，shader 回退
   主要覆盖退化/零/非有限切线以及自定义 raw 路径。镜像/负行列式已按 handedness
   处理，但退化回退帧的切线轴由法线决定，可能与该网格 UV 方向不同（有界近似）。
5. **“退化切线可回退”的前提**：当 `uEnableNormalMap != 0` 且 `vTangent` 为 NaN 时，
   基础法线贴图分支会先用 `normalize(vTangent)` 构造 TBN，`n` 在进入各向异性切帧
   之前已变成 NaN，anisotropic fallback 无法恢复。该缺陷属于既有基础法线贴图路径，
   不是本 diff 引入；当前 GL 退化夹具因此显式关闭基础法线贴图。生产使用需保证
   TANGENT 有效，或在退化网格上关闭基础法线贴图。
6. 清漆层保持各向同性；各向异性只作用于基色 metallic-roughness 的 specular 项。
7. 逐帧切换需要 `MaterialInstance` 覆盖；替换场景材质仍需重新 `build()`。
8. 未做正式 GPU 成本测量，也没有各向异性专属质量档或诊断计数；建议参数分档不是
   引擎质量档。
9. 未覆盖 MSAA、体积雾变体、glTF 扩展、与探针/SSR 的组合；这些必须由 Integrator
   的组合矩阵单独验证。
