日期：2026-11-11。状态：生产实现与 JVM 合同完成；真实 GL 用例已编写，但本 Worker 被禁止运行任何 GPU 测试，因此 GL 结果为 **NOT_EVALUATED**。对应 46 项路线图 #29 与执行计划 S2；执行计划见 [multi-agent full delivery](haikalat-multi-agent-full-delivery.md)，方向见 [realtime rendering roadmap](realtime-rendering-roadmap.md)。

## 适用范围

- 支持：球面行星上的 Rayleigh/Mie **单次散射**天空；以海平面散射系数、指数密度标高、行星半径和大气厚度描述介质；太阳方向（沿用场景方向光“光传播方向”约定）、太阳辐照度、线性曝光、太阳角半径与显示用太阳圆盘强度；固定观测高度（默认地面，可到大气层顶）下的天顶/地平线/任意上半球方向颜色。
- 支持：透射率 LUT（透射率 = 从大气内一点沿太阳方向到大气顶的指数光学深度）与太阳相对 sky-view LUT；两者都有明确上限，默认 `256x64` 与 `32x32`、采样数 `64/64`；默认质量档见下表。
- 支持：HDR 颜色输出（RGBA16F 目标）、深度测试/写入关闭、无混合；与现有风格化天空/IBL 背景的显式替换关系；LUT 重建、关闭释放与构造失败回滚。
- 不支持：多次散射、臭氧/其它吸收气体、天气/云、地面反照率与地形遮挡、海平面折射/日落畸变、光谱渲染、太阳临边昏暗、时域抖动/降噪、按像素自适应采样、行星自转/世界坐标平移视差、从大气生成 IBL、与现有体积雾/距离雾的解析耦合。
- 不支持：观测高度超过大气厚度、非球面行星、Mie 相函数以外的气溶胶模型、任意方向太阳的 `mu <= 0` 透射率（本版把太阳位于当地水平面及以下视为被行星遮挡）。
- 明确拒绝：非有限或越界的半径/厚度/系数/标高/太阳强度/曝光/角半径/圆盘强度、非 8 倍数的 LUT 尺寸、越界采样数、零/非有限太阳方向；构造期抛 `IllegalArgumentException`，不做静默夹取。

## 模型、单位与方程

设行星半径 `Rg`（m）、大气顶 `Rt = Rg + A`、观测高度 `h`、观测半径 `r0 = Rg + h`。密度：

```text
rho_R(x) = exp(-(r(x) - Rg) / H_R)
rho_M(x) = exp(-(r(x) - Rg) / H_M)
```

透射率：

```text
T(r, mu) = exp(-(beta_R * ∫rho_R ds + (beta_M + beta_Ma) * ∫rho_M ds))
```

单次散射辐亮度（`W / (m^2 sr)`）：

```text
L = I_sun * ∫ [ beta_R * rho_R * p_R(theta) + beta_M * rho_M * p_M(theta) ]
             * T_view(s) * T_sun(x(s)) ds
p_R(theta) = 3/(16*pi) * (1 + cos^2 theta)
p_M(theta) = (1 - g^2) / (4*pi * (1 + g^2 - 2g cos theta)^(3/2))   // Henyey-Greenstein
```

- `beta_R` 为海平面 Rayleigh 体积散射系数（每米，RGB 三通道）；`beta_M`/`beta_Ma` 为 Mie 散射/吸收系数（每米，标量）；`H_R`/`H_M` 为标高（米）；`g` 为 Mie 各向异性。
- `I_sun` 为大气顶太阳辐照度（`W/m^2`），默认 `1361`；`exposure` 为线性显示增益，默认 `0.02`，在写 HDR 目标前乘到辐亮度上。最终值仍是 HDR 线性值，后续 tone mapping/自动曝光由现有后处理负责；本 pass 不替代它们。
- 太阳方向 `sunDirection` 是**光传播方向**（从太阳指向场景），太阳位于 `-sunDirection`；太阳高度 `asin(-sunDirection.y)`、方位 `atan2(-x, -z)`。与 `SceneLight` 方向光及 `StylizedSkySettings` 约定一致。
- **着色器精度**：GLSL 不使用 double。所有几何量按 `Rg` 归一化（表面为 1，大气顶为 `Rt/Rg`），散射系数预乘 `Rg`；这样 6.4e6 m 量级的平方不会在 float 中灾难性抵消。Java 参考保持米制 double。

## LUT、空间与采样

| 资源 | 格式 | 参数化 | 默认 | 说明 |
|---|---|---|---|---|
| `transmittanceLut` | RGBA16F，`256x64`（LOW `128x32`，HIGH `512x128`） | `x = sqrt((r - Rg) / A)`，`y = mu ∈ [0,1]` | 64 采样 | 只覆盖上半球；`mu <= 0` 在采样时返回 0；`x^2` 让近地面获得更多行 |
| `skyViewLut` | RGBA16F，`32x32`（LOW `16x16`，HIGH `64x64`） | `x = theta / (pi/2)`，`y = relativeAzimuth / (2*pi) + 0.5` | 64 采样 | 局部坐标 +Y 天顶、+Z 太阳方位；片元按世界方向与太阳相对方位重映射 |
| 最终天空 | 调用方 HDR 目标（建议 RGBA16F） | 全屏三角形对 | — | 输出 `L * exposure`，alpha=1；在 `60000` 处钳制以保持 half-float 有限 |

- 两个 LUT 的尺寸都限制为 8 的倍数：透射率 `[8,1024]`、sky-view `[8,512]`；采样数分别 `[4,256]` 与 `[4,128]`。越界在 settings 构造期拒绝，dispatch 组数不会出现越界写入。
- 采样分布使用 `s = sMax * f^2`、`ds = 2*sMax*f/N`（`f=(i+0.5)/N`），把样本集中到密度最高的观测端；相对均匀采样，地平线长路径的误差从显著降低到约 0.1%（透射率 LUT）。
- `skyViewLut` 只覆盖 `theta ∈ [0, pi/2]`。片元对 `theta > pi/2` 钳到地平线 texel（地形应覆盖这些像素）；这是本版限制，不是完整的下半球介质。
- 太阳圆盘是 LUT 之外的**有界显示项**：`sunDiscIntensity * (1 - smoothstep(0.6r, r, acos(dot(view, sun))))`，在太阳低于当地水平面时淡出；不是物理太阳辐亮度，不参与散射积分。

## Pass 顺序、目标与真实消费者

- 本包交付 `AtmosphereSkyPass`（背景生产者），记录顺序固定为：透射率 LUT compute → write/read barrier → sky-view LUT compute → write/read barrier → 全屏天空 draw。
- 它是**背景 Pass**：应在深度清空后、opaque/transparent 几何前记录；不写深度、不做深度测试、不混合、不读场景颜色/深度；目标由调用方绑定，viewport 由调用方设置。目标建议 RGBA16F 线性 HDR；Pass 内部关闭 framebuffer sRGB。
- 每帧两个 LUT 都重新计算（默认约 111 万次积分步），避免太阳/观测高度移动后的陈旧表；小型表使这比维护脏标记/历史更简单且可预测。`rebuild(settings)` 只处理 LUT 尺寸变化。
- 真实消费者接线点（**本 Worker 不修改 `RenderPipeline`**）：
  1. `PipelineGeneration` 增加 `AtmosphereSkyPass atmosphereSky` 字段与 getter，在 `assembleEnvironment` 中按天空模式创建/借用；在 generation 退役/关闭列表中与 `stylizedSky` 同等释放。
  2. `RenderPipeline.RenderFrameState.renderBackground` 的分支优先级改为 `atmosphereSky > stylizedSky > environmentBackground`；三者互斥，绝不叠加。
  3. `synchronizeOutdoorSun` 在大气模式下用同一 `AtmosphereSettings.sunDirection()` 驱动方向光，保证天空与直射光一致。
  4. 观测高度：从场景/相机配置取“高于行星表面”的米制高度并作为 `record(..., observerAltitudeMeters, ...)` 参数；Pass 不使用相机世界坐标的平移。
  5. 窗口 resize 不需要重建 LUT；只有质量档/LUT 尺寸变化时在帧边界调用 `rebuild`，失败则不发布新设置。
  6. 若现有 `OutdoorEnvironmentSettings` 扩展天空模式，应显式拒绝“stylized + atmosphere 同时选中”；不要用两个非空值隐式判断。`EnvironmentBackgroundRenderer` 在大气模式下不得再绘制 IBL 背景。
- 雾边界：本 pass 只生产无限远天空背景，不按场景深度做空气透视。距离雾/体积雾保持现有独立介质；不得把同一 Rayleigh/Mie 系数再加进 `FogMediumSettings` 或体积雾，否则会重复积分。若未来要“大气空气透视”，需单独技术卡并明确与体积雾的去重。

## GPU owner、生命周期与失败

- Owner：Pass 独占 3 个 `ShaderProgram`、1 个 `ScreenQuad`（VAO/VBO）、2 个 RGBA16F LUT 纹理；借用调用方 framebuffer/viewport 与矩阵。所有创建/重建/关闭都在当前 GPU owner 线程和 current context 内执行。
- 构造：先编译三个程序、创建 quad、创建两个 LUT；任一步失败按逆序关闭所有候选并重新抛出，不发布半成品。
- 每帧：`record` 先校验打开状态、矩阵有限、观测高度范围、LUT 尺寸与 pass 当前存储一致；任何拒绝发生在记录 GPU 命令之前。矩阵/太阳/光学参数只是 uniform，不重建纹理。
- 重建：`rebuild(settings)` 在尺寸变化时先完整创建候选纹理，成功后才交换并关闭旧纹理；创建失败关闭候选、旧活动 pair 与尺寸保持不变。旧纹理退役失败时新 pair 保持活动并报告异常（不伪报回滚）。尺寸不变时是 no-op。
- 关闭：幂等；依次释放 LUT、quad、程序，聚合异常；关闭后 `record` 抛 `GlException`。
- 不拥有宿主附件/IBL/命令 recorder；不读回 GPU；不调用 `glFinish`/同步等待。
- 限制：`rebuild` 必须在帧边界、旧命令缓冲执行完之后调用；若在已记录但未执行的帧中重建，旧纹理关闭会使该帧执行失败。这是调用方顺序合同，不是自动重试。

## 已知限制

1. 只有单次散射；无多次散射、臭氧/其它吸收、天气、云、地面反照率/地形遮挡。地平线下沉只作为几何参考，sky-view LUT 按当地水平面截断。
2. 观测者模型是“固定高度 + 局部 Y 向上”；不做相机世界平移的行星视差，不处理非 Y 向上的行星坐标系。
3. `mu_sun <= 0` 被视为太阳被行星遮挡，忽略高海拔地平线下沉；twilight 仅以太阳高于当地水平面的部分近似。
4. sky-view LUT 默认 `32x32`，高频 Mie 前向峰值与地平线细节被低通；未做抖动/时域重建。片元在地平线处钳到最后一个 texel（约 88.6°），不是精确 90°。
5. 太阳圆盘是显示项，不是物理太阳辐亮度；没有临边昏暗、色温或大气折射。
6. 不生成 IBL/环境贴图；使用大气天空时仍需单独提供 IBL 来源。风格化 IBL 不再代表大气天空。
7. 与雾的边界是硬边界：不做空气透视；距离雾/体积雾必须保持为独立介质，禁止重复积分。
8. LUT 重建的“退役失败保留新 pair”路径可代码审查，但没有故障注入 GL 用例；不能声称已实测所有失败分支。
9. 未做正式性能/显存测量；质量档数值是配置上限，不是性能承诺。
