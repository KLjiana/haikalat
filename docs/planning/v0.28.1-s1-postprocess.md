# 0.28.1 S1 后处理技术卡：Vignette / Film Grain / Chromatic Aberration

日期：2026-11-11。状态：Vignette 已实现；Film Grain、Chromatic Aberration 在队列中。对应 46 项路线图 #23/#24/#25，执行计划见 [multi-agent full delivery](haikalat-multi-agent-full-delivery.md)。

## 共同边界

- 归属：`subsystems.postprocess` 色彩链，不新增 manager/factory；效果各自是 `PostProcessSettings` 中的不可变配置。
- 顺序：在 tone mapping 之后、FXAA/present/UI 之前；HDR-only（LDR 路径明确拒绝，避免在未定义的显示空间上重复编码）。
- 资源：每个启用的效果 owner 拥有自己的 shader 与 `ScreenQuad`；禁用/零强度不创建 Pass，也不分配资源；随候选代关闭。
- 成本：一次全屏采样/绘制；参数变化不重建 RenderGraph 之外的资源；与 Bloom/FXAA/TAA 的依赖通过现有 Pass 图表达。
- 参考：CPU 端按坐标、纵横比与参数计算期望颜色/边缘；真实 GL 读回中心/角落像素，不把当前输出直接当真值。
- 限制：不改变场景颜色空间或 HDR 范围；不处理 UI；不宣称在所有 AA/缩放组合下视觉等价。

## #23 Vignette（已实现）

| 项目 | 内容 |
|---|---|
| 输入 | tone-mapped LDR 颜色、viewport 尺寸、`VignetteSettings(enabled,intensity[0,1],smoothness[0,1],roundness[0,1])` |
| 输出 | 暗角调制后的 LDR 颜色 |
| 公式 | aspect-corrected `radial`/`box` 距离按 `roundness` 混合；`edge=smoothstep(1-width,1,d)`；`rgb *= 1 - intensity*edge` |
| 零值 | `enabled=false` 或 `intensity=0` → `active()=false`，不创建 Pass，图像精确不变 |
| 资源 | `VignettePass` 持有 shader + ScreenQuad；`PostProcessPipeline.owned` 关闭 |
| 参考 | `VignetteSettingsTest` 参数/零值；`VignettePassGlTest` 中心 > 角落，且 `RenderPipeline` pass 顺序 ToneMapping → Vignette |
| 成本 | 1 次全屏采样 + 1 次绘制，无额外附件（复用 tone-mapped RGBA8） |
| 限制 | 仅 HDR/ACES 路径；不模拟光学暗角/镜头呼吸 |

## #24 Film Grain（待实现）

- 输入：LDR 颜色、时间/帧序号、`FilmGrainSettings(intensity, response, seed)`。
- 输出：确定性、无闪烁累积的颗粒调制；默认关闭、零强度 no-op；应在 UI 之前。
- 验证：固定种子/时间下 CPU 参考、关闭基线、不同分辨率下颗粒尺度稳定；GPU 串行读回。

## #25 Chromatic Aberration（待实现）

- 输入：LDR 颜色、屏幕 UV、`ChromaticAberrationSettings(intensity, radial, samples)`。
- 输出：有界径向通道偏移；边缘采样 clamp 防越界；默认关闭/零强度 no-op。
- 验证：中心无偏移、边缘通道分离方向/幅度参考、越界不产生黑边；GPU 串行读回。
