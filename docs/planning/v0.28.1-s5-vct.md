日期：2026-11-12。状态：生产实现与 JVM 参考合同完成；真实 GL 用例已编写但**未执行**（worker 被禁止运行 `glSmoke`），因此 GL 结论为 `NOT_EVALUATED`。对应 46 项路线图 #45，执行计划见 [multi-agent full delivery](haikalat-multi-agent-full-delivery.md) 与 [realtime rendering roadmap](realtime-rendering-roadmap.md)。#44 DDGI 与 #45 是独立可选替代，本卡不要求两者同时驻留。

## 适用范围与承诺

- 支持：一个有界世界空间立方体（`center ± halfExtent`）的占用 + radiance 体素化；`32/64/128³` 基础分辨率与完整 mip 链；compute 保守三角形体素化；动态脏区清除/重采样/预算拒绝；GPU cone tracing 的漫反射与镜面间接光；显式 probe 读回；基于场景深度的 HDR 间接光合成；禁用时零 GL 资源和零命令。
- 不假设硬件光线追踪：全部路径为 compute shader + 3D texture，不调用 `GL_NV_ray_tracing`/`rayQuery`，性能与正确性不依赖 RTX。
- 不支持：多卷/clipmap、透明或 alpha 测试材质的双面体素化、逐像素材质 roughness/normal G-buffer（首版合成使用场景级 uniform roughness/albedo）、逐帧 4K 全场景性能承诺、超过 4096 个三角形的单次更新、与 DDGI 共享探针资源。

## 表示、尺度与边界

| 项目 | 内容 |
|---|---|
| 体积 | 闭区间立方体 `[center-halfExtent, center+halfExtent]`；面外世界坐标钳到边缘体素 |
| 基础分辨率 | `32/64/128³`（64 默认）；必须为 2 的幂以得到完整 mip 链 |
| 体素尺度 | `v = 2*halfExtent/resolution`；默认 `halfExtent=16` 时 32→1.0、64→0.5、128→0.25 世界单位 |
| Texel | RGBA16F：`rgb = surface radiance`，`a = coverage/occupancy` |
| Mip | 每级三轴减半直到 1³；级数 `1+log2(res)`（32→6、64→7、128→8） |
| 索引 | `x + nx*(y + ny*z)`（x 最快），与 3D texture layer 导出顺序一致 |
| 体素中心 | `min + (xyz+0.5)*v` |
| 薄墙 | conservative shell（不是实心填充），单墙通常 1–2 体素厚 |

`VctSettings` 校验：分辨率、半边长、强度、cone 数/张角、opacity threshold、normal bias、dilation、脏区数、更新预算、显存预算、trace 步数均拒绝非有限值和越界值，不做静默夹取。默认 `memoryBudgetBytes = 32 MiB`。

## 体素化机制（真实 compute 路径）

`vct-voxelize.comp` 每次调用处理一个世界空间三角形（triangle SSBO，20 floats/triangle）：

1. 计算三角形世界 AABB，转为体素 AABB，按 `uDilation` 扩张，再与脏区/体积边界取交集；越界部分永不写。
2. 用法线主轴（|n| 最大分量）投影到两个轴，得到 2D 三角形。
3. 对 AABB 内每个体素中心：要求其到三角形平面的距离 `<= v*(0.75+dilation)`，且投影点在三角形内或到任一边距离 `<= 0.75*v`（保守 2D 膨胀）。
4. `imageStore` 写入 `vec4(radiance, occupancy)`，alpha 为三角形覆盖度。

这是保守 shell 光栅化，不是逐体素包围盒求交；相邻/重叠三角形的 radiance 采用 last-writer-wins（occupancy 均为覆盖度），并发写不引入原子操作。单次更新三角形上限 4096，超出在录制前拒绝。

更新顺序（同一命令流）：

```
clear dirty region (imageStore 0)
  -> GL_SHADER_IMAGE_ACCESS_BARRIER_BIT | GL_TEXTURE_FETCH_BARRIER_BIT
voxelize dirty region (imageStore radiance/coverage)
  -> barrier
for each mip level L=1..N-1:
    downsample scaled dirty region from L-1 to L
    -> barrier
```

清除只覆盖脏区，因此移动物体离开的旧区域会归零；未触及区域的 radiance 保留。首次更新、体积 bounds 变化、`thinWallDilation` 变化和“场景 revision 变化但未提供脏区”都升级为全量更新（安全失败侧）。全量脏区超过基础体积 50% 也升级为全量。

mip 下采样（`vct-mip.comp`）：

```text
rgb_L+1 = sum(rgb_L,i * a_L,i) / sum(a_L,i)     (weighted by coverage)
a_L+1   = max(a_L,i)                            (conservative shell preservation)
```

使用 max coverage 而不是平均，是为了在粗 mip 上保留 1 体素薄墙；这是主要薄墙漏光控制之一。

## Cone tracing 数学

一次 cone 采样：

```text
r      = d * tan(aperture)
lod    = clamp(log2(max(2*r / v, 1)), 0, mips-1)
uvw    = (origin + direction*d - boundsMin) / (2*halfExtent)
sample = textureLod(volume, uvw, lod)
cover  = clamp((sample.a - opacityThreshold) / max(1-opacityThreshold, 1e-3), 0, 1)
L     += transmittance * cover * sample.rgb
T     *= 1 - cover
d     += max(v, 0.75*r)
```

终止条件：`d >= maxDistance`、`T <= 0.01`、`uMaxSteps` 用完或采样点离开体积；`maxDistance = max(v, 3*halfExtent)`。起始距离为 `v*(0.75 + normalBiasVoxels)`，用于降低自遮挡。

- 漫反射：在法线半球上按 cosine 分布取 `diffuseCones` 个方向，`cosTheta = sqrt((i+0.5)/N)`，`phi = 2π*(i+0.5)/N`，对每个方向执行一次 cone，结果取平均。
- 镜面：反射方向 `reflect(-view, normal)`；张角 `aperture = clamp(roughness² * specularApertureScale, 0.02, 1.2)`；`specularCones` 个方向在张角内抖动后取平均。
- 每像素合成（`vct-composite.frag`）：从场景深度经 `inverseProjection`/`inverseView` 重建世界位置，用世界位置屏幕导数求几何法线并翻向相机；远处（`depth >= 0.999999`）不贡献。输出 `diffuse*albedo*diffuseIntensity + specular*specularIntensity`，以 `ONE, ONE` 加性混合写入调用方 HDR 目标。

“真实 GL 用例”用统一封闭盒（所有面 radiance=1）检查漫反射收敛到解析值 1；用薄墙/双墙的 occupancy=0.3 检查透射率衰减；用高/低 roughness 的亮小盒检查镜面张角响应。JVM 参考独立实现同一组公式的 floor/frac、八角色权重和体素区间搜索。

## 生命周期、事务与预算

- 所有者：`VctPass` 拥有 3D texture、mip 链、triangle/probe SSBO、5 个 program、sampler、ScreenQuad；`Framebuffer`/场景深度是借用，不 resize、不销毁。
- 构造：`enabled` 配置在 GPU owner 线程一次性准备完整 `Runtime`；`disabled()` 不创建任何 GL 对象。
- 候选优先重配置：`reconfigure(next)` 先构建完整候选 `Runtime`，成功后才发布并退役旧代；构造失败保留旧 settings、旧 volume 和旧 program。分辨率或显存预算变化会重建资源；仅 trace/cone/budget 参数变化原地更新；bounds 或 dilation 变化使旧体积失效并在下一次更新做全量重建。发布后退役失败会保留新代并抛出带 suppressed 的异常，不伪报回滚。
- 禁用：`reconfigure(disabled())` 关闭专属资源，`runtime=null`；`recordVoxelize`/`recordProbeTrace`/`recordComposite` 在触碰借用输入前返回 0 命令；`volumeTexture()` 为 null，`volumeBytes()` 为 0。
- `close()` 幂等并聚合关闭失败；关闭后 record 入口抛 `GlException`。
- 更新预算：`maxDirtyRegions` 合并/折叠上限与 `maxVoxelsPerUpdate`（基础区 voxel 数一次 + 每级受影响 mip 区 voxel 数；clear 与 raster 各遍历基础区一次，不重复计费）在录制前检查；超预算抛 `IllegalArgumentException`，已发布体积保持不变，绝不录制半帧。
- 失败注入：`-Dhaikalat.test.failVctVolumeAllocation=true` 在候选分配前抛错，供 GL 事务用例验证旧代保留（一次性，用后清除）。

## 成本与 NOT_EVALUATED 边界

- 体素化 CPU 侧只做打包/上限检查（每三角形 20 floats）；GPU 工作量上界为 `maxVoxelsPerUpdate`（基础区计一次，另加每级 mip dispatch；实际 clear+raster 各遍历基础区一次），复杂三角形 AABB 可能放大单次 dispatch。
- cone trace 上界为 `probes × (diffuseCones + specularCones) × maxTraceSteps`；每步一次 `textureLod`。合成路径为每像素 `diffuseCones + 1` 条 cone。
- 未做正式 GPU/CPU 性能、显存峰值实测、多硬件或 4K 矩阵；本卡不宣称帧率、毫秒或“比 IBL 更快”。`#44` 与 `#45` 同时开启时两套昂贵资源都驻留，本 worker 不建立共享表示。

## 生产接线（Integrator，`codex/render-wiring-b3`）

生产入口（默认 `VctSettings.disabled()`，禁用时不创建 3D texture、mip、SSBO、program、screen quad 或
composite pass；拓扑 key 与基线逐字节一致）：

| 名称 | 语义 |
|---|---|
| `RenderPipeline.vct(settings)` | build 前配置；已有代次时抛 `IllegalStateException`。 |
| `RenderPipeline.vct()` | 当前请求值；不暴露 GPU 句柄。 |
| `RenderPipeline.applyVct(settings)` | 帧边界事务：设置相等直接返回；否则重建完整候选代（`VctPass` 构造期分配 runtime），失败保留旧代/旧 volume/旧设置。 |
| `RenderPipeline.vctSceneInput(VctSceneInput)` | 暂存调用方转换的可见 opaque 三角快照；`null` 表示本帧不更新（保留上次 volume）。 |
| `RenderPipeline.vctDirtyBoxes(List<VctBox>)` | 暂存上次成功更新以来的脏区；成功 voxelize 后自动清空，下一帧同 revision + 空列表为 no-op。 |
| `RenderPipeline.vctProbes(VctProbeBatch)` | 可选显式 probe trace；`null` 表示不 trace。 |
| `RenderPipeline.vctSurface(roughness, albedo)` | 首版场景级 receiver 代理；标量，不触发代次重建。 |
| `RenderFeatureSettings.vct(...)` / `vct()` | builder、`defaults()`、`toBuilder()` 与统一批量入口。 |
| `RenderFeature.VOXEL_CONE_TRACING` | 有效/不可用原因（`ACTIVE`/`DISABLED`/`PAUSED_BY_MASTER`/`UNAVAILABLE`）。 |
| `PipelineTopology.voxelConeTracing` | 仅当 settings enabled、HDR、非 MSAA/TAA 时进入拓扑 key。 |

图顺序与合同：

```text
GeometryPass (opaque/MASKED forward)
  -> VctVoxelizePass   (dirty-region clear -> conservative voxelize -> mip chain)
  -> VctProbeTracePass (optional explicit probe batch, compute)
  -> VctCompositePass  (blit 当前 HDR scene colour, depth-reconstructed additive cone light)
  -> post-process HDR chain / Bloom / TAA
```

- `RenderPipeline` 不扫描 `Mesh`/GLTF CPU 三角（当前 `Mesh` 只保留 GPU buffer），因此 `VctSceneInput`
  必须由调用方通过 `vctSceneInput(...)` 提供；未暂存快照时 voxelize/trace 记录零命令，composite 只做
  颜色桥接（不添加间接光），`VctPass` 从 `recordComposite` 的 `volumeValid` 前置条件 fail-closed。
- 共享 surface 为 VCT 请求单采样 `DEPTH`；composite 只重建世界位置并 additive 写入图拥有的
  `VctCompositeColor`，不声明深度附件、不写共享深度。
- `RenderFeaturePolicy` 对 MSAA/TAA 做软 `UNAVAILABLE`，对 DDGI+VCT/VCT+SSGI 硬拒绝；
  `PipelineFeaturePolicy` 在装配期再次拒绝非单采样、缺 depth 或双间接技术。
- 首版场景级 rough/albedo uniform 代替逐像素材质 G-buffer；与 DDGI 默认互斥；Bloom/TAA 消费
  composite 输出，不重复叠加 SSGI。

本轮验证（JVM 实际执行）：`RenderPipelineWiringB3Test` 的 VCT case 覆盖 voxelize→trace→composite
顺序、合成分离、disabled 拓扑 no-op 与设置回滚，10/10 PASS；真实 GL
`RenderPipelineWiringB3GlTest` 的 VCT case 为 **NOT_EVALUATED**（GPU 队列负责执行）：
