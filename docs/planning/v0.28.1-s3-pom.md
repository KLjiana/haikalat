## 技术卡

| 字段 | 内容 |
|---|---|
| 技术 ID／用户场景 | #31 视差遮蔽贴图；砖石、木板、浮雕面板等近景材质在掠射/斜视下用高度图伪造凹凸视差。默认关闭，不引入第二种材质系统或独立 Pass。 |
| 当前基础／差距 | 已有唯一 metallic-roughness PBR 路径（`PbrMaterials` → `Material` → `pbr-forward.frag`），五种固定纹理角色与共享 1×1 fallback，材质级 clearcoat/anisotropic 输入。缺少切线空间高度输入、按视角/距离衰减的有界 UV 偏移，以及“只改 UV、不改深度/阴影/轮廓”的公开近似合同。 |
| 首版范围 | 单层切线空间高度场的分层 ray march：`minSteps`/`maxSteps` 按视角插值、命中层线性插值、角度与距离双重 smoothstep 衰减、可配置高度通道与翻转；只把最终 UV 交给 base color / metallic-roughness / normal / occlusion / emissive 采样。`disabled()` 或 `heightScale = 0` 精确走原 `vTexCoord` 采样序列。 |
| 不支持输入 | 几何位移/tessellation、silhouette 扩张、自遮挡/软阴影、多高度层/视差修正（parallax-corrected cubemap）、逐像素高度缩放贴图、height map 的 glTF 扩展或场景 JSON 解析、UV 集选择（只用 `vTexCoord`）、clearcoat 法线贴图的 POM 偏移。 |
| 模块与控制 | `core.material.ParallaxOcclusionSettings`（GL-free 不可变 record，公开 advanced，含嵌套 `HeightChannel`）；`Material.parallaxOcclusion(...)` / `Material.parallaxOcclusion()`（默认 `disabled()`）；`PbrMaterials.createWithParallax(...)` 与末位带 `ParallaxOcclusionSettings` 的完整 `createWithBindings(...)` 重载；`PbrTextureRole.HEIGHT` + `PbrMaterials.HEIGHT_UNIT = 6`；唯一生产消费端 `pbr-forward.frag`。没有新增 manager、factory、Pass、FBO、历史或 GPU owner。 |
| 材质默认 | 所有既有 `PbrMaterials` 工厂（含 glTF 路径）继续以 `ParallaxOcclusionSettings.disabled()` 构建并绑定黑色高度 fallback：`uParallaxEnabled = 0`、`uParallaxHeightScale = 0`、步骤/衰减为文档默认值。既有材质模板、绘制顺序与像素路径不变；`uHeightMap` 作为未使用 sampler 仍按固定 unit 6 绑定。 |
| 输入格式与空间 | `heightScale`：有限 `[0,1]`，UV 空间高度；切线空间横向斜率为 1（与法线成 45°）时全高度对应 `heightScale` 个 UV 单位。`minSteps/maxSteps`：`[1,128]` 且 `maxSteps >= minSteps`；层数 `mix(maxSteps, minSteps, clamp(N·V,0,1))` 后向上取整。`fadeStart/fadeEnd`：从几何法线量起的视角（度），`[0,90)` 与 `(fadeStart,90]`，窗内 smoothstep 1→0。`fadeStartDistance/maxDistance`：相机世界距离，同样 smoothstep 1→0，且 `maxDistance > fadeStartDistance`。两权重相乘，任一窗口可单独关闭效果。均为**材质值**，不是 `RenderFeatureSettings` 拓扑开关。 |
| 高度贴图／通道／颜色空间 | 新增 `PbrTextureRole.HEIGHT`，要求 `TextureColorSpace.LINEAR`（非颜色、不 gamma 解码），固定 unit 6（0–4 为 PBR 角色、5 为清漆法线、8–10 为借用 IBL）。`HeightChannel` 选择 R/G/B/A（默认 R，shader 内 clamp 到 `[0,3]`），`flipHeight` 采样后取 `1 - h`。缺省使用 `PbrFallbackTextures` 的黑色 1×1 RGBA8：高度 0 表示平面，march 第一步即返回原 UV。通道与翻转属于材质设置，不是纹理角色属性。 |
| 算法 | 在 frag 中用几何法线重建切线帧（`vTangent` 重新投影；缺失/退化时复用确定性的法线派生轴与 handedness 修正副切线），把 `view = normalize(camera - world)` 投影到 `(T,B,N)`。`slope = viewT.xy / max(viewT.z, 1e-4)`，长度上限 `PARALLAX_MAX_SLOPE = 8`；每层步进 `slope * heightScale * weight / layerCount`，从表面层向相机方向反向推进，`currentDepth` 每层增加 `1/layerCount`，直到采样高度低于当前深度。命中后用相邻两层的 `depth - height` 误差做一次线性插值，得到连续 UV；若步数耗尽仍高于表面，则返回最后一个采样 UV（有界回退，不返回 NaN）。 |
| 零值/禁用还原 | `uParallaxEnabled = 0` 或 `uParallaxHeightScale = 0` 时 `materialUv` 精确等于 `vTexCoord`，不进入 helper、不采样高度图；base color、metallic-roughness、normal、occlusion、emissive 的采样表达式与顺序保持原样。所有新增分支都是正向 guard，没有 `uParallaxEnabled == 0` 特例。 |
| 参数校验 | `ParallaxOcclusionSettings` 构造期拒绝非有限/越界高度、非法步数、非有限或倒置角度窗、非有限或倒置距离窗、null 通道，抛 `IllegalArgumentException`；builder 在 `build()` 时经同一构造器校验。`Material.Builder.parallaxOcclusion(null)` 抛 NPE。`MaterialInstance` 直接注入 NaN/Inf uniform 属于调试/越权路径，shader 用 `!(x > 0)` 等 NaN 敏感比较失败关闭到 `vTexCoord`。 |
| UV 越界与有界性 | UV 坐标由 slope 上限（8）、`heightScale ≤ 1`、weight ≤ 1 与层数上限共同约束，最大横向位移不超过 8 个 UV 单位；高度采样与最终材质采样都交给各自 sampler 的 wrap 模式（fallback 为 CLAMP_TO_EDGE，自定义可为 REPEAT），因此越界只产生 clamp/wrap，不产生 NaN 或崩溃。march 使用编译期 `PARALLAX_MAX_STEPS = 128` 上界 + uniform clamp + break，不存在无界循环；`viewT.z` 有 `1e-4` 下限。 |
| Pass 顺序 | 不新增 Pass。既有 PBR forward 的 `main` 顺序调整为：几何法线/双面翻转 → 视线 → POM UV（仅启用时）→ base color/alpha → metallic-roughness → 基础法线贴图 → 清漆 setup → cluster debug 早退 → 各向异性 setup → 逐灯直接光 → IBL → 清漆 IBL 分割 → GTAO/AO/环境强度 → emissive/输出。POM 在 base color 之前完成，之后所有材质采样共用 `materialUv`；几何/阴影/速度相关输入（`vWorldPosition`、`vViewDepth`、shadow matrix）不变。 |
| GPU owner／生命周期 | 不新增 GPU owner。高度图是材质模板的 borrowed 纹理（由调用方 `PbrFallbackTextures` 或资产 owner 拥有），随既有 `Material`/`TextureBinding` 生命周期绑定与关闭；POM 参数只是 `Material` 模板 uniform。准备/提交即既有 `Material.Builder`；退役即关闭既有 Material，无新增候选/事务。 |
| 失败 | 非法设置装配期拒绝；shader 内非有限/倒置 uniform 失败关闭到原 UV；缺失高度贴图使用黑色 fallback（平面）；退化切线使用确定性回退帧。没有“部分启用”状态，也没有每帧隐式重试。 |
| 成本／回退／质量档 | 启用时每片元 `layerCount + 2` 次高度采样（默认 8–32 层，上限 128）与一次切线帧重建；禁用/零 scale 零额外采样。回退为降低 `maxSteps`/`heightScale`、缩小距离窗或关闭。**不新增引擎质量档枚举**；建议 Low `minSteps 4 / maxSteps 12`、Medium `8/32`、High `12/48`（同一分支，不宣称性能分档）。未做正式 GPU 成本测量，成本状态 `NOT_EVALUATED`。 |
| 参考与许可 | 算法为本项目自写分层 POM + 线性插值，无第三方 shader 或资产；高度/自发光测试纹理由测试代码生成。独立 double 参考位于 `src/test` 的 `ParallaxReferenceMath`，不进入生产包，也不调用生产 helper。 |

## 独立 oracle 与验证范围

### 独立参考

`src/test/java/.../subsystems/render3d/pbr/ParallaxReferenceMath.java` 是测试侧 double
精度独立实现：smoothstep 角度/距离权重、层数选择、slope 上限、层进、命中判定与
一次线性插值。它手工重写公式，不调用 `ParallaxOcclusionSettings`、`PbrMaterials`
或 shader 源；`HeightSampler` 由调用方提供，纹理过滤/wrap 语义由夹具显式实现。
固定样本由独立推导得到并由 `ParallaxReferenceMathTest` 锁定：

- 视角 `viewT = (0.6, 0, 0.8)`、`heightScale = 0.2`、`minSteps 4 / maxSteps 8`：
  `layerCount = 5`、全高度横向位移 `0.15`；
- 常数高度 `0.5`：3 步后命中，线性插值给出 `u' = u - 0.075`；
- 线性高度 `h(u) = 0.25 + 0.5u`：解析交点深度
  `d = 0.5 / (1 + 0.5·0.15)`，`u' = 0.4302325581395349`，分层+一次插值精确复现；
- 常数高度 `1`：march 耗尽回退到全偏移 UV `u - 0.15`，无 NaN；
- slope 上限：`viewT = (8, 0, 1e-3)` 时偏移被限制在 `8·heightScale`；
- `minSteps = 500` 被 clamp 到 128；越界 UV 在 REPEAT 采样下保持有限。

### 真实 GL（首轮 Orchestrator 执行 FAILED，已修 oracle；本包仍 NOT_EVALUATED）

类：`com.kaleblangley.haikalat.integration.ParallaxGlTest`，单用例
`parallaxMovesTheMaterialUvAsTheOracleAndKeepsEveryOtherContract`，运行命令：

```text
.\gradlew.bat glSmoke --tests "*ParallaxGlTest"
```

由 Orchestrator 串行执行。**首轮 1/1 FAILED**，失败在 disabled 基线：

```text
disabled baseline: only 342/11154 covered pixels matched the independent oracle (0.0307),
worst 0.8391236 at (107,54) uv=(0.64448,0.20141)
expected=(0.02416,0.56471,0.10702) actual=(0.86328,0.26172,0.6875)
```

根因在测试 oracle，不在生产 POM/shader/纹理：

- 该像素实际颜色 `(0.86328,0.26172,0.6875)` 精确等于 emissive 色块 `(239,140,216)` 的
  sRGB→linear 值，说明纹理、颜色空间、emissive factor 与采样路径都正确。
- 用临时 JVM 探针（已删除，未提交）复算：像素 (107,54) 的相机射线与倾斜 quad 交点
  的正确局部坐标是 `(0.0853,-0.1244)`，即 `uv=(0.5853,0.3756)`，落在色块 (9,6)，
  与实测颜色一致；这也确认读回行序、UV 方向、旋转与透视插值假设正确。
- 旧 oracle 在 `frontSurfacePoint` 中先调 `model.transformPosition(local)` 再读取
  `local.x/local.y`。JOML 的 `transformPosition(Vector3f)` 原地修改参数，导致
  `SurfacePoint` 把 **world x/y + 0.5** 当成 UV 上报：`(0.6445,0.2014)` 正好是
  world 坐标，对应错误色块 (10,3)。因此 matched 仅 3%，并非 fixture 的 UV 翻转、
  sRGB 或 tonemap 问题。
- 修复：在变换到 world 之前先保存 `u/v`，world 使用副本；探针删除。JVM 重跑
  `*Parallax*` 等 13 classes / 59 tests / 3 guarded GL skips / 0 failures。
  第二轮真实 GL 由 Orchestrator 复跑；本包**不宣称 GL PASS**。

覆盖：

1. 倾斜 45° 的 opaque quad（`TangentGenerator` 生成的切线 +X/副切线 +Y），
   64×64 LINEAR 高度斜坡 + 64×64 SRGB、NEAREST、4 texel 色块自发光图；关闭
   直接光、IBL、阴影，线性 HDR 读回即为自发光采样值。独立 oracle 逐像素预测
   POM UV 所在色块，要求 ≥95% 覆盖像素匹配；同时用 disabled 基线验证同一预测
   在原始 UV 上的正确性。
2. POM 启用帧与 disabled 帧必须有 >500 像素的可见差异；oracle 统计 POM 后采样
   色块改变的覆盖像素 >1/3，防止“shader 静默返回原 UV”的空洞通过。
3. `uParallaxEnabled = 1` + `heightScale = 0` 与 disabled 逐字节相等；
   清除 overrides 后恢复模板启用帧逐字节相等。
4. 角度窗（10°–20°）与距离窗（0.1–0.5）排除夹具视角/距离时，与 disabled 逐字节
   相等（衰减到零的精确回退）。wide-window + 全高度 + 1×1 白色高度图把 UV 推出
   `[0,1]`：断言输出有限、有界、无 GL 错误，并用常数高度 1 的 oracle 预测 clamp
   后的色块。
5. 深度/轮廓 A-B：前方 quad 后 0.011 世界单位处放黑色背板。

**深度/阴影合同**：`pbr-forward.frag` 从不写 `gl_FragDepth`（`ParallaxShaderTest`
断言），阴影采样使用 `vWorldPosition`/shadow matrix 而非 `materialUv`，阴影投射
Pass 使用独立 depth-only shader；因此 POM 不改变深度缓冲、shadow map、velocity 或
几何轮廓。GL 夹具只对“前表面覆盖/遮挡集合”做 A-B，**不**单独读回 shadow map 做
等价断言，该子项状态与真实 GL 一起为 `NOT_EVALUATED`。

## 已知限制

1. **仅 UV 位移近似**：不改变顶点、深度、shadow map、velocity、轮廓或描边；
   无 silhouette 扩张、无自遮挡、无厚度/阴影，不能称为几何位移或 displacement。
2. **无 tessellation / 真实凹凸**：高度场不参与深度预通道、阴影投射或 GTAO；
   掠射角的遮挡关系仍是平面。
3. **MASK 材质的 alpha discard 使用位移后 UV**：几何轮廓不变，但 mask 边缘被
   discard 的 texel 集合可能变化；OPAQUE/BLEND 路径不受影响。
4. **清漆法线贴图不参与 POM**：可选的 `uClearcoatNormalMap` 仍采样 `vTexCoord`；
   清漆层是独立覆盖层，本版未与基色高度对齐。
5. **高度通道/翻转是整材质值**：无逐像素高度缩放、UV 集选择或高度图数组；
   glTF height/map 扩展与场景 JSON `heightTexture` 均未接入，需程序化传入
   `PbrTextureRole.HEIGHT`。
6. **越界语义依赖 sampler**：UV 不强制 clamp，tiling 材质可 wrap；高度图与最终
   材质使用各自 sampler，wrap 不一致时边缘可能跳变。
7. 逐帧切换需 `MaterialInstance` 覆盖 `uParallax*`/unit 6；替换场景材质仍需重新
   `build()`。
8. 未做正式 GPU 成本测量，也没有 POM 专属质量档枚举或诊断计数；建议参数分档不是
   引擎质量档。
9. 真实 GL 未执行：倾斜 quad 采样、零值等价、衰减、越界 UV、深度 A-B 与
   `HAIKALAT_VOLUME_FOG` 变体均为 `NOT_EVALUATED`；MSAA、glTF 扩展、与
   #16/#17/#19 的组合矩阵由 Integrator 组合验证。
