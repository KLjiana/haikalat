## 范围与承诺

- 目标：双面薄叶／薄布在背光方向获得可控的透射颜色，进入现有 PBR 直接光结果。
- 支持：`PbrMaterialProperties` 的显式标量 `thicknessFactor`、`transmissionFactor`、`backlightFactor`，均为 `[0,1]`、默认 `0`；geometry 仍为普通 opaque/MASK 网格。
- 不支持：厚度贴图、屏幕空间折射、multiply 混合、glTF `KHR_materials_transmission` 自动导入；不宣称能量守恒的薄介质散射，也不自动把双面 glTF 材质识别为薄叶。

## 输入/输出与公式

| 项目 | 内容 |
|---|---|
| 输入 | 三个归一化浮点材质值（线性、无时间语义）；场景 properties 键为 `material.<name>.pbr.thicknessFactor/transmissionFactor/backlightFactor` |
| 输出 | 现有 HDR 表面颜色增加背光项；不改变 alpha、shadow map、surface 通道或 Pass 拓扑 |
| 法线 | 沿用现有 `uDoubleSided` + `gl_FrontFacing` 翻转后的 shading normal（含 normal map），与 PBR 反射项使用同一 `Nf` |
| 公式 | `B=max(dot(-Nf,L),0)`，`F=max(dot(V,-L),0)`，`lobe=F^(1+7*thickness)`，`absorb=exp(-2*thickness)`；`Ctrans=baseColor*radiance*transmission*backlight*B*lobe*absorb` |
| 灯循环 | 方向光与 clustered 本地光复用同一 radiance、距离/锥角衰减和 shadow visibility；不新增灯扫描或第二套阴影采样 |
| 零值 | 两个控制任一为 `0` 时函数立即返回 `vec3(0)`，反射路径与加法顺序不变，默认输出与改动前逐像素一致 |
| 能量 | 艺术近似：`transmission*backlight ≤ 1`；未从反射项扣除透射能量，技术卡明确公开该限制 |

## 集成、生命周期与阴影

- 归属 `core.assets` 的不可变材质定义与 `subsystems.render3d.pbr` 的装配/着色；没有新增 manager、Pass、纹理或 GPU owner。
- `PbrMaterials` 两条创建路径都写入 `uThicknessFactor`／`uTransmissionFactor`／`uBacklightFactor`；旧七参数构造器保留并补 `0`，现有调用点不改语义。
- 阴影 path 仍是 depth-only 且显式关闭 cull；MASK 的 alpha cutoff、双面 raster 与主 pass 保持同一值。背光项只消费既有 visibility，不改变 shadow-caster 约定。
- 已知限制：若薄叶自身作为 shadow caster 且使用已启用阴影的方向光，正面 bias 可能把自身计入遮挡，背光项被 self-shadow；首版不新增 transmission shadow pass，作者可用非投影薄叶或非阴影灯验证效果。
