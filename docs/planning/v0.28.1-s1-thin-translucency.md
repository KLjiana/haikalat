## 范围与承诺

- 目标：双面薄叶／薄布在背光方向获得可控的透射颜色，进入现有 PBR 直接光结果。
- 支持：`PbrMaterialProperties` 的显式标量 `thicknessFactor`、`transmissionFactor`、`backlightFactor`，均为 `[0,1]`、默认 `0`；geometry 仍为普通 opaque/MASK 网格。
- 不支持：厚度贴图、屏幕空间折射、multiply 混合、glTF `KHR_materials_transmission` 自动导入；不宣称能量守恒的薄介质散射，也不自动把双面 glTF 材质识别为薄叶。

## 输入/输出与公式

| 项目 | 内容 |
|---|---|
| 输入 | 三个归一化浮点材质值（线性、无时间语义）；场景 properties 键为 `material.<name>.pbr.thicknessFactor/transmissionFactor/backlightFactor` |
| 输出 | 现有 HDR 表面颜色增加背光项；不改变 alpha、shadow map、surface 通道或 Pass 拓扑 |
| 法线 | 沿用现有 `uDoubleSided` + `gl_FrontFacing` 翻转后的 shading normal（含 normal map），与 PBR 反射项使用同一 `Nf` |
| 公式 | `B=max(dot(-Nf,L),0)`，`F=max(dot(V,-L),0)`，`lobe=F^(1+7*thickness)`，`absorb=exp(-2*thickness)`；`Ctrans=baseColor*radiance*transmission*backlight*B*lobe*absorb` |
| 灯循环 | 方向光与 clustered 本地光复用同一 radiance、距离/锥角衰减和 shadow visibility；不新增灯扫描或第二套阴影采样 |
| 零值 | 两个控制任一为 `0` 时函数立即返回 `vec3(0)`，反射路径与加法顺序不变，默认输出与改动前逐像素一致 |
| 能量 | 艺术近似：`transmission*backlight ≤ 1`；未从反射项扣除透射能量，技术卡明确公开该限制 |

## 集成、生命周期与阴影

- 归属 `core.assets` 的不可变材质定义与 `subsystems.render3d.pbr` 的装配/着色；没有新增 manager、Pass、纹理或 GPU owner。
- `PbrMaterials` 两条创建路径都写入 `uThicknessFactor`／`uTransmissionFactor`／`uBacklightFactor`；旧七参数构造器保留并补 `0`，现有调用点不改语义。
- 阴影 path 仍是 depth-only 且显式关闭 cull；MASK 的 alpha cutoff、双面 raster 与主 pass 保持同一值。背光项只消费既有 visibility，不改变 shadow-caster 约定。
- 已知限制：若薄叶自身作为 shadow caster 且使用已启用阴影的方向光，正面 bias 可能把自身计入遮挡，背光项被 self-shadow；首版不新增 transmission shadow pass，作者可用非投影薄叶或非阴影灯验证效果。

- JVM：旧构造器/`defaults()` 三值为零；显式值可读写；场景 properties 解析往返；NaN、负数、`>1` 在构造与解析层拒绝。

## 成本与回退

- 每个直接光增加三个标量 uniform 与一次分支；控制为零时提前返回，不执行 pow/exp，不改变原有分支预算。
- 关闭：材质三值归零（或旧构造器）即回到原 PBR；无资源需要回收。

## 第二次验收：边界行为证据（2026-11-13）

日期：2026-11-13。代码提交 `ccfa06c0`（基于集成 HEAD `4b1f3e62`）。首次验收只有
背光/正面光/零值 1 个 case；MASK alpha-cutout、back-face 相机、`thickness > 0` 的
吸收/波瓣方向、cascade shadow 的可见性一致性都没有行为覆盖。生产 shader 未修改。

### 新增 case 与断言

1. `maskCutoutBackFaceAndSideLightKeepThinTransmissionBounded`
   - 2×1 base-colour 纹理：左 texel alpha 0.2（< cutoff 0.5），右 texel alpha 1.0。
     `alphaCutoff=0.5` 的 MASK 材质下，左探针被 discard 到背景（与矩形外背景
     能量差 ≤2），右探针保留背光透射（>30）；同一纹理 `alphaCutoff=0` 时左探针
     被着色且显著高于 MASK 值（差 >30），证明 cutoff 真正生效而非 fixture 变空。
   - back-face 相机：相机在 -Z、yaw 90° 看双面 quad 的背面，背光方向
     `(0,0,-1)`；薄材质中心能量比零值高 **>30**。
   - front-lit 负对照：同一双面材质正面受光时，薄与零值中心能量差 **≤2**，
     证明正面 PBR 路径未变。
   - side-lit 拒绝边界：光方向 `(1,0,0)` 时 `back = dot(-N,L) = 0`，薄材质与零值
     中心能量都为 0（差 ≤2），对应 shader 的 `back <= 0` 提前返回。
2. `thicknessChangesAbsorptionAndLobeInTheAssertedDirection`
   - 背光、正对相机：`thickness=1` 的中心线性 HDR 亮度 / `thickness=0` 的比值
     **< 0.5**（`absorb=exp(-2)=0.1353`，正对时 `lobe=1`）。
   - 斜视相机（front ≈ `(-0.496,0,-0.868)`）：同一比值**再小于正对值的 0.9 倍**，
     对应 `lobe = forward^mix(1,8,thickness)` 的收紧。
3. `cascadeShadowAttenuatesTheThinReceiverExactlyOnce`
   - 两个镜像的 shadow 配置测量同一可见性 profile：front light（travel -Z）+
     caster 在 +Z 时用零值材质测 direct 可见性；back light（travel +Z）+ caster
     在 -Z 时用薄材质测 thin 可见性。caster 均为 1.6×1.6、接收面 3×3、
     `ShadowSettings(32, 4.0, 0.1, 20.0, 0.01)`，在 penumbra 内找
     `0.15 < visibility < 0.9` 的像素。
   - 薄材质的 shadowed/lit 比值与 direct 测得的 visibility 差 **≤0.1**：既不是 1
     （阴影消失），也不是 visibility²（双重变暗）；阴影确实使薄接收面变暗。
   - 该 case 也验证了文档中的限制：只有既有 visibility 被消费，没有新增
     transmission shadow pass；接收面仍显式 `castShadows=false`。
