## 采样、门限与回退

每个接收像素（`depth < 1` 且 albedo 非零）：

1. 由 device depth + inverse projection 还原 view 位置；normal 用 octahedral 解码。
2. 接收点环境辐照度：有绑定 irradiance cube 时
   `E_amb = texture(uIrradiance, rotate(normal)).rgb * intensity`；否则
   `E_amb = PI * ambientFallback`；`L_amb = E_amb / PI`。
3. 固定序列：`u1=(i+0.5)/n`、`u2=fract((i+0.5)*0.61803398875 + rotation)`，
   `rotation = interleavedGradientNoise(gl_FragCoord.xy)`；以 normal 构造
   orthonormal 基，得到 cosine-weighted 半球方向。辐照度估计为
   `PI / n * sum(L_i)`。
4. 每条射线在 view space 走 `stepCount` 步，`t = maxDistance*(step+0.5)/stepCount`，
   用 raster projection 投到屏幕；离开 `[0,1]` 或 `clip.w <= 0` 记为离屏。
5. 命中判定：`separation = rayDepth - sceneViewDepth`；
   `separation <= max(0.02, 0.002*sceneViewDepth)` 继续；
   `separation > thickness` 视为被厚几何遮挡并不再贡献；
   `distance < 0.05 m` 继续（避免自命中）。
6. 命中置信度：`facing = clamp(-dot(hitNormal, rayDirWorld),0,1)`（背向射线拒绝）、
   命中面粗糙度 `smoothstep(minRoughness, min(minRoughness+0.2,1), roughness)`、
   屏幕边界 `smoothstep(0, edgeFadePixels, minBorderPixels)`；命中贡献
   `color * facing * roughnessWeight * edgeFade`。
7. 天空/背景样本（`sceneDepth >= 1`）贡献 0：IBL ambient 已覆盖环境→接收点路径，
   不再叠加。被遮挡样本贡献 0。离屏样本累计为环境回退：
   `min(offscreenCount/n, maximumOffscreenFraction) * E_amb`。
8. 合成：`out = base + albedo * max(gathered,0) * strength / PI`；背景、albedo 为零、
   NaN/Inf 时逐字节返回原颜色。

## 去重合同（直射／IBL／AO）

- **直射光**：只读取接收点颜色，不重新累加；只有其它可见表面的辐亮度进入 gathered。
  接收点自身直射亮像素不会改变输出（GL case 7）。被屏幕命中的邻居的直射光转换为
  接收点的一次间接弹射，属于新光路，不是重复。
- **IBL ambient**：屏幕内天空/背景样本贡献 0；环境 cube 只用于接收点基线和离屏回退，
  不会作为第二个 ambient 项叠加。离屏回退最多为 `maximumOffscreenFraction * E_amb`
  且按接收点 albedo 加权，作为“看不见的几何”的一次弹射估计并有界。
- **AO**：不减去任何既有 ambient，也不把 forward 的 AO 再乘到新增弹射上，因此 AO
  只由 forward 应用一次。首版新增弹射不被 GTAO 再次遮挡（偏保守增亮，见限制 4）。

## Pass 顺序与配置拒绝

HDR 链（新增 SSGI 在 TAA 之后、SSS/SSR 之前）：

```
Geometry → [HdrResolve] → [Fog] → [VfxComposite] → [ScreenDistortion] → [TAA]
  → SsgiPass → SubsurfaceScatteringPass → SsrPass → [TemporalDenoisePass]
  → [DepthOfField] → [MotionBlur] → AutoExposure/Bloom → ToneMapping → ...
```

- `PostProcessPipeline` 在 `effects.ssgi().active()` 时创建 owner；HDR 关闭时抛出
  `screen-space indirect diffuse requires HDR tone mapping`。
- 缺少 `DEPTH`/`NORMAL`/`ROUGHNESS`/`ALBEDO` surface 输入时在 `addFinalPass`
  或 `validateSurfaceInputs` 抛出明确异常。
- 与 temporal upscaling 互斥：SSGI 需要全分辨率共享表面，upscaler 的低分辨率
  路径在候选装配期以 `temporal upscaling cannot consume a full-resolution surface
  input ... indirect diffuse ...` 拒绝，不会静默组合。
- disabled 时不创建 pass，`passNamesFor` 与基线顺序不变。
- SSGI 为共享 surface 新增 RGBA8 通道；未启用时 layout 与基线一致。

## 明确限制与未验证项

1. 这是对已着色 HDR 颜色的**有界空间近似**：没有多次弹射、路径追踪、方向性辐照度
   重建、屏幕外几何重建、GI 专用时域历史或 #34 信号适配。首版输出直接合成进颜色链，
   未单独输出 GI radiance target 供降噪器消费。
2. 命中辐亮度是命中像素**朝相机方向**的 outgoing radiance，被近似当作朝接收点的
   incoming radiance（SSGI 的固有限制）；掠射/镜面命中靠 roughness 门限压掉。
3. march 使用固定世界步长和 thickness 窗口：比步长更薄的几何可能被跳过；步数越大
   越贵也越准。深度/法线边界用固定 bias 与点积阈值，不使用材质法线贴图。
4. 新增弹射没有乘 GTAO AO：这是保守的增亮近似（避免 AO 二次应用），但遮挡区可能
   略亮；不是重复计数。接收点仅用 albedo 标量 factor，未采样 base-colour 贴图。
5. `maximumOffscreenFraction` 限制看不见的几何对结果的影响；开阔天空边缘仍可能得到
   有界的“虚构几何”弹射，默认 0.5 是该有界近似的调参点。
6. 每个像素最多 256 次 march fetch（16×16）与 5 次 surface fetch；没有 GPU 毫秒、
   带宽或 4K/1080p 性能测量，性能 `NOT_EVALUATED`。默认 8×8。

## F4 时域适配（可选 GI temporal accumulation）

日期：2026-11-12。状态：生产实现、JVM 合同与真实 GL 用例已写入；默认关闭。
本阶段只给 SSGI 增加一条 GI 专用历史，不改变 `TemporalDenoisePass` 的 SSR 绑定，
也不共享它的历史。

### 设置与兼容构造

`SsgiSettings` canonical record 末尾追加 5 个组件，旧的 12 参数 canonical 构造器保留
并映射为 `temporalBlend = 0`（精确空间路径），因此既有源码调用点无需修改：

| 参数 | 默认 | 校验 | 语义 |
|---|---|---|---|
| `temporalBlend` | 0.0 | 有限，`[0, 0.95]` | 每帧历史权重上限；`0` 是不分配历史、不编译时域 shader 的精确 no-op |
| `historyFrames` | 8 | `[1, 64]` | 保留样本上限；有效权重从第 2 帧的 0.5 递增到 `min(temporalBlend, (historyFrames-1)/historyFrames)`，计数器饱和，不随帧数无界增长 |
| `temporalDepthRejection` | 0.02 | 有限，`[1e-4, 0.5]` | 相对 previous-depth 窗口，米制，保留 1 m 下限 |
| `temporalNormalRejection` | 0.9 | 有限，`[0, 1]` | 当前与历史 octahedral normal 的最小点积 |
| `temporalVelocityRejection` | 64 | 有限，`[0, 4096]` | 最大重投影像素数 |

新增 `temporalActive()`（`temporalBlend > 0`）、`historyWeightFor(accumulatedSamples)`、
`depthTolerance(expectedPreviousDepth)`，以及 5 个 `withTemporal*` setter 和 builder 入口。
`disabled()`/`defaults()` 的时域值保持关闭。

### Pass 与目标

- `SsgiPass` 仍是唯一的公开 owner；`SsgiPass(SsgiSettings, int width, int height)` 在
  `temporalActive()` 时创建第二个 program（`ssgi-temporal.frag`）、私有 staging target 和
  双 slot 历史；旧 `SsgiPass(SsgiSettings)` 保持空间路径，传 temporal 设置但无 extent 时
  fail-closed。
- 每帧先由 `ssgi.frag` 的 temporal 模式把**新增弹射**（不含 base）写入私有 staging target，
  再执行 `ssgi-temporal.frag` 一次 MRT draw：
  - attachment 0 = 累积新增弹射（下一帧历史，避免 base 反馈）；
  - attachment 1 = 正 view depth + octahedral normal + surface flag；
  - attachment 2 = `base + accumulatedAdded`，由 `PostProcessPipeline` 作为
    `SSGI_COLOR` 外部附件发布。
- `SsgiPass.TemporalInputs` 是 nested public 输入合同（颜色/depth/normal/roughness/albedo、
  velocity/previous-depth/validity、jittered inverse projection、projection、view、
  可选环境源、extent），所有矩阵防御性复制；stable view-projection 不进入合同，相机切镜
  由 pass 自己比较 inverse view 与 inverse projection 判断。
- `PostProcessPipeline` 在时域分支使用 `writeToExternalTarget()`，每帧
  `synchronizeTemporalImports(graph)` 重新发布当前写 slot；历史只在
  `frameSucceeded()` 后交换。`prepareResize`/`commitResize` 增加 SSGI candidate，
  `frameFailed()` 保留旧读 slot，`invalidateTemporalHistory(...)` 同时清空 SSGI 历史。
- 共享 surface 在 `SceneBufferRequirements.ssgi(true)` 中额外请求 `VELOCITY`、
  `PREVIOUS_SURFACE_DEPTH`、`VALIDITY`；`PipelineTopology` 按 `temporalActive()` 选择。
  `validateSurfaceInputs` 在缺少这三条时在正式帧前拒绝。

### 重投影、拒绝与 clamp

1. 当前像素 `uv = (pixel + 0.5) / extent`；历史 UV 为
   `previousUv = uv + velocity - currentJitter + previousJitter`（velocity 是
   stable-raster 位移；两个 jitter 都是归一化 UV）。当前帧已经以 `currentJitter`
   栅格化，历史 texel 则以 `previousJitter` 栅格化，因此必须先减去当前 jitter、
   再加回上一帧 jitter；043e36bb 之前遗漏这两项，TAA 下历史会偏一个 jitter 差。
2. 逐像素接受条件（全部满足）：
   - `validity >= 0.5`（相机切镜、首帧、无效变形和缺失 previous surface 都写 0）；
   - velocity 有限且 `|v| < 4`，`previousUv` 在 `[0,1]` 内，像素距离
     `<= temporalVelocityRejection`；
   - `expectedPreviousDepth = previousDepthTexture(pixel)` 为正；
   - 2x2 历史 state 的 `|depth - expectedPreviousDepth| <= depthTolerance`；
   - 历史 normal 与当前 normal 的 octahedral 解码点积 `>= temporalNormalRejection`。
3. 被接受的历史先做 depth-matched 3x3 当前 GI 邻域 clamp；邻域为空时（薄轮廓/单像素洞）
   不做 clamp，避免把唯一当前像素当作 AABB 而误杀历史。
4. 混合：`added = history * w + spatial * (1 - w)`，`w = historyWeightFor(acceptedFrames + 1)`；
   首帧 `w=0`，输出严格等于空间样本。
5. 生命周期：`beginFrame` 标记 candidate；`frameSucceeded` 交换 slot 并把保留样本数 +1；
   `frameFailed` 丢弃 candidate；显式 `invalidate()`、resize、相机切镜清空历史。
   相机切镜由 `SsgiPass.looksLikeCameraCut` 额外检测：平移 > 4 m、前向点积 < 0.8，
   或反投影 depth mapping / FOV-aspect 线性部分的相对变化 > 1e-3；jitter 只改
   clip x/y 平移列，因此不会误触发。切镜帧本身仍提交，并从 1 个样本重新开始。
6. 历史从不被读于未初始化状态：新 slot `valid=false` 时 shader 不采样历史；写 slot 在发布前
   由一次全屏 draw 完整覆盖。

### 确定性、成本与限制

- 每帧序列 rotation 由 `rotationIndex * 0.61803398875 mod 1` 决定，`rotationIndex` 只在
  成功帧后自增并按 64 取模（有界）。空间路径不进入 rotation 分支，
  `uTemporalMode=0`，因此 `temporalBlend=0` 的输出与改动前逐字节一致。
- 时域 shader 每像素最多 2 次直接 fetch + 4 次历史 tap + 3x3 当前 GI/深度邻域 + base/depth/
  normal/velocity/validity；无 `while`、无随历史长度增长的循环、无 CPU 读回。
- 历史成本约每像素 3×RGBA16F（历史色 + state + composite）× 2 slot + 1×staging；
  未做 GPU 毫秒/带宽测量，性能 `NOT_EVALUATED`。
- 时域仍复用冻结的 single-sample velocity 合同；移动物体若未写正确 velocity 仍会靠
  depth/normal 拒绝兜底。没有逐通道协方差、方向性辐照度重建、多次弹射、
  屏幕外几何重建或 #34 信号适配。
- 只覆盖 SSGI 自身历史；不改变 SSR 的 `TemporalDenoisePass`，也不与其共享历史。

## 第二次验收：TAA jitter 反例与边界证据（2026-11-13）

日期：2026-11-13。代码提交 `ccfa06c0`（基于集成 HEAD `4b1f3e62`）。043e36bb 已把

### 反例数学

静态接收面、velocity = 0、TAA 风格两帧交替 jitter `+0.5 / -0.5` 像素
（`uCurrentJitter = ±0.5/48`）时，正确的历史地址为：

| 帧 | current jitter | previous jitter | 历史偏移 `-j_cur + j_prev` |
|---|---|---|---|
| 1 | -0.5 px | +0.5 px | **+1 px** |
| 2 | +0.5 px | -0.5 px | **-1 px** |

若帧 0 的历史为 `S_0(x)`，则：

```text
H1(x) = 0.5 * S0(x+1) + 0.5 * S1(x)
H2(x) = (2/3) * H1(x-1) + (1/3) * S2(x)
```

- 遗漏 jitter 的旧公式（`uv + velocity`）在帧 1/2 都取 `x`，得到 `H2 = S(x)`；
- jitter 符号反转取 `x+1`（帧 1 取 `x-1`），得到第三个不同的递推；
- 采用周期 3 的合成信号 `S = {1.0, 0.0, 0.5}` 时，帧 2 的三个值分别为
  **0.8333（契约）/ 1.0000（遗漏）/ 0.6667（反号）**，两两差 0.1667，远大于
  JVM 的 0.1 判别阈值。

JVM `SsgiTemporalReferenceTest.taaJitterMovesTheHistoryAddressByTheJitterDelta` 与
`jitteredRecurrenceSeparatesTheContractFromMissingOrFlippedJitter` 固定上述公式和
数值；`SsgiTemporalReference` 新增带 jitter 的 `previousUv` 重载及两个仅测试用反事实
helper。

### GL 反例 fixture

`SsgiTemporalGlTest` 新增两个 case，均使用同一 48×48 合成接收面：

1. `nonzeroJitterReprojectsToTheStableNeighbourAndRejectsTheCounterfactuals`：
   - 接收面 albedo 按列周期 3（0.95/0.10/0.55），历史地址在 `x±1` 时空间 GI
     有强对比；帧 1/2/5/7 的 GPU 输出逐像素匹配独立 double 递推（容差 0.02）；

   - 第 8 帧在非零 jitter 下显露更近表面（6 m → 3 m）：jitter 修正后的历史 tap
     仍是 6 m，previous-depth 期望 3 m，历史被拒绝，输出匹配空间样本且与
     ghost 混合距离 **> 0.1**；

### 仍明确的边界

- 时域用例仍是固定两帧交替 jitter（不是 Halton/多相位 TAA 序列）；velocity 是
  合成 uniform 对象速度，previous-depth 由同一静止平面提供，不覆盖真实移动几何的
  previous-depth/validity 生产链。
- missing/flipped 仍是测试侧独立预测，不是把生产 shader 回滚后重跑。
- 空邻域回退的代价是：薄接收面在每帧直接采用当前单样本（不再跨帧平均），
  在低样本/高方差时可能更噪；这是有界正确性优先的取舍。
- 未新增 RenderPipeline 端到端帧、性能/显存或人工视觉证据，`NOT_EVALUATED`。

### 展馆的半分辨率空间路径

- `SsgiSettings.halfResolution` 默认为关闭，既有构造器继续选择全尺寸。半分辨率模式与时域累积互斥，组合请求在配置构造期拒绝。
- 借用全尺寸 HDR、深度、世界法线、粗糙度和反照率。以向上取整的半宽、半高追踪，记录反弹光与接收面的正值视空间深度。水平方向和竖直方向各做一次最多 37 点的滤波。用连续相邻深度估计局部斜率，避免把倾斜接收面当作边缘。深度断层和法线变化仍限制滤波。全尺寸合成乘当前像素的反照率并保留 HDR alpha。
- RenderGraph 管理三张半分辨率 RGBA16F 附件与全尺寸输出，随图事务调整尺寸。1440p 三张附件合计约 21.1 MiB。`SsgiPass` 拥有 trace、filter、resolve program 和复用 quad。模式没有历史附件。展馆固定 8 条射线、每条至多 8 步，1440p 的接收面追踪位置上限由约 369 万降为约 92 万。
- 独立验证覆盖同一平面重建、深度和法线边缘拒绝、奇数分辨率布局与资源释放。既有空间与时域参考继续覆盖全尺寸分支。展馆同机位的 GPU 时间与开关截图记在 `build/exhibition/ssgi-probe/`。
