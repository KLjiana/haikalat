# 0.28.1 S3 #14 有限水面技术卡（Water Surface）

日期：2026-11-11。状态：首版生产实现已写入；JVM 合同与真实 GL 用例均已执行并通过。对应 46 项路线图 #14，调度范围见 [multi-agent full delivery](haikalat-multi-agent-full-delivery.md) 的 S3 行。

## 技术卡

| 字段 | 内容 |
|---|---|
| 技术 ID／用户场景 | #14 水面；为 S3 水体场景提供有限、可配置、时间驱动的平面水面，并为后续 #11 水面折射提供受控的表面/深度合同。首版默认关闭。 |
| 当前基础／差距 | 已有共享 `scene.depth`（raster 深度或 MSAA 多采样深度）、HDR `SceneColor`、`CameraBlock`、PBR `PbrEnvironment` 预滤波立方图、`PostProcessPipeline.sceneColorInput` 与候选代/借用资源协议。缺少有限水面设置、解析波法线、深度吸收与岸边过渡。 |
| 首版范围 | 一个世界空间轴对齐矩形（`minX/minZ/maxX/maxZ`，`y == level`）的平面水面；两列确定性正弦波的法线；深度重建得到的垂直水厚；Beer-Lambert 吸收近似；`smoothstep` 岸边过渡；Fresnel 加权的 IBL/天空反射（无 IBL 时使用显式回退色）。**排除**完整水下渲染、折射（#11）、屏幕空间反射、流体模拟、泡沫/焦散和体积雾合成。 |
| 模块与控制 | 新职责包 `subsystems.render3d.water`：advanced `WaterSurfaceSettings`（唯一配置值）与 internal `WaterSurfacePass`（shader、单位矩形 mesh、cubemap sampler）。`RenderFeature.WATER_SURFACE` 与 `RenderFeatureSettings.waterSurface(...)` 统一发布；`RenderPipeline.waterSurface(...)` 在 build 前配置，`applyWaterSurface(...)` 在帧边界发布。默认 `WaterSurfaceSettings.disabled()`；`enabled=false` 时图里没有 pass、shader 或附件。 |
| 输入 | 已解析的 HDR 场景颜色（`GeometryPass` 颜色附件）、共享 raster 场景深度（单采样 `sceneDepth` 或 MSAA `sceneDepthMS`，与几何样本数一致）、`TemporalFrameState` 的 jittered projection、view、inverse jittered projection、near/far 与相机位置、可借用 `PbrEnvironment.prefilteredSpecular()`、本帧累积波时间。水面 pass 通过显式 `uProjection/uView` uniform 获得本帧矩阵，不依赖共享 `CameraBlock`。坐标为世界空间右手系，1 单位按米解释。 |
| 输出 | 独立全尺寸 `waterSurfaceColor`（RGBA16F）；不写共享深度、不修改几何颜色附件。关闭/无水体时下游颜色链保持原 `SceneColor`。颜色为线性 HDR；水面以 `SRC_ALPHA/ONE_MINUS_SRC_ALPHA` 合成在复制后的背景上。 |
| 水面几何 | 单位 XZ 矩形 mesh（4 顶点、2 三角形）经逐帧模型矩阵 `T(center, level) * S(width, 1, depth)` 放置；有限边界由几何裁剪保证，屏幕外/矩形外像素只保留复制后的背景。 |
| 波法线 | 确定性双列正弦：`k1 = 2π/wavelength`，主方向 `d1=(cos θ, sin θ)`；次列 `k2=1.7k1`、`d2=(-sin θ, cos θ)`、权重 0.5、固定相位 1.3。`H = A[sin(k1 d1·p - ω1 t) + 0.5 sin(k2 d2·p - ω2 t + 1.3)]`，`ω = k·speed`；法线 `normalize(-∂H/∂x, 1, -∂H/∂z)`。CPU 对应为 `WaterSurfaceSettings.waveNormal(...)`，shader `waveNormal()` 使用同一常数。 |
| 吸收／岸边 | `thickness = level - sceneWorldY`（由共享深度反投影得到；深度为远平面时按 `level - farPlane` 视为深水）。`absorb = 1 - exp(-density·thickness)`，`shore = smoothstep(0, shoreFadeDistance, thickness)`；输出 `color = mix(waterColor, reflection, fresnel)`，`alpha = shore · mix(absorb, 1, fresnel)`。`fresnel = 0.02 + 0.98(1-N·V)^5`。 |
| 遮挡与相交 | pass 没有深度附件（必须采样唯一一份共享深度），逐片段比较水面视图深度与场景视图深度：场景更近则丢弃水面；场景远于水面则继续着色。相交/掠射限制：水面视图深度超过相机远平面、或视线方向 `|dir.y| < 1e-3` 时丢弃，像素保留背景，避免无界 Fresnel/除零。 |
| 反射近似 | `reflect(view, normal)` 经 `uEnvironmentRotation` 旋转后采样 `prefilteredSpecular` 基础 mip，乘环境强度（与 PBR 一致的逐管线 IBL override）；无借用环境时使用 `reflectionFallback` 线性色。首版不做 SSR、平面反射或 Fresnel 粗糙度分层。 |
| 参数校验 | `level ∈ [-10000,10000]`；每轴 bounds 宽度/深度 `∈ [0.05, 20000]` 米；`wavelength ∈ [0.05,100]` 米；`speed ∈ [-8,8]`；`amplitude ∈ [0,0.35]`（斜率量纲）；`absorptionDensity ∈ [0,8]` 1/m；`shoreFadeDistance ∈ [0,10]` 米；颜色分量 `∈ [0,16]`。全部要求有限，非法值在设置构造期拒绝而非静默夹取。`waveDirectionRadians` 规范化到 `[0,2π)`。 |
| 装配关系 | `PipelineTopology.waterSurface()` 仅在 `enabled=true` 时把 DEPTH 并入 raster 表面请求（与几何同样本数），因此水面总能拿到真实深度且不需要额外 resolve 拷贝。Pass 顺序：`SceneSurfacePass → GeometryPass → WaterSurfacePass → [TAA/Fog/DOF/…]`。`PostProcessPipeline.sceneColorInput("waterSurfaceColor","WaterSurfacePass")` 让后续 HDR 链依赖水面；MSAA 时 HDR resolve 源改为水面 pass。 |
| 依赖校验 | 水面要求 HDR tone mapping（线性 HDR 吸收合成）；明确拒绝与体积雾同时启用（体积合成读取 `GeometryPass` 颜色，首版未接入水面），由 `RenderFeaturePolicy` 与 `PipelineFeaturePolicy` 双重拒绝。解析雾/TAA/DOF/Bloom 等既有 HDR 消费者可继续消费水面颜色。 |
| 资源与失败 | `WaterSurfacePass` 拥有 shader、单位 mesh 与 cubemap sampler，由 `PipelineGeneration` 关闭；同样本数的候选代可借用 donor，`adoptBorrowedResources` 转移生命周期。借用颜色/深度 framebuffer、环境立方图与调用方 recorder 不释放。无历史、无 GPU 读回、无 `glFinish`。候选失败时按既有候选清理路径释放自有资源。 |
| 时间语义 | `RenderPipeline` 每成功执行帧累积 `deltaSeconds`，上限 3600 s（float 相位精度）；`waveSpeed=0` 时法线不随时间变化；同一输入序列得到同一水面。暂停时时间不推进，恢复不跳变。 |
| 成本／回退 | 每帧 1 次全尺寸颜色 blit + 1 次矩形 draw + 1 张全尺寸 RGBA16F 附件；关闭时零成本、零附件。启用水面会在无其他 surface 消费者时新增一个 depth-only `SceneSurfacePass`（与解析雾/景深同机制），该几何开销另计。未做 GPU 性能测量，成本状态 `NOT_EVALUATED`；回退是关闭开关。 |
| 参考与许可 | 波/吸收/岸边/反射公式均为项目自写；无第三方 shader 或资产，水面为程序化几何。独立 JVM/GL 参考使用测试内从公开公式重写的实现与手算数值，不以当前 GPU 输出当真值。 |
| 验证范围 | JVM：设置边界/禁用 no-op/波法线对照双列公式/吸收与岸边参考/防御性拷贝，`PipelineTopology` 的 water 深度请求与非法组合拒绝；`.\gradlew.bat logicVerification` = PASS。GL：`WaterSurfacePassGlTest`（吸收/岸边/有限边界、解析法线对照、掠射有限性）与 `WaterSurfacePipelineGlTest`（enabled/disabled 图、矩形内外、吸收/岸边响应、时间变化、MSAA resolve）；`.\gradlew.bat glSmoke --tests "*WaterSurfacePassGlTest" --tests "*WaterSurfacePipelineGlTest"` = 6/6 PASS、0 skipped。GL 用例的读回索引使用 `window.width()/height()` 的实际 framebuffer 尺寸（隐藏窗口实测为 152×64），不使用请求尺寸。 |

## 明确限制与未验证项

1. 首版不实现水下体积、折射、吸收散射分层、泡沫、焦散或流体模拟；水厚只由共享不透明深度的垂直差近似，透射背景颜色来自复制后的场景颜色。
2. 反射是预滤波 IBL 基础 mip 或固定回退色，不是屏幕空间反射；高光反射不区分粗糙度，也没有平面反射的镜像相机/裁剪。
3. 半透明 VFX/粒子不写共享深度，因此水厚与岸边只按不透明表面计算；透明物体与水面交错的正确折射/遮挡不在本版承诺内。
4. 与体积雾互斥；MSAA 路径的逐片段深度比较固定使用 sample 0（`texelFetch(..., 0)`），不做逐样本水面着色。
5. 波法线是解析法线，不位移顶点；水面轮廓始终是平面矩形，不随波峰起伏，也不产生几何自遮挡。
6. 时间为线性累积且上限 3600 s；长时间运行需要重开管线或接受波相位冻结。
7. 未做 GPU 性能/显存测量；成本 `NOT_EVALUATED`。
8. 真实 GL 用例已在 NVIDIA RTX 3050 Laptop / 576.88 上执行并通过；未验证其他 GPU/驱动。GL 读回按实际 framebuffer 尺寸索引，隐藏窗口的请求尺寸与实际 framebuffer 尺寸不同（实测 64×64 请求得到 152×64 framebuffer），测试固定使用实际值。
