## 模拟离散合同

1. **固定步与确定性**：每次 `step(cmd, n)` 记录 n 个 `dt = timeStepSeconds` 的 dispatch；shader 只读旧场、
   写另一张场，无时间/帧号/随机输入。源在步骤 *s* 的速率由 `s·dt` 是否落在
   `[startSeconds, endSeconds)` 决定，CPU 作为 uniform 上传，因此**相同 settings + 相同步数 ⇒ 相同命令序列**。
   `replay(cmd, n)` = `reset` + n 步；GL 用例 d 断言重放场与首次场逐字节相等。
2. **速度与浮力**：单元速度 `v = wind + (0, buoyancy·T, 0)`，`T` 先 clamp 到 `[0, maximumTemperature]`。
   面法向速度为两侧单元速度均值；x/z 面只有风分量，y 面由两侧温度决定。
3. **封闭边界**：每个轴的最外侧面法向速度**恒为 0**（不采样边界外，也不使用外部零值通量）；
   Jacobi 更新下总质量在注入与消散之间精确守恒（浮点求和除外）。GL 用例 c 用朝外侧风长时间
   推进后比较注入后总质量。
4. **通量与更新**：标量通量为一阶 upwind（`v>0 ? v·left : v·right`），
   `S' = (S − dt·(∂Fx/∂x+∂Fy/∂y+∂Fz/∂z))·exp(−k·dt)`。密度与温度共享同一速度场但各有独立
   dissipation/cooling；指数因子不会产生负值。
5. **注入**：源球内的网格中心按 `(1−q)²`（`q = |p−c|²/r² < 1`，否则 0）加入
   `rate·dt·weight`；密度与温度分别累加，温度再次 clamp。源必须完全位于 AABB 内。
6. **稳定性**：settings 构造期强制
   `dt·(|wx|/hx + (|wy|+buoyancy·Tmax)/hy + |wz|/hz) ≤ 1`；`maximumStableTimeStepSeconds()` 提供保守上限。
   这是显式一阶 upwind 的 CFL 条件，超过即拒绝而不是静默 clamp。温度始终有界；密度有非负/非有限守卫。
7. **暂停/重放/重置**：`SmokeTimeline` 保存 accumulator、stepCount、paused。`advance` 每帧最多
   `maximumStepsPerFrame` 步，超出部分丢弃（不形成追帧债务）；暂停不累计墙钟，恢复不补步。
   `reset` 清零两个场和步数但保留 paused；`replay` 先 reset 再重放。
8. **不是完整流体**：没有压力投影、涡量/curl、速度自平流、障碍物碰撞或自适应/稀疏网格；速度场是
   风 + 温度浮力的规定场。网格是固定轴对齐 AABB，越界不存在介质。
9. **源时间边界语义**：步骤 *s* 的时间为 `s·timeStepSeconds`（double）；`timeStepSeconds` 是 float，
   `dt·n` 与十进制端点可能相差约 1e-9，窗口比较不额外加容差。作者应选择能被步时间明确区分的端点；
   GL fixture 用 0.09/0.19 秒而不是 0.1/0.2 秒，避免端点归属歧义。

## 体积渲染与合成合同

1. **单介质**：shader 只声明 `uSmokeField`（sampler3D）与 `uSceneDepth`（sampler2D），不声明场景颜色、
   雾密度/source 或粒子纹理；因此本介质只由本 Pass 积分一次，雾/#38 分别由各自 owner 积分一次。
   调用顺序见技术卡 Pass 顺序；这是顺序分层近似，不是把三个介质放进同一射线联合积分。
2. **射线与深度**：世界射线由逆投影/逆视图重建；AABB slab 相交时对 `|direction|<1e-9` 的分量显式
   判断（避免 0·∞ = NaN）；可见区间 = `[max(entry,0), min(exit, surfaceDistance)]`。表面在体积前 →
   区间为空 → 输出 0（OCCLUDING 下 alpha=0，背景逐字节不变）；表面穿过体积 → 只积分到表面。
3. **步长/预算**：`stepLength = max(span/maxSteps, stepSizeMetres)`，
   `steps = clamp(ceil(span/stepLength), 1, maxSteps)`，中点采样。区间变长只会加粗步长，不突破每像素预算。
4. **能量**：`σ_e = densityScale·density·(absorption+scattering)`，
   `albedo = scattering/(absorption+scattering)`；单次散射逐段
   `S += T·light·phase·albedo·(1−exp(−σ_e·δ))`，`T *= exp(−σ_e·δ)`，光学深度上限 88 保持有限。
   相位与雾/#38 共用归一化 HG 与 `max(0.01, …)` 下限；`μ = dot(lightDirection, −rayDirection)`。
5. **权重/合成**：`contributionWeight ∈ [0,1]` 乘在光深上恰好一次；`0` 是精确 no-op（GL 用例 e 断言
   逐字节一致）。`OCCLUDING` 使用 `ONE, ONE_MINUS_SRC_ALPHA` 并保留目标 alpha；`ADDITIVE` 使用
   `ONE, ONE` 且忽略 coverage。
6. **覆盖率**：以 AABB 8 角投影出屏幕矩形并开 scissor；跨越眼平面保守取全屏；覆盖占比超过
   `maximumScreenCoverage` 时在写任何命令前 fail-closed。完全离屏时只 blit，不 draw。
7. **单采样/无历史**：只接受已解析单采样颜色与深度；不支持 MSAA 原始附件、TAA/jitter/velocity，
   不共享任何历史。

## 明确限制与不支持项

- 不是完整流体：无压力投影/不可压约束、无速度自平流、无涡量、无障碍物/地形碰撞、无自适应网格；
  速度场为风 + 温度浮力。
- 不是 #38 或雾的替代/复用：三套介质各自积分一次；不建模它们在同一条射线上的前后交错顺序。
- 光照只有单方向常量光与 HG 单次散射；无阴影、无多次散射、无自发光/温度黑体颜色。温度只驱动浮力，
  不参与体积渲染颜色。
- 网格只能轴对齐 AABB；不支持旋转/缩放网格、稀疏块、跨 AABB 边界的源。
- 最多 4 个源；源窗口上限 3600 s；网格每轴 8–64。
- 密度/温度存 RGBA16F：长时间以最大速率注入可溢出 half 范围（约 1023 s 连续 64/s 于单格），
  shader 会把非有限值清零（会损失该格质量）；生产应使用有界爆发/消散。
- `step`/`advance`/`replay` 在**命令记录完成**后提交 CPU `stepCount`；若之后 GPU 执行失败，CPU 步数
  与已写场不会自动回滚（没有成功帧回调）。`reset`/`replay` 可确定性恢复；Integrator 应把模拟推进放在
  可丢弃失败帧/成功帧边界，或失败后显式 `reset`。
- 体积 Pass 假定调用方在同一 GPU owner 线程、同一帧内先完成模拟命令再记录；不替调用方同步或排序。
- 无 TAA/jitter/velocity/历史；只接受单采样已解析颜色与深度；不支持 MSAA 原始附件。
- `SmokeVolumePass` 是完整消费者，生产 `RenderPipeline` 接线已由 Integrator 补全（见“生产接线”）；
  TAA/MSAA、体积雾/粒子/云的同射线交错顺序仍不在首版合同内。
- 未做真实 GL 编译/执行、GPU 性能、显存峰值、多硬件、Debug 回调策略、端到端场景视觉或人工画质签收。

## 生产接线（Integrator，`codex/render-wiring-b2`）

生产入口（均默认 `SmokeSimulationSettings.disabled()` + `SmokeRenderSettings.disabled()`；禁用时
不创建 simulation、volume pass、目标或 draw，拓扑 key 与基线逐字节一致）：

| 名称 | 语义 |
|---|---|
| `RenderPipeline.smokeSimulation(settings)` / `smokeSimulation()` | build 前配置 simulation owner；不暴露 3D 场句柄。 |
| `RenderPipeline.smokeRender(settings)` / `smokeRender()` | build 前配置体积消费者；不暴露目标。 |
| `RenderPipeline.applySmokeSimulation(settings)` | 帧边界事务：设置相等时直接返回；否则构建完整候选代（网格/source 变化会重建 owner），失败保留旧代、旧 simulation 与旧设置。 |
| `RenderPipeline.applySmokeRender(settings)` | 同上；渲染设置变化重建 volume pass，若 simulation 设置未变则借用同一 simulation owner。 |
| `RenderFeatureSettings.smokeSimulation(...)` / `smokeRender(...)` | 第 21/22 个 canonical 组件；builder、`defaults()`、`toBuilder()` 与统一批量入口。 |
| `RenderFeature.VOLUMETRIC_SMOKE` | `RenderFeaturesControl.activities()` 的有效/不可用原因（`ACTIVE`、`DISABLED`、`PAUSED_BY_MASTER`、`UNAVAILABLE`）。 |
| `PipelineTopology.volumetricSmoke` / `volumetricSmokeCompositionActive(...)` | 只在“simulation active + render active + HDR + 非 MSAA/非 TAA + 同帧单采样深度”时进入拓扑 key；否则请求保持 `UNAVAILABLE` 且不改变图。 |
| `SmokeVolumePass.COLOR_TEXTURE` | 图节点颜色附件逻辑名（`volume.smokeColor`）；pass 自有目标经一次全屏 blit 写回图颜色链。 |

图顺序与模拟阶段：

```text
SmokeSimulation (compute, deterministic sim stage; zero colour/depth consumers)
  -> GeometryPass -> VolumetricOpaqueComposite -> VolumetricParticlePass（可选）
  -> VolumetricTransparency（可选） -> WaterSurfacePass（可选） -> RefractionPass（可选）
  -> StochasticTransparencyPass（可选） -> VolumetricCloudPass（可选）
  -> SmokeVolumePass（复制上一位颜色生产者，烟雾介质只积分一次）
  -> post-process HDR 链
```

- 模拟 compute pass 零依赖、在帧的固定位置记录一次；`SmokeSimulation.step` 自带 image/fetch
  barrier，体积 pass 通过 `dependsOn(SmokeSimulation.PASS_NAME)` 保证在其之后。每帧
  `advance(cmd, deltaSeconds)`，暂停/重放/固定步语义沿用 owner。
- 体积节点由 `RenderPipeline.addSmokeVolumePass(...)` 声明，消费上一位颜色生产者与共享单采样
  不透明深度；图节点只声明颜色附件、**不声明深度附件**。记录后由图节点 blit 回图颜色链。
- 依赖与 fail-closed：`PipelineFeaturePolicy` 拒绝“smoke active 但无 HDR / 非单采样 / TAA / 无单采样
  深度”的外来拓扑；`RenderFeaturePolicy` 对“render active 但 simulation disabled”报 `UNAVAILABLE`，
  不创建半套资源。MSAA/TAA 不改变图。
- 失败帧：若模拟 compute 已记录、后续帧失败，下一帧先 `reset(cmd)` 再 `advance(...)`，避免从未知
  步数继续；成功帧不额外读回。
- resize：`SmokeVolumePass` 走候选代新目标事务，`SmokeSimulation` 网格与步数保持不变；关闭时先
  close volume pass 再 close simulation，幂等并释放全部私有资源。
