## 密度、光照与合成合同

1. **单一云场复用 #10**：`VolumetricCloudSettings.coverageField` 直接持有既有
   `CloudShadowSettings` 值。`cloud-march.frag` 中的 `cloudShadowHash/cloudShadowNoise/
   cloudShadowDensity` 与 `pbr-forward.frag` 为**同一源文本**（`VolumetricCloudShaderTest`
   对函数体做规范化后逐字比较），阈值/softness 映射与风偏移表达式
   `vec2(0.8, 0.6) * (uCloudShadowTime * max(uCloudShadowSpeed, 0.0))` 也相同。
   差异只在投影：可见云层取云自身的世界 `xz`，#10 把接收面沿光方向投影到过原点的平面。
   因此“一份授权参数/一套噪声”成立，但阴影足迹与可见云层不是同一投影（见限制 1）。
2. **密度场**：`density(p) = extinction · mask(p.xz, time) · profile(p.y)`，
   `extinction = density · (absorption + scattering)`，
   `profile(y) = smoothstep(0, 0.25, t) · (1 − smoothstep(0.75, 1, t))`，
   `t = (y − base)/(top − base)`；层外密度**精确为 0**。这是解析高度带，不是局部天气网格。
3. **有界步进**：先求射线与高度带的交区间并按不透明深度截断；
   `stepLength = max(span / maximumSteps, stepSizeMetres)`，
   `steps = clamp(ceil(span/stepLength), 1, maximumSteps)`，中点采样。因此步长是质量旋钮、
   `maximumSteps` 是每像素硬上限；水平射线在层内时区间上限为 30 km（`CLOUD_MAX_HORIZONTAL_DISTANCE`），
   不会出现无限区间。
4. **有界光照**：仅当朝向光的方向 `toLight = −lightDirection` 有正 y 分量时做光照；
   距离为到层顶的解析距离并 clamp 到 `maximumLightDistanceMetres`，
   固定 `lightSteps` 个中点样本。光源在层下方（`toLight.y ≤ 1e-4`）时直接光为 0（只有透射率）。
5. **单次散射与能量**：`S += T · light · phase · albedo · lightTransmittance · (1 − e^{−σδ})`，
   `T *= e^{−σδ}`，`phase` 与体积雾/粒子共用归一化 HG 及 `max(0.01, …)` 分母下限。
   因此 `S ≤ light · phase · albedo · (1 − T)`，`T` 单调、有界；无多次散射、无阴影图、
   无自发光、无 IBL 耦合。
6. **深度与背景**：只接受单采样不透明深度；表面在云层之前 → 区间为空 → `S=0,T=1`，
   OCCLUDING 合成后该像素与源颜色**逐字节相同**；清空深度视为无遮挡。合成式为
   `out = S + T · scene`（`texelFetch`，不采样正在写入的附件）。
7. **低分辨率渲染**：`renderScale ∈ [0.1, 1]`，低分辨率尺寸唯一规则
   `max(1, round(extent · renderScale))`（Pass 与测试共用）。march 用低分辨率像素的 NDC 建射线，
   但用包含它的**全分辨率**像素中心取深度，避免为深度单独降采样。
8. **空间重建**：目标像素对 2×2 低分辨率云 texel 做双线性加权，权重乘以深度相似度
   `exp(−|centerDepth − tapDepth| / depthToleranceMetres)`；表面/背景不匹配的 tap 权重为 0；
   全部被拒绝时回退到最近 texel。深度来自 tap 中心对应的全分辨率像素。
9. **时域历史与拒绝**：历史是全分辨率 S/T 与 state（锚点深度/曝光/权重/有效位）。
   Java 侧在 `cameraCut`（位移、朝向、投影变化超阈值）或 `exposureAccepted == false`
   （相对变化超阈值、曝光非正/非有限）时整帧拒绝；shader 侧再逐像素拒绝
   （全局无效、上一 slot 无效、重投影 UV 越界、`|storedDepth − expectedDepth| > max(1e-4, 2%·depth)`）。
   接受的历史先 clamp 到当前 3×3 低分辨率范围，再按 `historyBlend` 混合（`currentWeight = 1 − historyBlend`）。
10. **事务**：历史只在整帧成功后交换；失败/未记录帧丢弃候选，`historyCloudTexture()` 不变；
    resize 先分配完整候选（低分辨率目标 + 历史对 + 输出目标）再发布，失败保留旧目标。
11. **关闭即 no-op**：`disabled()` 的构造被拒绝，Pass 不创建任何 GPU 资源；生产中关闭时
    不调用 `record`，场景颜色链逐字节不变。
12. **无读回**：生产 Pass 不调用 `glGetTexImage`/`glReadPixels`/`glMapBuffer`/fence；
    GL 用例中的读回仅为测试证据。

## 建议质量档（调用方配置，不是内部预设）

| 档位 | renderScale | maximumSteps | stepSizeMetres | lightSteps | 说明 |
|---|---|---|---|---|---|
| Low | 0.25 | 16 | 80 | 2 | 远景/俯视天幕；低分辨率 + 柔和重建 |
| Medium | 0.5 | 32 | 40 | 4 | 默认候选；700 m 层厚下约 10 次 view 步 |

## 成本与显存（估算，未测量）

以 1920×1080、`renderScale = 0.5` 计：

| 资源 | 每像素 | 显存 |
|---|---|---|
| 输出目标（RGBA16F） | 8 B | ≈ 15.8 MiB |
| 历史 2 slot ×（S/T + state，各 RGBA16F） | 32 B | ≈ 63.3 MiB |
| 低分辨率 march 目标（0.5 尺度，RGBA16F） | 2 B（等效全分辨率） | ≈ 3.96 MiB |
| 合计 | 42 B | ≈ 83 MiB |

每低分辨率像素最多 `maximumSteps × lightSteps` 次密度/光照采样（Medium：32×4=128，
每次光照样本 3 个 octave 的 4 个 hash）；全分辨率重建最多 4 个云 tap、4 次深度取、
9 个 clamp tap、1 个历史 fetch + 4 个双线性历史 tap；合成为 2 个 texelFetch。
`historyBlend → 0` 时历史仍不写回退，成本不变。**GPU 时间/显存峰值/帧预算全部 `NOT_EVALUATED`。**

## 明确限制与未验证项

1. **阴影与可见云层不是同一投影**：#10 把接收面沿光方向投影到过原点的平面，本 Pass 在云的
   世界 `xz` 上评估同一 mask。两者共享参数、噪声与风偏移，但阴影足迹与可见云不会逐像素对齐；
   要严格对齐需修改 #10 的投影约定（属 S1 owner），本包不做。
2. **解析高度带，不是完整天气**：只有 `base..top` 的解析垂直剖面与 2D 覆盖率场；没有局部密度
   网格、温度/湿度、注入/消散/平流、云类型、降水、云粒子或云间遮挡。风速只做统一平移。
3. **单次散射/单方向光**：无多次散射、无阴影图自遮挡、无 IBL/环境光、无自发光、无逐点光源；
   光源在层下方时直接光为 0。强前向相位依靠与雾一致的 `0.01` 分母下限保持有界，是艺术近似。
4. **时域模型是相机重投影 + 邻域 clamp**：不建模云的风速速度场，也没有 reactive mask；
   快速移动的云在 `historyBlend` 较高时依赖邻域 clamp 抑制拖影，不保证无 ghosting。
   曝光拒绝是**整帧相对阈值**，不是逐像素曝光状态；积分/jitter 未接入。
5. **低分辨率近似**：march 使用低分辨率射线与低分辨率深度中心采样；在陡峭深度边界或薄云边缘，
   深度感知重建可能出现回退最近 texel 的局部近似；`renderScale` 越低误差越大。
6. **共享 #10 hash 的 binary32 敏感性**：`fract((p3.x+p3.y)*p3.z)` 的乘积在 GPU binary32 下
   有约 1e-3 的量化，并在整数附近 wrap；同一世界坐标在 double 参考与 GPU 上的 mask 可差
   百分之几（实测平均约 0.03，wrap 处可达 0.26）。这是 #10 接口本身的数值属性，不是本 Pass
   引入的第二种云场；因此 GL 参考比较采用 mask 场统计 + 由实测 T 反解有效 mask 的方式，
   而不是逐像素比对 hash 值。若未来要求逐像素 mask 一致性，需要 #10 owner 更换稳定 hash
   或加入 `precise` 约定，并同步其清单与参考值。
7. **未接线/未测**：真实 `RenderPipeline` 端到端场景、透明队列、MSAA 原始深度、TAA/jitter、
   连续运动重投影精度、暂停/重放、动态分辨率、GPU 性能/显存/帧时间、多硬件与 1920×1080 预算
   全部 `NOT_EVALUATED`；GL 两轮 7 case 各只有 horizon/disocclusion 子集通过（首轮 2 个、
