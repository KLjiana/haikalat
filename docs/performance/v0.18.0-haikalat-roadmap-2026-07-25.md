# v0.18.0 Haikalat 综合场景性能与稳定性报告

日期：2026-07-25

版本：`0.18.0`

环境：Windows、JDK 21、LWJGL 3.3.3、OpenGL 4.6、NVIDIA GeForce RTX 3050 Laptop GPU、
驱动 576.88。以下结果是当前机器的受控基线，不是跨硬件性能承诺。

## 综合场景

`HaikalatShowcaseDemo` 在同一 RenderGraph 中运行高级动画、PBR 与阴影、Bloom/LUT/雾、
体积光、CPU VFX、Compute/SSBO GPU 粒子和 retained UI。

| 场景 | 尺寸 / 帧 | 负载 | CPU update 平均 | RenderGraph GPU 平均 | 结果 |
| --- | --- | --- | ---: | ---: | --- |
| 综合像素验收 | 640×360 / 24 | CPU VFX 72、GPU 粒子 256、体积 24 步 | 5.3876 ms | 4.7886 ms | 230,400 个非黑像素，关闭后 GL 资源归零 |
| 综合性能基线 | 960×540 / 360，预热 60 | CPU VFX 256、GPU 粒子 2,048、体积 24 步 | 0.7596 ms | 0.6088 ms | 9 个动作事件、47 段 Ribbon、4 个 Decal |
| 长时间稳定性 | 320×180 / 3,600，预热 120 | CPU VFX 256、GPU 粒子 256、体积 24 步 | 0.2066 ms | 0.2275 ms | 预热后资源 identity/估算显存不变，退出后归零 |

综合像素入口包含首次 shader 编译等预热成本；性能和稳定性入口分别排除 60 帧与 120 帧预热。
GPU 粒子正式路径没有 CPU map/readback，长期运行以完整 GL resource sequence 集合与估算字节数
做前后等值检查。

## 发布回归

- `localMilestone4Verification` 通过高级动画 JVM、GPU effects 真实 GL、综合像素和 3,600 帧稳定性验证。
- `localReleaseVerification` 通过 48 个本地发布任务，覆盖既有 Demo、resize、glTF、UI、诊断、
  可见性、10,000 renderer allocation 与 static gate。
- v0.17.2 的结构化静态提交基线继续作为 `comparePerformanceBaseline` 的同机回归基准；v0.18.0
  没有用新增综合场景数据替换不同负载的历史基线。

受控 GPU 粒子、体积光、双层动画混合和方向光级联方案的能力边界见
`docs/guides/milestone4-api-performance-limitations.md`。
