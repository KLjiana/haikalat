独立 ignored noise shader 副本复用八个噪声格点共有的六个坐标乘积，代替原先每个格点分别计算的 24 个乘积。仍执行八次相同 avalanche hash，原浮点转换、插值顺序、seed、采样坐标与风场公式不变；未降低节点数、阴影面板或介质质量，未新增资源。原 volumeHash 外部函数保留。

独立 masked 64-bit 整数参考与新 32-bit 复用路径完成 8,388,608 个格点比较；实际旧/新 GLSL 对 16 个 seed、1,048,576 个坐标的 4,194,304 个输出字逐位一致。GPU 输出中的三个格点 hash 另与独立整数参考核对。输入覆盖负坐标、整数两侧、大幅度但可安全 floor 的坐标和 seed 位模式；输出原始二进制已逐文件再次核对。该 helper 对照尚不等于完整消费者和主场景验收。

最初验证夹具调用了不存在的 ShaderProgram.bind；修复为现有 glUseProgram(id) 后仅重跑短 oracle。失败源码与编译日志保留在 oracle-fixture-compile-failure，不计为通过。成功 oracle 严格 GL 日志 32 条允许的诊断读回提示、0 违规，未扩大 policy。
