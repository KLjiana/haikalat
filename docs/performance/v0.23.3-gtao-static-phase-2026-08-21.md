# v0.23.3 GTAO 静态场景时域稳定性报告

> 版本：`0.23.3`
>
> 日期：2026-08-21

## 补丁范围

v0.23.3 是 v0.23.2 的纯修复补丁，不改变 GTAO 的资源格式、采样预算、PBR 绑定或公开配置结构。
本补丁只调整 temporal sample phase 的触发条件：固定 view 保持 phase `0`，真实 view matrix
移动超过 `5.0e-4` 才轮换 deterministic phase。判定使用未带 TAA jitter 的 view matrix，避免
TAA 投影抖动被当作摄像机移动。

## 验收方法

| 场景 | 结果 |
| --- | --- |
| `test --tests "*GtaoPassesTest" --rerun-tasks` | 通过；覆盖原 phase 合同与静止 view phase 固定 |
| `glSmoke --tests "*GtaoShaderGlTest" --rerun-tasks` | 通过；shader/FBO/像素与历史路径保持兼容 |
| `runRender3dGtaoVisualDemo --hidden --gtao --preview --view=close --gtao-quality=high --gtao-radius=1.4 --gtao-strength=1.5 --frames=120` | 通过；固定近距 AO 预览 120 帧无 GL/资源错误 |
| `check --rerun-tasks` | 通过；25 个任务全部成功 |

## 性能与兼容性

- 新增两个持久 `Matrix4f` 和固定数组复用，不在稳定帧创建临时对象。
- GTAO 的质量、半分辨率、history 格式、texture unit 13 和间接光调制合同保持不变。
- 原 v0.23.2 性能基线与 4K disabled GPU 接受策略继续有效，详细历史数据保留在
  `docs/performance/v0.23.2-render3d-gtao-2026-08-20.md`。

## 结论

静止摄像机下的全屏统一 phase 轮换已移除；移动摄像机仍保留 temporal 采样轮换，并在开始/停止
移动时丢弃一次旧 history，避免相位模式切换产生单帧跳变。该补丁不改写 v0.23.2 历史标签。
