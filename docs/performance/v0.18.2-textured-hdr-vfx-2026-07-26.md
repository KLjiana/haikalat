# v0.18.2 纹理化 HDR VFX 性能与资源报告

日期：2026-07-26

环境：Windows、JDK 21、LWJGL 3.3.3、OpenGL 4.6.0 NVIDIA 576.88、
NVIDIA GeForce RTX 3050 Laptop GPU。以下为单机受控数据，不是跨硬件性能承诺。

## 方法

`runVfxPerformance1080p` 与 `runVfxPerformance4k` 均以固定 `1/60 s` 步长运行 240 帧，
使用 curved/all、HDR、三层 Bloom 和 soft particles。场景最终包含 768 粒子（fire 与 smoke）、
159 个 textured Ribbon segment 和 2 个 textured surface Decal。当前 adapter 保留稳定透明顺序，
因此 929 个 primitive 对应 929 次 draw；相邻相同材质只复用 texture/material state。

## 结果

| 入口 | 分辨率 | CPU update 平均 | RenderGraph GPU 平均 | draw | uniform payload |
| --- | ---: | ---: | ---: | ---: | ---: |
| `runVfxPerformance1080p` | 1920×1080 | 0.3961 ms | 0.3225 ms | 929 | 74,320 bytes |
| `runVfxPerformance4k` | 3840×2160 | 0.3296 ms | 0.6408 ms | 929 | 74,320 bytes |

GPU 时间包含 VFX HDR target、Bloom 与 tone mapping。CPU update 只覆盖确定性 VFX 模拟与 snapshot，
不含 command execution/present；本次只做单轮发布验收，不用于建立跨版本统计阈值。

## 资源预算

- runtime VFX 目录：14 个文件，压缩/源文件合计 1,023,971 bytes。
- 13 张 PNG 解码估算：7,733,248 bytes，低于 24 MiB GPU 常驻预算。
- 正式 JAR 内 VFX 压缩条目：996,696 bytes；raw `dev/paricle/Luos/WrizFX` 条目为 0。
- grayscale/alpha mask 按 `R8` 上传并生成 mip；`RGBA_COLOR` 按 `SRGB8_ALPHA8` 上传。
- `VfxTextureCacheGlTest` 验证 storage 格式、相同 key 复用及关闭；Showcase 3,600 帧验证
  预热后 live GL resource identity/估算显存不漂移，退出后归零。

## 图形验收

- fire/smoke：61 个 draw，同时命中 Alpha、Additive 和 soft-particle 路径。
- impact：51 个 particle 与 2 个 Decal；trail：完整一圈 159 个 Ribbon segment。
- Showcase MSAA：typed color/depth resolve 后 soft particle 可采样单采样深度，最终 230,400 个非黑像素。
- Showcase 自动曝光：曝光链读取 base HDR，Bloom 读取 VFX composite，最终 230,400 个非黑像素。
- GL debug 无 HIGH 或 `GL_INVALID_*`；只出现现有精确 NVIDIA 131218 shader-state specialization 策略项。

## 发布性能门禁

第一次短预热运行受 CPU 电源爬升影响，`static-all-visible` 为 `3.406 ms`，未通过相对
v0.17.2 baseline 的 5% 上限。随后保持原始 100 帧 warmup、1,000 帧采样、5 轮参数，并在一次
1,000/10,000 JFR 预热证明同候选可达到 `2.708 ms` 后复测；五轮 median 为
`2.731/2.776/2.776/2.758/2.876 ms`，`comparePerformanceBaseline` 通过。没有修改 baseline、
阈值、场景、样本数或候选实现来规避门禁。

最终完整 readiness 即使临时启用高性能方案并把既有 JFR 作为预热，正式五轮仍为
`3.349/3.588/3.327/3.192/3.090 ms`，取中位 `3.327 ms`，超过固定 `3.126 ms` 上限。
因此独立复测只能证明门禁对机器热状态敏感，不能替代完整候选结果；v0.18.2 正式发布仍被阻塞。

## 限制

尚未实现 sprite-sheet flipbook、Ribbon repeat UV、VFX shader fog influence、Bloom scatter/highlight
clamp 或 draw batching。`VfxUvRegion` 与 `fogInfluence` 保留为纯值合同，但不把未接通的表现声明为完成。
