# v0.24 室外环境阶段性能记录

日期：2026-09-08。硬件：本地 NVIDIA GeForce RTX 3050 Laptop GPU，OpenGL 4.6，
Windows，关闭 VSync。命令为 `runOutdoorEnvironmentBenchmarks`，每组预热 120 帧、
测量 600 帧，volume on/off 配对，五轮；指标来自稳定帧 CPU/GPU/allocation，而不是窗口
创建、GL context 或 shader 编译的 wall time。

新增体积链增量（同尺寸 enabled − disabled）为：1080p CPU p95 `+0.174398 ms`、
GPU p95 `+2.522112 ms`；4K CPU p95 `+0.159199 ms`、GPU p95 `+3.112960 ms`。
4K Balanced 使用每轴 1/4 的 960×540 体积目标；1080p 使用每轴 1/2。两档均在任务书的
增量 GPU/CPU 预算内。关闭模式不创建体积目标和历史，稳定 allocation 增量只来自配对场景
本身的代次切换，不在线性增长。

## 其它证据

`runOutdoorEnvironmentIntegration` 已通过 `TAA + GTAO + Bloom + 自动曝光 + CSM` 组合，
并分别通过 MSAA、相机进入局部雾体和 resize 短跑；稳定性入口通过 3,600 帧、100 次预设/尺寸
切换和 10 次颜色/深度历史失败注入。所有运行没有 `GL_INVALID_*` 或 HIGH 消息；NVIDIA
131218 是已登记的 shader-state 冷启动信息，策略上限覆盖五轮候选矩阵。

历史链路单独保存 RGBA16F 散射/透射率与 R16F 深度，使用上一帧 VP 重投影、深度拒绝和 3×3
邻域裁剪。参考档 `--volume-quality=high` 关闭历史并使用 96 步、每轴 1/1；Balanced
使用 32 步，Low 使用 16 步、每轴 1/4。
