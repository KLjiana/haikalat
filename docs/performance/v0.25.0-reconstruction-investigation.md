2026-10-04。这是 M6 的失败诊断与修正记录，不是发布验收。
灯数、强度、模型、ROI 和 0.005 暗区门槛保持原值。

## 拆分深度积分和 XY 插值

质量入口增加可选 `--probe=x,y`，仅接受固定 stride 对应的原生像素。
该探针分别记录实际射线、四个生产 XY 列的独立细步长射线、生产列结果和各列 opaque 深度。
探针不参与参考图像、ROI、收敛或质量判定；只多分配 256 bytes 的 Demo readback。

`27fa3ec8...` 的小镇 420 帧 run `2636cafb-a19d-47da-800b-dbcddb9615c2`：
原生像素 (470,402) 的参考 S.r=0.006707331，生产 S.r=0；细 Z 的四列插值为 0.003272742。
这确认该点有明显的格内深度采样遗漏；细化 Z 后，剩余 XY 误差小于暗区门槛，但不能以这个探针替代全图验收。

像素 (230,654) 的参考 S=0，生产 S.g=0.019447079；细 Z 的四列插值反而为 0.027859202。

## 深度引导候选

在已有 prefix texture 的物理 Nz+1 边界之外追加一层 guide，增加 8 bytes/column；不新增 texture owner。
guide compute 在 opaque geometry 和积分后读取原始 depth，按稳定投影定位列中心，并用 raster 投影还原深度。
仅靠近 opaque 层的查询使用深度权重，空气与完整雾距查询仍使用完整 prefix；不按首个 opaque depth 截断卷。
NORMAL、透明和逐 sample 合成使用相同的颜色查询。新增 GL 回归覆盖前景剔除背景光和空气/远端不截断。

`1d470d25...` 的完整两组质量 run：历史开 `eec437a2-601f-4c06-b023-99d67c9bb684`，
历史关 `18135ae1-903c-46ea-b7ac-4ef1e4ddeb0f`。均为 10/12 帧通过，只剩小镇 60/420 暗区失败。
实验室 420 历史关暗区误差降为 0.000962723；历史开为 0.001205308。
源项同点对照一致，正常限幅与非有限计数为 0。该候选之后继续检查 guide 权重连续性及其与 reactive 的一致性。

后续候选已加入平滑的局部深度尺度、紧支撑权重、天空排除及 fog-far 淡出。
前景完全排除背景列时，reactive 同样不包含它；GL 回归增加引导过渡点两侧、远端连续性与前景响应掩码。
连续引导候选 `c9694c2ee98f13855668841e217d3c4f6d16c36d592f2c4d59e55922b073d933` 已独立验证：
foundation `7aaa7de6-ed8f-40b3-a475-e3c753b6c9ff` 普通 1001 用例（224 个显式 opt-in GL skip）、
45 项体积 GL、16 项 clustered 和 18 项既有 GL 全部通过。
完整历史开 `de8b4607-6d25-4d46-941d-fd5df5b5d4a5`、历史关 `0b603f82-cc77-48b9-8793-3a1bd855812d`
均为 10/12 帧通过。实验室 420 无历史暗区误差 0.000962723，历史开 0.001205372；
小镇 60/420 无历史为 0.006856249 / 0.006707476，仍失败。所有同点 source 对照误差为 0。
该指纹正常 1080p/4K 三轮正式性能子集已经测量：1080p CPU 第 2 轮 0.3616ms 超限，4K 通过，没有完整压力矩阵。
精确运行与全部失败见 [阶段报告](../releases/v0.25.0-release-report.md) 和 [性能基线](v0.25.0-volumetric-baseline.md)。

## 未接受的整格平均实验

四个 Z 分层点各自重查 cluster，源项取整格平均，并让历史坐标跟随分层中心。
`343ccb9d...` run `588bdc38-1c9b-4654-b52c-614b5eb8c5c4` 的小镇历史关：
60/420 暗区最大误差为 0.008177585 / 0.033162388，240 帧通过。全部 45 项 GL 专项通过仍不能消除这项图像失败。

420 帧 (202,406) 的参考 S.r 约 9.88e-7，而候选为 0.033162486。
整格平均 q 被用在最后不足一格的积分上，会把终点之后的强光摊到前景半段。
该实验已撤回。下一步须同时保存源项的格内分布和正确的 partial-segment 查询，
不能只增加采样点后平均成一个常数，也不能以降低灯强度或扩大阈值处理这些像素。
任何新增表示还须先证明 4K 的 128/192 MiB 及双代次预算，保留独立无历史验收。

## JVM 归因与稳定灯索引比较

d4e04bbf 的 84665c86-0776-41a4-9ff5-d73e4488dc78 保存完整 JFR 与配置，明确标记 profiler+CPU isolation，
不是正式结果。记录含 39 次 GC，机器 CPU load 的部分快照为 67%～92%；pipeline.execute 范围只有 17 个
Java 和 10 个 native 样本，样本不足以确认单一驱动瓶颈。源指纹读取、模型创建及结果序列化的分配也在整个记录中，
不能混算成 pipeline.execute 的新增成本。

记录提示体积历史的 stableId map 查询发生装箱；冻结灯表向量读取本身不生成副本。
当前 e8e3b369e0f9ee1ea44bf7cfe1639008f022b042537ac439e0e450be5dc302b1 在原索引处先核对 stableId，
匹配才直接使用记录，索引移动则回退原查找；不依赖未核验的索引缓存，不改变参数、时域判断和成功帧协议。
新回归覆盖删除首灯、失败后恢复相同值，以及方向灯排序移动。普通 1003 项（225 opt-in GL skip）、
46 项体积 GL、16 项 clustered、18 项既有 GL 均通过。

局部比较独立进程探针 128 灯、20,000 warmup+50,000 调用，旧/新平均约 3.05 / 1.87 µs，
两边稳态线程分配都为 0：JIT 已能消除原 map 查询的装箱，不能宣称减少了同样数量的稳态堆分配。
当前历史开 f2cb6961-dfc1-41ef-a49f-d548e8db8a63、历史关 220a8ad8-6fb2-4363-9f56-3f4cebb95c99
均 10/12，逐项图像与同点 source 指标不变。正式正常子集 1080p CPU 三轮全失败、合并 0.5774 ms，
4K 逐轮及合并通过、合并 -0.0218 ms；各 900 配对帧、100% 覆盖，完整压力矩阵未在新指纹重测。
该局部优化不足以解决 M6 性能门槛，阶段出口仍未通过。
