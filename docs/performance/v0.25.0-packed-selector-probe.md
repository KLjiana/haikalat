## 改动与合同

当前原生射线先读取四个 RGBA16F texel，建立十六槽的占用 mask；随后每个区间、每盏候选灯重复读取同一 selector texel。忽略目录的原型把已读取的十六个正值分别按原来的 int 转换，两个 16-bit 编码存入一个 uint，共八个 uint；按原槽位顺序解码。producer 的整数编码不超过 2047；所有正的有限 half 值不超过 65504，同样能完整保留转换后的编码。负值继续触发原 full-scan overflow 路径。光照、介质、求积节点/面板、filtered contribution 单次替换、采样点和资源均未改。

该缓存可能增加寄存器压力。减少纹理指令本身不能证明性能收益，因此在实际消费者通过后才做代表探查。

## 正确性证据

独立 CPU 按原浮点槽值生成候选顺序与 overflow 列表；原实现和原型的实际 selection/decode GLSL 片段都读取真实 RGBA16F 3D texture，各与 CPU 的 1,572,864 个 uint word 逐值比较，GPU 两版结果也完全相同。共 65,536 张十六槽表，其中 8,192 张 overflow、57,344 张非 overflow、40,949 张稀疏占用；覆盖空表、密表、最后一槽、随机空洞、1～2047 producer 编码，以及 65504/.25/.5 等有限 half 边界编码。它是索引语义证明，不声称完成了完整场景画质或灯光数学验收。

两个现有实际 GL 用例通过、0 skip：`nativeFineIntervalsReplaceTheStoredFilteredContributionOnce`、`nearPointNativePixelsAndSelectorFallbacksAgreeWithIndependentContinuousRays`。测试副本只增加原型资源 URL/SHA 断言，独立连续射线、诊断开关和 1/16/17/2048 灯回退等原断言保留；生产测试与源码未改。
