# v0.22.1 文本性能基线

日期：2026-08-09

环境：Windows、Java 21、LWJGL 3.3.3、OpenGL 4.6.0 NVIDIA 576.88、
NVIDIA GeForce RTX 3050 Laptop GPU。完整任务使用 3 轮、30 帧预热、120 帧稳定采样和
每组 100 次 Markdown parse。

命令：

```powershell
.\gradlew.bat runTextBenchmarks --rerun-tasks --no-daemon --console=plain
```

Parser 在进入 CommonMark 前拒绝超过 1,048,576 字符的输入；容量测试不依赖实际分配超大 AST。

## 门槛结论

- 静态稳定阶段没有重复 shaping、layout 或 glyph upload bytes；该条件由 benchmark 内部门禁执行。
- 普通文本关闭特效时只写入 effect type，不准备效果颜色、厚度、偏移、模糊或角度参数，也不进入额外 shader path。
- v0.22.0 尚无同构的 `runTextBenchmarks` 数据，因此不能伪造精确的 5% A/B 数值；本报告建立后续补丁可重复比较的正式基线。普通文本实现缩短了 CPU uniform 路径，实测未见明显回退。
- 完整运行记录到 92 条 NVIDIA 131218 冷启动 shader-state specialization 消息；它们由 vendor、severity、source、type、ID、task 与消息全文精确约束，上限 120，且发生在稳定测量窗口前。
- 未出现 HIGH、`GL_INVALID_*`、未授权 MEDIUM、资源泄漏或线程悬挂。
