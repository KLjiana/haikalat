# v0.18.1 VFX 曲线性能记录

日期：2026-07-25
平台：Windows，JDK 21，NVIDIA GeForce RTX 3050 Laptop GPU（驱动 576.88）

## 方法

```powershell
.\gradlew.bat runVfxCurveBenchmark --rerun-tasks
```

同一 JVM 和线程内构造 linear/curved 两个固定 seed 的 `EffectInstance`，各保持 10,000 active
particles，并以 60 个固定步长形成真实出生批次。完成 12 次 warmup 后交替顺序采样 40 次，以中位数
避免固定先后顺序、GC 和系统负载偏差。两侧使用相同 particle count、lifetime、camera 和 snapshot
输出规模；curved 侧额外采样三关键帧 size track 与三 stop color gradient。线程分配通过 JDK
`ThreadMXBean` 采集。

## 结果

| 路径 | CPU snapshot 中位数 | 线程分配中位数 |
| --- | ---: | ---: |
| 0.18.0-compatible linear | 0.5720 ms | 1,241,864 bytes |
| v0.18.1 curved | 0.5278 ms | 1,241,864 bytes |

本轮 curved 中位数比 linear 低 `7.73%`，第二次独立复测为 linear `0.6150 ms`、curved
`0.5546 ms`（`-9.82%`），均满足“不高于 linear 10%”的预算。两侧分配量完全相同；曲线采样
不创建临时集合、装箱值、lambda capture 或每粒子颜色临时对象。单次 snapshot 内，相同出生批次
复用完全相同的 `age01` size/color/rotation 结果。40 个 measured snapshot 加 12 个 warmup snapshot
共记录 `1,040,000` 次属性应用。

该结果是单机微基准，不替代 `runVfxPerformanceBaseline` 的真实 GL adapter CPU/GPU 指标。
