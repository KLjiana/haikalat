# v0.19.4 Modern UI 验证记录（2026-07-28）

日期：2026-07-28。

环境：Windows、Java 21、NVIDIA GeForce RTX 3050 Laptop GPU、OpenGL 4.6、
驱动 576.88。

独立 `ModernUiDemo` 不创建 `UiDemo` 的完整输入场景和千项虚拟列表，并在资源、
RenderGraph 与首帧 UI GL 资源预热完成后才显示窗口。`runModernUiIntegration` 的
确定性 60 帧结果：

| 项目 | 结果 |
| --- | ---: |
| 最终 framebuffer | 800×520 |
| visible nodes | 15 |
| quads | 320 |
| batches / draws | 16 / 16 |
| 非清屏采样 | 3,359 |
| UI ring 累计等待 | 0.55 ms |
| 最大可见帧 / 超过 25 ms 的帧 | 13.67 ms / 0 |

集成场景每 15 帧自动重触发一次 Play transition，并断言旧 timeline 对应的
ripple/shimmer/confetti 会被统一取消，active effect 始终不超过 3。
| 未授权 HIGH / MEDIUM | 0 / 0 |

测试包含 SDF 圆角、transform/property timeline、显式 managed layer/双轴 blur target、
source-unavailable direct fallback、shimmer、ripple 和 confetti。最终 readback 触发一次
NVIDIA `131154` pixel-transfer 同步提示；它只发生在 correctness readback，已沿用带到期日和
任务正则的现有 GL policy，不位于性能测量窗口。

纯 JVM `UiEffectRuntimeTest` 额外执行 3,600 帧固定步长 soak。每 30 帧启动一个固定种子 spark，
active effect 始终不超过 4、预留粒子不超过 48，结束时 active 为零。

本记录是功能/容量快照，不是跨机器 GPU 性能门槛。正式 1080p/1440p/4K 五轮 GPU timing
仍应在 compositor record 阶段替换 direct visual fallback 后重新采样。
