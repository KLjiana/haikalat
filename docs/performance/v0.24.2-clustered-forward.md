# v0.24.2 Clustered Forward 性能记录（候选，未发布）

日期：2026-09-10。基线提交 `4f261b2`（v0.24.1）+ 本候选未提交改动。
硬件：NVIDIA GeForce RTX 3050 Laptop GPU / PCIe / SSE2，驱动 576.88，Windows。

本文件只记录已执行入口的真实输出；成功退出的任务不自动等同于通过预算，失败门禁原样保留。

## 最终结论（2026-09-10 优化后）

`.\gradlew.bat runRender3dClusteredBenchmarks` 正式门禁**通过**：

- `sparse-128 1080p` ClusterAssign GPU p95 = 0.116 ms（预算 ≤0.75 ms）
- `sparse-256 4K` ClusterAssign GPU p95 = 0.856 ms（预算 ≤1.50 ms）
- GPU 覆盖率 1.00，overflow 期望（sparse/coverage=0、overlap>0）与真实 extent 门禁均通过

## 方法与口径

- 正式入口：3 轮 ×（120 warmup + 300 measured），`cpuIsolation=true`（每测量帧前 `glFinish`）。
- 快速入口：`runRender3dClusteredBenchmarkSmoke`：1 轮 10+30、`--informal`，只验证采样/覆盖/overflow。
- 帧循环只测量 `RenderPipeline.execute` 的 wall time；`record` 为 `FrameProfile` 全部 pass 的 CPU
  录制纳秒之和；`submit` 是逐帧 `wall-record` 后再取分位数。
- 分位数由 `SampleStatistics` 对排序副本计算；空样本显式失败。
- GPU 样本使用 `RenderGraph.enableGpuSampleCollection()` + 每帧 `drainGpuSamples()`，按
  `sampleFrameSequence` 过滤轮次窗口并去重；覆盖率 1.00。
- 4K 使用精确 3840×2160 的 owned offscreen target（隐藏 GLFW 窗口会被工作区裁剪，
  旧记录中的 3840×1415 已作废），cluster 数为 60×34×24 = 48,960。
- 原始逐帧样本与源码指纹写入 `build/reports/clustered/<sha256>/<uuid>/metrics.json`。

## 优化过程（记录真实尝试）

1. 初始 assign 在每个 cluster 上对同一组计数器做 `atomicMax/atomicAdd`。1080p p50 1.09 ms、
   4K p50 5.52 ms；条带化 128 槽后 p50 仍约 1.1 ms/4K 5.5 ms。
2. 移除每 cluster 的全局原子：新增 `cluster-stats.comp`，每 256 个 header 在 workgroup 内用 shared
   atomic 归约，再每 workgroup 只发一次全局 atomic；assign 不再触碰计数器。1080p p50 降至 0.17 ms，
   4K 降至 1.0 ms。
3. assign 只读紧凑 view-space sphere（每灯 16B），不再读 80B 完整记录。
4. 改为一个 workgroup（256 线程）处理 4 个 cluster，每 64 线程一个 quarter；无跨 warp 同步，
   workgroup 数降 4 倍。4K p95 从 1.65 ms 降到 0.86 ms。
5. 尝试过 subgroup ballot（KHR）路径，但 NVIDIA 的 OpenGL 上下文不暴露该扩展，该路径从未执行，
   已删除，避免留下无法验证的分支。4-cluster shared-scan 版本对 Intel/AMD/NVIDIA 都可用。
6. 诊断 counters 仍为双缓冲 persistent-coherent 映射 + fence；fence 现在绑定到创建它的 storage，
   resize 后旧 fence 不会验证新 storage（`ClusterDiagnosticResizeAuditGlTest`）。

## 正确性对照

- `ClusterLightingGlTest`：像素级全灯参考对照，正常列表 K=128 与 overflow K=8 分开。
- `ClusterRotatedViewAuditGlTest`：旋转 yaw/pitch 与跨 slice 对照；旧 viewZ 实现差 33，修复后 ≤2。
- `ClusterAssignmentGlTest`：CPU oracle/GPU 读回、resize 后重新分簇、overflow 计数。
- `LightTableLayoutGlTest`：GPU 读回验证 16+80N std430 布局。
- `ClusteredLightingResourcesLifecycleGlTest`：预算/分配失败不泄漏 program。
- `runRender3dClusteredQuality`：两遍确定性图像门禁（A/B 逐像素一致、声明帧互异、summary 一致）。
