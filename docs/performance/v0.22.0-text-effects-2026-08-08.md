# v0.22.0 文本与字体特效专项记录

日期：2026-08-08

环境：Windows、Java 21、LWJGL 3.3.3、OpenGL 4.6.0 NVIDIA 576.88、
NVIDIA GeForce RTX 3050 Laptop GPU。

## MarkdownTextDemo 真实 GL 证据

命令：

```powershell
.\\gradlew.bat runMarkdownTextIntegration
```

确定性隐藏窗口运行 30 帧，脚本在第 8 帧和第 16 帧切换内置主字体，最终使用
JetBrains Mono。最终帧验证了 Markdown 默认布局、`strong`/行内 `code` 节点、inner glow
效果类型和非空 framebuffer。

| 指标 | 结果 |
| --- | ---: |
| rendered frames | 30 |
| visible glyphs | 993 |
| UI quads | 1010 |
| draws | 62 |
| non-clear samples | 4151 |
| final font | JetBrains Mono |

## JVM 与架构证据

- `UiTextEngineTest`：5/5 通过，覆盖默认字体随全局选择变化、显式字体保持固定和特效 atlas padding。
- `MarkdownParserTest`：2/2 通过，覆盖 CommonMark block 与 inline `strong`/`code`。
- `TextSystemTest`：3/3 通过，覆盖共享文本服务、字体注册和布局缓存。
- `ArchitectureBoundaryTest`：20/20 通过，确认 text subsystem 不依赖 UI/backend/OpenGL。
- `dependencyLockGuard` 与 `assetManifestGuard` 通过；shader SHA-256 已同步到 `docs/licenses/assets.tsv`。
