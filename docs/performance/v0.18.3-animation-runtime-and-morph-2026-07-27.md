# v0.18.3 Animation Runtime 与 Morph 性能报告

日期：2026-07-27

环境：Windows、JDK 21、LWJGL 3.3.3；真实 GL 验收环境为 OpenGL 4.6.0 NVIDIA 576.88、
NVIDIA GeForce RTX 3050 Laptop GPU。以下为单机受控结果，不是跨硬件性能承诺。

## 方法

`runAnimationRuntimeBenchmark`、`runAnimationConstraintBenchmark` 与
`runMorphTargetBenchmark` 均固定 `1/60 s`，每轮至少预热 60 帧且至少完成 10,000 次角色 update，
再测量 120 帧，共 5 轮，按总耗时中位轮报告耗时和当前线程分配。Graph 场景为两 child 1D locomotion Blend Tree；
constraint 场景为四 joint FABRIK；Morph 场景分别采样 4/8 target LINEAR track。

## CPU 结果

| 场景 | 角色 | targets | 120 帧中位总耗时 | 分配/角色/帧 |
| --- | ---: | ---: | ---: | ---: |
| Graph locomotion | 1 | 0 | 0.2123 ms | 0 B |
| Graph locomotion | 100 | 0 | 11.6900 ms | 0 B |
| Graph locomotion | 1,000 | 0 | 111.7150 ms | 0 B |
| FABRIK | 1 | 0 | 0.1991 ms | 144.267 B |
| FABRIK | 100 | 0 | 15.8995 ms | 32.643 B |
| FABRIK | 1,000 | 0 | 162.5834 ms | 32.064 B |
| Morph weight sampling | 100 | 4 | 1.2601 ms | 0.003 B |
| Morph weight sampling | 1,000 | 8 | 4.7762 ms | 0.000 B |

Graph 热路径已消除 transition/event 空列表 iterator、channel segment 和 BlendTree weight 临时对象；
1/100/1,000 角色均为 0 B/角色/帧。Morph 的 32-byte 总量是进程级计数噪声。FABRIK 的规模化结果
稳定在约 32 B/角色/帧，对应每次求值返回的公开不可变 `AnimationConstraint.Result`；单角色数值还
包含预热后延迟初始化，因此不作为 allocation gate。

## Morph GPU 与资源

真实 GL fixture 同时包含一个非蒙皮 primitive 与一个 two-joint skinned primitive，每个 primitive
有 4 个 POSITION/NORMAL/TANGENT targets。解码统计为 8 targets、864 bytes 原始 delta；GPU
`std430` 打包为 1,152 bytes asset-owned delta SSBO。单实例的三个 primitive/node weight buffers
合计 48 bytes；两个实例可保持不同权重。

`runGltfMorphSkinningIntegration` 验证 PBR color、directional shadow、Morph-before-skin、
normal/tangent 稳定回退、per-instance isolation、zero-weight 路径、部分上传失败回滚和关闭归零。
该入口当前是确定性像素/资源门禁，不发布 GPU timing；4/8 target 数字因此只代表 CPU weight sampling，
不把功能性 GL 证明写成 GPU 性能承诺。

## 限制

当前没有 compute morph、GPU animation sampling、自动 2D triangulation、motion matching 或
full-body IK。Morph 每 primitive 固定最多 8 targets；GPU delta 使用受控 SSBO，普通 zero-target
glTF 不创建 Morph buffer。
