## 适用范围与指标

参考设备为 RTX 3050 Laptop 4 GiB、NVIDIA 576.88、Java 21。当前选定配置为原生 1920×1080、128 局部灯、8 个局部雾体、已分配 2 Point + 4 Spot 缓存阴影、BALANCED、NONE、Bloom off。其他硬件和综合高级效果需要自己的测量，不由本机结果推导支持范围。

| 项目 | 原严格目标 | 当前本机策略 |
|---|---:|---|
| 1080p 雾 GPU 增量 p95 | 2.0 ms | 2.75 ms，门禁 |
| 雾 CPU execute 增量 p95 | 0.35 ms | 1080p 为 0.65 ms，门禁 |
| 4K 雾 GPU 增量 p95 | 4.0 ms | 保留该参考线；`benchmark.gate4k=false`，只记录 |
| 4K 雾 CPU 增量 p95 | 0.35 ms | 当前配置的 0.65 ms 也仅供对照，不作门禁 |

数值是按相同 round/measured index 配对的 fog-on − fog-off 增量分位数，不是整帧耗时，也不是两个 p95 相减。CPU execute 包含提交阶段的驱动开销，不能等同于整机 CPU 或 Minecraft 帧耗时。

三轮、每侧 120 warmup + 300 measured、交替 on/off、完整同帧 GPU Pass 求和及覆盖率门槛维持原规则；逐轮和汇总都要满足门槛，不能用汇总掩盖坏轮。4K 取消的是性能门禁，采样完整性、错误检查和资源预算继续有效。保留原质量误差/稳定性门槛、无雾跨版本 CPU 0.05 ms 目标和资源字节上限；未来超出新预算仍应如实记 FAIL。
