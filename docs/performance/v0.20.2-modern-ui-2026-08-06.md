# v0.20.2 外部动画与现代 UI 性能记录

日期：2026-08-06

环境：Windows、Java 21、LWJGL 3.3.3、OpenGL 4.6.0 NVIDIA 576.88、
NVIDIA GeForce RTX 3050 Laptop GPU。

## ModernUiDemo 真实 GL 证据

命令：

```powershell
.\gradlew.bat runModernUiIntegration
```

固定窗口为 1280×720，确定性脚本运行 90 帧，覆盖设置页打开、reduced motion、音量修改、
返回战役和继续游戏。最终帧 framebuffer readback 得到：

| 指标 | 结果 |
| --- | ---: |
| visible nodes | 93 |
| quads | 423 |
| batches / draws | 52 / 52 |
| compositor layers | 1 |
| active effects | 2 |
| max frame | 11.40 ms |
| slow frames >= 25 ms | 0 |
| non-clear samples | 3711 |

JVM 场景测试同时验证 93 节点菜单树、CJK 文本、style class 主题解析、设置页可见性、
长循环 ambient animation 的 reduced-motion 取消和脚本返回路径。

## 外部动画 Demo 证据

`runPlayerWildIntegration` 使用 12 节点、1 skin、`steve.png` 纹理与 8 个紧凑外部 clip，
验证 98 条 TRS channel 的 CPU 解码、GPU 上传、可见性、循环/一次性播放和 0.22 秒姿势
过渡。外部 clip 不携带独立 buffer，模型和动画清单仍通过资源 generation 追踪。

## 限制

该记录只收录本版本新增的现代 UI 和外部动画专项数据；完整发布候选的 JVM、OpenGL、
资源生命周期、静态提交和 JFR 结果由 `build/reports/release/readiness.json` 与
`build/reports/performance/current.json` 机器证据保存。
