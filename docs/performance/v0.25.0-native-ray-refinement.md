## 图像失败的原因

Town 420 原始暗区最大绝对误差为 0.00670748，超过冻结的 0.005 门槛。同采样点完整灯表对照仍为 0，问题发生在积分和重建阶段。

只增加末段深度求积无法解决横向欠采样。64 点深度曲线原型 `60d8ec95…` 在 native pixel (478, 410) 引入了 0.05994388 的误差：真实射线的散射为 0，相邻 (472, 408) 网格列的独立积分却为 0.07048453。该失败原型及完整源码 ZIP 保留于 run `81b4e1ee-344e-42e9-94d7-0aa36c3ea14b`，原型已经回退。

新原型只在近局部灯的高梯度区间按实际像素射线补充积分，替换该区间的粗网格散射贡献。保留当前源项、源项历史、原有透射率、灯单位、阴影定义、配置、ROI 和所有数值门槛。
