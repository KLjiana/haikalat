# GTAO 切片积分修复记录

日期：2026-09-09。修改当前工作树，未提交或切换版本。

## 改动

`gtao-estimate.frag` 从屏幕方向 horizon 平方均值改为视线切片解析积分：建立切片基、投影法线并保存投影长度和有符号角度；两侧 horizon 以视线为参考，初始值对应法线半球边界；厚度偏移和距离衰减作用于 horizon，最后在法线半球范围内积分 `cos(theta - n) * abs(sin(theta))`。切片可见度乘法线投影长度，再汇总和应用强度。

可对照 [Intel XeGTAO 的投影与解析积分](https://github.com/GameTechDev/XeGTAO/blob/master/Source/Rendering/Shaders/XeGTAO.hlsli)。本次没有移植其完整降噪、深度 MIP、采样优化或光线追踪调参流程；有限方向和屏幕外信息缺失仍是现有实现的限制。

移除了设置测试中强制匹配旧平方公式文本的断言；原 JVM 对称球冠参考保留，并明确它只验证一个特例。更新了资源清单中 estimate shader 的 SHA-256。

## 新增验证

- 直接编译生产 shader 的切片投影与积分函数，与 131072 步独立角度数值积分比较。7 组输入覆盖正对视线的 30° 对称遮挡、倾斜法线、非对称 horizon、视线偏转、联合旋转与无遮挡；容差 0.0002，低于一个 R8 台阶。
- 完整生产 estimate shader 读取真实透视深度：6 组无遮挡平面组合覆盖 0°/35° 倾角和 3 个方位角，检查中心区域保持可见。容差 0.04 包含有限切片采样误差。
- `glSmoke --tests '*Gtao*' --tests '*OutdoorEnvironmentGlTest'`：25 项通过，无跳过。
- `runRender3dGtaoIntegration`、`assetManifestGuard` 和 `git diff --check` 通过；集成日志为 `build/gtao-integral-integration.log`。

日志：`build/gtao-integral-tests.log`。
