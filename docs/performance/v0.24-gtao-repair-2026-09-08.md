## 正式基准结果

执行命令：

```powershell
.\gradlew.bat runRender3dGtaoBenchmarks --rerun-tasks --console=plain
```

默认配置为 3 轮、每轮预热 30 帧、测量 60 帧、1920×1080 与 3840×2160，启用/关闭
GTAO 串行 A/B。第一轮在 1080p 完成两侧后触发 CPU 门禁：

| 结果 | enabled CPU p50 | disabled CPU p50 | 增量 | GTAO GPU p50 |
| --- | ---: | ---: | ---: | ---: |
| 第一次正式运行 | 0.826000 ms | 0.462700 ms | 0.363300 ms | 0.659456 ms |
| 同配置重跑 | 0.812400 ms | 0.364000 ms | 0.448400 ms | 0.651264 ms |
| 门槛 | — | — | ≤ 0.350000 ms | ≤ 2.000000 ms |

两次运行都因 `enabled CPU p50 delta` 超过 `0.35 ms` 而失败；任务在 1080p 处停止，
因此本记录没有伪造 4K 正式结果，也没有把整轮 wall 时间或冷启动时间当作稳定帧指标。
allocation trend 两次均未出现正向增长，disabled 历史 CPU/GPU 回退也未超限。

## 诊断与后续

运行期间 NVIDIA 驱动报告了若干 `GL PERFORMANCE [MEDIUM] 131218` shader state
recompile 提示，未出现 `GL_INVALID_*` 或 HIGH 消息；这些冷启动提示不被当作正确性通过。

仍未完成，不能执行正式版本切换或 `releaseReadiness`。
