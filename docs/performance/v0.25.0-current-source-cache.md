## 改动与正确性

合成阶段复用当前帧已经求出的四列 aggregate source，减少重复全簇计算；filtered interval 仍只替换一次，单灯 native quadrature 和阴影计算保留。当前 RGB 光照使用 RGBA32F，消光 alpha 保留 medium/history 的半精度值；历史、prefix 仍为 RGBA16F。新增 sampler 21，宿主纹理快照覆盖 0～31；没有新增长期资源或分配位置。补齐 2D/3D 上传、framebuffer 元数据与全字节记账，诊断 full-scan reference 与实际 source 使用同一存储格式。

- 27 个定向 JVM、asset/API guard 通过。62 个实际 GL 用例在首轮执行：60 PASS、2 个消光精度合同 FAIL；修复后实际重验 32 个光照/合成/历史用例 PASS，30 个资源、事务与宿主用例按输入投影复用。后续仅 demo reference 修正，生产/GL 输入逐字节一致，62 项标为 REUSED_PASS；不称作当前指纹重新跑了全部 62 项。
- 缓存/直接计算在同帧与三种 filtered scale 下通过既有独立混合射线合同，比较容差 5e-7；原数学、混合和失败恢复门槛未放宽。原编译缺失格式与两个 GL 失败均保留。
- 新 M0 绑定/尺寸/预算检查通过；实际 4K RGBA32F 写读精度、resize 重叠和关闭由资源 GL 用例证明。M0 原格式能力列表仍为 RGBA16F/R8，其 PASS 不冒充单独的 RGBA32F capability-query。
