## 修复原因与行为

原小镇 history-on 60 帧暗部最大误差 0.00709318649，探针 (386,470) 的原生 S 为 0，独立 S.r=0.0071007865。
prefix 保存过滤后的总 q，旧细化却扣除当前灯 q；历史 q 比当前 q 小时会被扣成负 S。

现在每个实际细化区间仅扣除一次存储的 prefix/source 贡献，恢复当前粗源项，再用原生 Point/Spot 求积替换当前近灯贡献。
该局部区间中的其他灯和发射项保持当前粗采样，未细化区间继续使用过滤后的历史 q。没有新增纹理、缓冲或每灯历史。
两种受控 q 比例 0.1/2、混合方向灯和发射、部分深度终点及未细化射线的独立 GL 回归在旧实现失败、修复后通过。

Spot 保持 2m、Point 1m 支持；有效已分配阴影的 Spot 使用四个 8 节点角度区间，锥边不使用单点平滑。
当前 60 帧 history-on 暗部误差降到 **0.00172276329 < 0.005**，420 帧为 0.00241998117；未改变门槛。
移动相机的 60 帧粗历史接受 210238/230400（91.25%），体积历史保持启用。

恢复完整粗照明时显式借用现有 UBO 6、SSBO 2/3；片元灯表仍为 13，reactive 脏域仍为 14。
探索候选的已激活 cluster/reactive 14 冲突保留为未签收；最终 PBR 实际链接断言核对两组只读 cluster 均为 2/3。

街道关闭局部体积贡献后左侧薄暖光束消失，Bloom off 下可辨；喷泉无蓝色雾团，没有全画面灰幕。
酒馆 420 帧与此前末帧最大 HDR 差为 0.000244140625，平均 5.50e-8，当前独立参考与原生画面均检查。
受控时域的 TAA 逐像素极值仍保存为诊断，不把 ROI 均值通过称为逐像素稳定或连续风动/事件美术通过。
