## 森林预设修正

实际静止镜头首次检查时，原高度衰减 0.24 在 30/150/270/390 帧各触发 120 个介质限幅单元，风动与零风都复现。
这是该镜头远端下方网格的全局高度指数增长；原失败保留，不能用“画面有限”代替正常预设限幅为零。
两份森林 schema 2 profile 的 `medium.height_falloff` 改为 **0.22**；基准密度 0.004、雾距 90m、BALANCED、灯光、history、风速、shader 上界与验收阈值均未改变。
当前全部 33 个原生采集帧及六份独立图像的 nonfinite/medium/source/integral limit 计数均为 0。

独立最终图像最大 NRMSE 为 0.0157889 < 0.05，最大归一化 p95 为 0.0410907 < 0.10，暗部绝对误差为 0。
实际风动时间从 0.0166667 到 7.0167036s；同镜头零风对照只改变 `volume.wind`。
原始 HDR 风动差最大 0.0322266；末帧平均绝对差 0.0000220402。启用历史的后续采集帧均保留有效体积历史。
近端 z24 切片没有局部噪声雾，原首批该切片风动/零风相同；不把它的零差异误称为全场景没有风动。

已查看当前森林原生末帧、三镜头与旧单太阳/旧 96 步对照、15 张风动关键帧与零风对照。
道路/树干/树冠保持可读，局部薄雾保留空间层次；旧单太阳更亮，作为视觉连续性参考，不作为新物理误差基线。
酒馆事件三组对照已查看，关灯帧及之后两帧未见明显亮部残影；保留真实 reactive/S/T 数据与所有原始图像。
视觉结论限定所采集关键帧，连续风场系数/成功时间的独立 6 序列合同继续按原输入范围复用。
