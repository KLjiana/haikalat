## 必须保留的结论边界

1. **性能通过依赖新的本机政策。** 有效正式样本 GPU 雾增量 p95 为 1.745920 ms，CPU 为 0.4373 ms；满足当前 2.75／0.65 ms 门禁。GPU 也低于旧 2.0 ms，但 CPU 仍高于旧 0.35 ms。4K 只作记录，没有当前候选 4K 达标证明。本轮没有新增性能测量。
2. **收益包含质量取舍。** 无已分配阴影灯的求积由 8 节点变为 4 节点，Spot 阴影求积由 4 面板变为 2 面板。现有质量矩阵仍通过原误差门槛，但不能称为完全无损或与首次纯结构重构逐像素一致。介质缓存自身有独立缓存开关像素对照。
3. **时序矩阵不是所有动态内容的视觉保证。** 原 manifest 仍保留物理切灯背景变化、移动风场／VFX 事件等视觉限制；ROI 统计通过不证明每个像素都稳定。
4. **宿主验收仍是回调、借用目标和生命周期范围。** 消费者创建独立空几何 Scene 与方向光，未接入 Minecraft 地形、深度遮挡、光照和阴影统一表现；人工、多人及受伤／摇晃斜投影未验收。
5. **架构收敛尚未全面完成。** RenderPipeline 仍承担较多装配与事务职责；未增加 GTAO 第二试点或公共生命周期框架。
