# v0.25.0 酒馆入口与室内场景修复

日期：2026-10-06。当前运行时候选 `cc7843eea61bd1ccd8a344945a892bc646f4bf4f1607fd103381240ff79cc6bc`（1806 文件），本轮只有 Demo/酒馆配置变化。**入口、室内构图及近处火星定向验证通过；整版仍 releaseReady=false。** 按 v2 人工选测，没有运行旧发布聚合。

原 `threshold` 路线停在关闭的门板前，店铺主体也是实心盒。现在仅酒馆采用第一栋西侧店铺的空心室内，提供门洞、打开的门扇、内墙、吧台、瓶架、桌椅和内置灯具。普通小镇仍选择原来的关闭店铺分支。

相机从 `(-4.8, 1.7, 12)` 行进到 `(-10.5, 1.7, 12)`，218/219/220 帧检查入口两侧，300 帧后停在室内，保留 420 帧末图。门口 alpha 烟、软粒子烟与近处 additive 火星沿用原材质/纹理/混合路径；火星提高到镜头内并缩小为 5×12 mm，避免近距离投影成为大亮条。120 帧亮灯、180 帧关灯、240 帧移雾事件保留。局部雾延伸至门内，两个室内火把的位置、强度和半径仅对酒馆调整。仍有 128 盏表面局部灯、16 盏开启体积贡献，没有以 16 盏注雾代替 all-128 压力承诺。
