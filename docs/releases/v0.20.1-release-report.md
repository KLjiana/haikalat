# v0.20.1 可嵌入渲染正式版验收报告

日期：2026-07-29

状态：`0.20.1`

环境：Windows、Java 21、LWJGL 3.3.3、OpenGL 4.6.0 NVIDIA 576.88、
NVIDIA GeForce RTX 3050 Laptop GPU。

## 发布范围

本版补齐 Haikalat 的宿主无关可嵌入渲染边界：

- `PresentationTarget` 显式描述 draw/read FBO、color/depth/stencil attachment、
  输出尺寸、采样、generation 与 `OWNED` / `BORROWED` 生命周期；
- `RenderGraph` 支持导入和逐帧替换 borrowed attachment/presentation target，
  close、resize 和失败回滚不接管宿主资源；
- `RenderPipeline` 新增 `ExternalCamera + PresentationTarget` 每帧入口，几何、
  visibility、PBR、阴影、雾、HDR VFX、Bloom、tone mapping 和 FXAA 使用显式相机与目标；
- `UiRenderer` 和 `UiSystem` 的 overlay 路径使用同一 presentation target 的 FBO、
  像素尺寸、scissor 与 sRGB 策略；
- `HaikalatRuntime.createEmbedded(RenderDevice)` 不创建窗口、context、渲染线程或主循环，
  不调用 present / `swapBuffers`，并强制宿主渲染线程调用；
- embedded build、resize、render、failure 和 close 恢复宿主 OpenGL 状态，包括
  framebuffer、read-buffer selector、viewport/scissor、program/VAO、buffer、
  texture/sampler/image binding、clear color 与 blend/depth/cull/stencil 状态。

旧 `RenderWindow`、framebuffer `0` 和独立 Demo 入口保持兼容。Haikalat 不依赖
Minecraft、NeoForge、Blaze3D 或 `ResourceLocation`；适配继续位于 HaikalatHost。

接入方式见 `docs/guides/embedded-rendering.md`。

### 混合架构 CPU 调度诊断

本机 CPU 为 Intel Core i7-12650H，逻辑处理器 0–11 为 P-core，12–15 为 E-core。
Windows `Kernel-Processor-Power` 事件 37 持续记录逻辑处理器 12–15 被系统固件限频；
未约束 affinity 时，`static-all-visible` 会随主线程迁移在约 3.1–5.5 ms 之间波动。
同一时段用未包含 v0.20.1 改动的 v0.20.0 `HEAD` 对照复测也出现相同退化，因此该现象
不是本候选引入的 scene submission 回退。

将一次性 Gradle 进程限定到 P-core 0–11 后，不修改 baseline 或 5% 门槛，
`static-all-visible` 五轮 CPU median 为
`2.770 / 3.015 / 2.833 / 2.842 / 2.707 ms`，五轮中位数约 `2.833 ms`，
低于 `3.126 ms` 上限。正式验收使用独立 single-use daemon，使 affinity 能由启动进程
完整继承：

```powershell
$env:GRADLE_USER_HOME='D:\project\Java\learnopengl\.gradle'
cmd.exe /d /s /c 'start "" /b /wait /affinity 0FFF gradlew.bat --no-daemon releaseReadiness "-PreleaseVersion=0.20.1"'
```

## 嵌入渲染证据

- `embeddedJvmVerification`：10 项契约测试通过；
- `embeddedGlVerification`：5 项真实 GL 测试通过；
- 默认 `check`：728 项测试，0 failure/error；
- GL-enabled 测试：728 项中仅 3 项按自身平台条件跳过；
- `localGlVerification`：77 个 Gradle task 通过；
- raw host FBO/color/depth-stencil 由测试直接用 OpenGL 创建，不使用 Haikalat owner
  伪装 borrowed 生命周期；
- depth=0/1 A/B 证明宿主 depth 参与真实遮挡；
- resize 后 32×32 目标替换为 24×20 目标，同一 runtime/pipeline 继续工作；
- graph、pipeline、runtime close 与故意抛异常后，borrowed FBO/texture 仍有效；
- host color、HDR VFX、Bloom、tone mapping、FXAA 与 UI 像素进入非零目标；
- embedded build/resize/render/close 后没有未授权 `GL_INVALID_*` 或失效 ID 恢复。

## 性能与 GL 证据

本版没有改变 v0.20 的 scene submission 与 UI 容量预算。对照性能事实继续引用
`docs/performance/v0.20-m7-2026-07-28.md`：

- static all-visible 五轮 CPU 平均值中位数 `2.984 ms`；
- 10,000 quad 剩余约 `255 KiB/frame`，仍归属于 render/GL submission 预算；
- static all-hidden queue 五轮满足 `0.15 ms` 门禁；
- NVIDIA `131218` shader specialization 与登记过的 correctness readback 保持允许，
  没有未授权 HIGH/MEDIUM、资源 use-after-close 或线程悬挂。

## 宿主验收与发布边界

HaikalatHost 维护者于 2026-07-29 确认该候选可发布。Minecraft/NeoForge 客户端日志、
Blaze3D Java 状态缓存同步和游戏内事件编排属于外部宿主仓库，不作为 Haikalat
主仓库依赖或自动化输入。

当前 UI subsystem 是 screen-space retained UI，尚无 world-space UI 节点；未来若增加
world-space UI，必须复用同一帧 `ExternalCamera`。本版不引入 Minecraft API、第二窗口、
第二 context、额外渲染线程或新的渲染后端。
