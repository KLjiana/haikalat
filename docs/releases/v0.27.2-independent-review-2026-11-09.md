## 生产链审查

| 入口／职责 | 当前实现与判断 |
|---|---|
| 需求与布局 | `PipelineTopology` 合并 `SceneBufferRequirements` 的 raw／single 需求，`SceneSurfaceLayout` 统一附件、格式、槽位、采样数和 producer；深度、深度＋法线、运动数据组三类实体布局成立 |
| 光栅与 resolve | `ForwardPassBuilder` 按布局建目标；`SceneSurfacePass` 按槽位生成 shader 定义；`SceneSurfaceResolvePass` 从受控输入取样；最近覆盖样本与同深度首样本规则保留，伴随通道不独立选样 |
| GTAO | `GtaoSurfaceInputs` 消费共享单采样深度／法线及可选运动数据；专用 depth 兼容分支仍有真实 Pipeline 测试，不代替共享分支 |
| TAA／reactive | `PostProcessPassBuilder` 按实际 producer 建依赖，录制 TAA 时逐通道取受控输入；reactive 在最终生产阶段标记就绪，体积 alias 验证来源与槽位 |
| 体积雾 | `VolumetricSurfaceInputs` 区分原始深度和单采样深度；guide／composite 各自依赖实际生产者；候选回调使用自己的输入记录 |
| 生命周期 | `SceneSurfaceInputs.Frame` 结合 owner、当前帧对象、尺寸、真实 Graph 回调与录制线程检查；结束帧或退役后旧借用失效；标志表示命令已录制，不伪称 GPU 已执行 |
| 事务与所有权 | `PipelineGeneration` 和 `RenderGraph` 继续承担发布／退役及附件所有权；兼容目标转交后从 donor 账目扣除；target revision 防止过期 resize／replacement 候选提交 |

本次的收益是重复附件／producer 决策减少，并没有消除 `RenderPipeline` 的全部装配职责。公开 `SceneBufferView` 仍是兼容的被动句柄，运行期保护由内部输入入口完成；不能据此声称裸 GL ID 在任意外部调用处都能自动失效。`LINEAR_DEPTH` 无生产者时被拒绝，没有伪造实现。
