## 1. 候选改动

- `subsystems.vfx`：新增 `VfxRimLight`、`VfxUvFlow`、`VfxDissolve`、`EffectLight`、`VfxLight`；`VfxMaterial` 增加三个可选效果项；`EffectSnapshot` 增加效果时间、显式溶解进度与灯列表，`MeshInstance` 增加生命周期进度；`EffectInstance` 增加效果时钟、暂停/恢复、取消、重放、显式溶解与效果灯采样；`EffectAsset` 增加有限生命周期灯与法线网格校验。
- `render3d.vfx`：`vfx.vert` 增加可选 NORMAL location 2、模型/法线矩阵与世界位置；`vfx.frag` 增加轮廓、UV Flow、溶解/边缘和线性噪声；`VfxRenderer` 上传组合参数、逆转置法线、奇异变换跳过、程序化噪声纹理和事务式纹理准备/有界缓存。
- `render3d`：`VfxLightBridge`、`LightIdAllocator`、`VfxLightDiagnostics`；`RenderFrameContext` 支持冻结额外灯；`RenderPipeline.vfxLights`/`maxVfxLights`/`vfxLightDiagnostics` 在帧冻结前合并，HDR VFX 门与直接光门分别报告原因；`Render3dDiagnostics` 增加 `vfxLights` 组件。
- `demo.pbr`：`CombatVfxProfile`、`CombatVfxProfileCodec`、`CombatVfxCatalog`、`CombatVfxEffectFactory`、`CombatVfxController`；`HaikalatShowcaseDemo` 接入固定技能过程、作者面板、A/B、保存/加载、暂停/取消/重放、受光 PBR 背板与效果灯。
- 文档/构建：公共 API allowlist 与迁移记录、能力矩阵、控制合同、战斗 VFX 指南、测试合同索引；`build.gradle` 升到 0.28.0；两个 VFX shader 的 `assets.tsv` 指纹更新；Showcase 三个隐藏集成任务改为 120 帧以覆盖释放/命中阶段。
