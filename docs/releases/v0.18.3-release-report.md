# v0.18.3 确定性动画运行时与 glTF Morph 发布验收报告

状态：`0.18.3`，正式发布

日期：2026-07-27

环境：Windows、Java 21、LWJGL 3.3.3、OpenGL 4.6.0 NVIDIA 576.88、
NVIDIA GeForce RTX 3050 Laptop GPU。

## 发布范围

本版本将原有 Player/Mixer 工具扩展为可复用的确定性 Animation Graph、layer、constraint 与 signal
运行时，并为 glTF 增加完整 Morph Target/weights animation 的 CPU、PBR、directional shadow 和
生命周期闭环。范围仍只包含 Haikalat，不包含 HaikalatHost、Minecraft、网络、实体或物理适配。

## 主要能力

- typed parameter/trigger/state/transition/interruption、1D/显式 triangle 2D Blend Tree 与倒放。
- 最多 8 层 Override/Additive、Bone Mask、fade、root motion policy 和 pose 同权重 Morph 合成。
- Marker/Sync/结构化 signal，以及 application 侧单向 Animation-to-VFX bridge。
- Look-at、JointLimit、连续链 FABRIK、双手约束和纯输入 Foot IK。
- glTF POSITION/NORMAL/TANGENT Morph、mesh/node weights、STEP/LINEAR/CUBICSPLINE weights
  animation、每实例权重、conservative bounds、上限与失败回滚。
- asset-owned delta SSBO 和 instance-owned weight SSBO；PBR/shadow 固定 Morph-before-skin。

性能、分配与资源数字见
`docs/performance/v0.18.3-animation-runtime-and-morph-2026-07-27.md`。

## 明确限制

Graph 第一版只提供 Java Builder，不提供序列化、编辑器、自动 2D triangulation、motion matching
或网络状态复制。约束不查询 Scene/Physics，FABRIK 只支持连续单链，Foot IK 需要外部 target/normal。
Morph 每 primitive 最多 8 targets，不支持 compute/GPU sampling、mesh shader、动态 target 或第二组
skin weights。真实 GL Morph 入口是像素/资源正确性门禁，不发布 GPU timing。
