# v0.20.2 外部动画与现代游戏 UI 正式版验收报告

日期：2026-08-06

状态：`0.20.2`

环境：Windows、Java 21、LWJGL 3.3.3、OpenGL 4.6.0 NVIDIA 576.88、
NVIDIA GeForce RTX 3050 Laptop GPU。

## 发布范围

本版收口 0.20.1 之后完成的外部动画和 UI 工作：

- 新增 `haikalat.animation-clip/1` 紧凑 JSON 动画解码器，支持按模型节点名绑定 TRS/weights
  轨道、STEP/LINEAR 关键帧和事件；保留 glTF animation sidecar 的显式绑定约束；
- `player_wild` 接入 8 个外部动画 clip 与 `steve.png` 纹理，验证 12 节点、1 skin、98 条
  TRS channel，并使用 0.65x 播放和 0.22 秒自动姿势过渡；
- `GltfSceneInstance` / `AnimationMixer` 支持从当前可见姿势继续的直接 cross-fade，且不会
  改变原有立即 `play(...)` 语义；
- 独立 `ModernUiDemo` 提供 1280×720 双语现代游戏主界面、战役页、设置页、控件状态、
  style class 主题、SDF 圆角、UI VFX、timeline、CJK/Latin 字体和 reduced-motion；
- 新增可注入 `StyleResolver` 与节点 style class，旧 `UiDemo`、普通 quad/image/glyph 路径
  和已有 UI API 保持兼容。

## 专项结果

- `ModernUiDemo`：90 帧、1280×720、93 nodes、423 quads、52 draws、最大帧 11.40 ms，
  25 ms 以上慢帧为 0，最终 framebuffer 非清屏采样 3711；
- `ModernGameMenuSceneTest`：验证完整菜单树、CJK 文本、主题 style class、设置页切换、
  reduced-motion 取消长循环和确定性脚本返回；
- `player_wild`：8 个外部 clip、98 条 TRS channel、`steve.png` 像素纹理、循环/一次性播放
  和 0.22 秒运行时姿势过渡通过；
- 完整 JVM、GL、资源生命周期、静态提交、性能基线和 JFR 结果以机器 readiness 报告为准。

## 已知边界

- 紧凑 `haikalat.animation-clip/1` 是 Haikalat 导出格式，不重新解释 GeckoLib 原始 Molang、
  BLEND、声音、粒子或 timeline；需要完整 GeckoLib 语义时应在导出阶段烘焙；
- ModernUiDemo 是独立展示与验收入口，offscreen subtree replay/cache reuse 仍属于后续 UI
  优化范围；
- 远端 CI 和托管平台 Release 需要在配置对应 runner/remote 后单独完成，本报告只声明本机
  staged candidate 验收。
