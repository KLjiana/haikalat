## 2. 冻结范围

0.27.4 只新增统一配置／控制面，沿用现有 owner 与候选事务：

- 不可变完整快照：`RenderFeatureSettings`（嵌入 `RenderSettings`、
  `PostProcessSettings`、`VolumetricFogSettings`、`OutdoorEnvironmentSettings`、
  阴影／聚簇配置；只对原先不存在的 master、direct、IBL、三类阴影、HDR VFX 和
  preview 增加布尔）。
- 统一入口：`RenderPipeline.features()` 返回 `RenderFeaturesControl`，持有
  requested／effective 快照、revision、status、failureReason 和 activities。
- 总开关 `enabled`：暂停时不触碰 host 附件、不清空子配置、不重建代次；恢复时
  失效 TAA／GTAO／体积雾历史。
- 模块开关：直接光、IBL、方向光／点光／聚光阴影、AO、体积雾、天空、后处理效果
  （Bloom／自动曝光／解析雾／AA／色调映射／调色）、HDR VFX、预览。
- 沿用 `RenderPipeline` 的 `createGeneration`／`activateGeneration`／退役对账；
  不新增 GL 资源管理器、bus 或第二套生命周期调度器。

## 4. 控制相关现有入口

| 能力 | 现有入口 | 控制接入方式 |
|---|---|---|
| master pause | 无 | 新增；在 `executeFrame` 入口返回 `SKIPPED_PAUSED`，不进入 host import／resize／绘制 |
| 直接光 | `SceneLight`、`FrameLightTable`、`FrameLightBinder`、Clustered | 新增布尔；PBR shader 已存在 `uEnableDirect`，由 `FrameLightBinder` 在材质绑定后覆盖 |
| IBL | `PbrEnvironment`（借用）、`PbrMaterialBinder` | 新增布尔；覆盖 `uEnableDiffuseIbl`／`uEnableSpecularIbl`，不销毁借用环境 |
| 阴影 | `PipelineTopology.capture` 从场景灯与容量推导 | 三新增布尔参与 capture，关闭时不创建对应 Pass／图集 |
| AO | `GtaoSettings.enabled/temporal`、`applyGtao` | 快照内 `PostProcessSettings.gtao` |
| 体积雾 | `VolumetricFogSettings.enabled/history`、`applyVolumetricFog` | 快照内配置；与解析雾互斥校验在候选分配前 |
| 天空 | `OutdoorEnvironmentSettings.enabled`、`applyOutdoorEnvironment` | 快照内配置；与 IBL 独立 |
| 后处理 | `RenderSettings`、`PostProcessSettings`、`applyVisualSettings` | 快照内配置；逐效果 Pass 与共享 surface 需求由 topology 重算 |
| HDR VFX | `hdrVfx*` recorder | 新增布尔；关闭时不把 recorder 传入后处理，也不调用 |
| 预览 | `GraphPreviewController`、`previewOverlayRecorder` | 新增布尔；关闭时不创建 preview renderer／不执行 prepare／frame 回调 |

## 5. 基线限制

- 当前只验证了主源码编译、`publicApiGuard`／`architectureGuard`／
  `assetManifestGuard` 与既有聚焦 GL 冒烟；没有在基线上重跑完整 0.27.3 矩阵。
- JAR 仍是 0.25.0；不得把旧 JAR 的 38 项 GL 结果当作 0.27.4 产物证据。
- NVIDIA `131218` 是驱动性能提示，不是功能错误；它只允许在策略文件登记的
  套件／上限内出现，不能全局静音。
- 性能、多硬件与真实 Minecraft 视觉仍未评估。
