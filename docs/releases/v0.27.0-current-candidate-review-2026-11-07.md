日期：2026-11-07。结论：**第一阶段体积雾边界与生命周期试点在当前本机预算范围内完成，releaseReady=false。** 本报告补齐预算调整、静态光照复用、有界 FP32 介质缓存及求积策略变化后的验收，不改写[首次阶段记录](v0.27.0-phase1-review.md)或旧归档。

## 预算与性能结论

完整数值与适用配置见[本机预算政策](../performance/v0.27.0-rtx3050-budget-policy.md)。正式样本 run `3215aca0-6645-47d6-bc95-5c619237f18c` 保持原 `f1a36c…` 指纹，三轮各侧 120 warmup + 300 measured，900/900 同索引配对，GPU 覆盖率 100%。本轮未重新运行 benchmark，状态为 **REUSED_PASS**。

| 范围 | GPU 增量 p95 ms | CPU execute 增量 p95 ms | 新预算 |
|---|---:|---:|---|
| 第 1 轮 | 1.805312 | 0.4034 | PASS |
| 第 2 轮 | 1.723392 | 0.4579 | PASS |
| 第 3 轮 | 1.694720 | 0.3981 | PASS |
| 汇总 | 1.745920 | 0.4373 | PASS |

这些是该 1080p 固定配置的 fog-on − fog-off 增量，不是整帧耗时或 Minecraft 帧耗时。当前样本 GPU 满足旧 2.0 ms 线，CPU 超过旧 0.35 ms 线，旧合同整体未通过。4K 较早候选的 5.805056 ms 只作记录，不冒充当前候选的 4K 性能验收。

资源模型补齐缓存后，BALANCED 4K 的保守私有存储加参数为 126,295,568 bytes；加全尺寸单采样颜色/reactive 为 200,945,168 bytes，两代 401,890,336 bytes，仍在原字节上限内。均为分配估算，不是驱动显存测量。关闭状态无雾缓存，静态 clustered 结果由其原 owner 持有，只有完整输入相同且成功帧提交后才可复用。

质量取舍明确保留：未分配阴影灯 4 节点、分配阴影灯每面板 8 节点、分配阴影 Spot 2 个角度面板。新完整参考矩阵在原门槛下通过，不能称为与首次纯结构重构逐像素相同或全部收益来自无损优化。
