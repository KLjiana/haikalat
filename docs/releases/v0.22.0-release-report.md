# v0.22.0 文本子系统与 Markdown/UI 字体特效正式版验收报告

> 版本：`0.22.0`
> 状态：`0.22.0`
> 发布日期：2026-08-08
> 基线：v0.21.1
> 主题：共享文本子系统、CommonMark Markdown 与可验证字体特效

## 执行摘要

v0.22.0 将字体、排版、glyph atlas 和 CommonMark 解析收敛到共享的
`com.kaleblangley.haikalat.subsystems.text`。UI 通过 `UiTextEngine` 适配该服务，Markdown
和其他消费者不再重复维护文本解析、字体注册或布局逻辑。版本同时提供了可复现的 Markdown
与字体特效 Demo，并修复了字体切换后 inner glow 退化的问题。

## 版本范围

- `TextSystem` 统一字体注册、fallback、HarfBuzz shaping、FreeType rasterization、布局、
  Unicode 边界和 glyph atlas 请求。
- `MarkdownParser` 使用 CommonMark Java 0.24.0，输出 renderer-neutral `MarkdownDocument`。
- `MarkdownTextDemo` 展示 block/inline Markdown、字体切换、字体大小调节和六类文本效果。
- 默认 UI 字体会跟随 `UiSystem.selectFontFamily(...)`，显式 JetBrains Mono 等字体保持固定。
- inner glow 使用局部覆盖率范围检测内部边缘，兼容 anti-aliased 和接近二值的字体覆盖率。

## API 与架构

- 新增 `subsystems.text.TextSystem`、`BundledFonts`、`MarkdownParser` 和 `MarkdownDocument`。
- UI text 类迁移到共享 text subsystem；`UiTextEngine` 只负责 UI 节点到共享文本服务的适配。
- 架构边界测试确认 text subsystem 不导入 UI、backend 或 OpenGL 类型。
- 不新增 Dialog/TaskDialog 公共契约；本版本发布范围聚焦文本基础设施和 Demo。

## 兼容性与限制

现有 UI Label、TextField、glyph upload 和 display-list 合同保持兼容。正式承诺 Latin/CJK
文本；完整 BiDi、彩色 emoji、variable-axis UI、富文本 UI widget 和编辑器仍不在本版本范围内。

## 发布门禁

最终候选必须在所有 0.22 文件完成 staging 后执行：

```powershell
.\\gradlew.bat releaseReadiness -PreleaseVersion=0.22.0 --rerun-tasks
```

该命令会验证 staged candidate、依赖锁、资产清单、公共 API、架构边界、JVM 测试和桌面
OpenGL 集成，并写入 `build/reports/release/readiness.json` 与 `readiness.md`。
