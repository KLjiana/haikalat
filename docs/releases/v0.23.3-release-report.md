# v0.23.3 GTAO 稳定性补丁发布报告

> 版本：`0.23.3`
>
> 状态：`0.23.3`
>
> 日期：2026-08-21

## 发布范围

v0.23.3 是 v0.23.2 的纯加固补丁，修复固定摄像机下 GTAO 接触阴影抖动：

- 静止 view 保持稳定 GTAO sample phase，不再每帧轮换全屏统一角度；
- 真实摄像机移动时继续轮换 temporal phase 以收集额外样本；
- phase 判定比较未带 TAA jitter 的 view matrix；
- 摄像机开始/停止移动时丢弃一次旧 history，避免相位模式切换跳变；
- 增加静止 view phase JVM 回归测试。

不改变 GTAO 的公开设置、RenderGraph 拓扑、资源格式、PBR texture unit 13、性能预算或 v0.23.2
已接受的 4K disabled GPU 历史对照策略。
