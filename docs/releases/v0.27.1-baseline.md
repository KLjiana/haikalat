## 生产路径与责任清单

| 路径 / owner | 开工事实 |
|---|---|
| `RenderPipeline.createGeneration` | 构造 GTAO 深度程序并连接深度/表面生产者；Geometry 依赖 GTAO upsample；PBR 间接光使用 AO |
| `GtaoPasses` | 四个 fullscreen 程序、quad、可选双缓冲历史；estimate → temporal → denoise → upsample；历史只在整帧成功时提交 |
| `PostProcessPassBuilder` | 构造、关闭、resize、import、帧回调、失效及诊断均代理 GTAO；这是需要移出的完整生命周期代理 |
| `PipelineGeneration` | 拥有 Graph、后处理、雾与其他 owner，已支持借用资源转交、候选失败清理和 fence 退役 |
| `SceneSurfacePass` / resolve | Graph 拥有 D24 或 MSAA 深度、RG16F signed-oct 世界法线及运动数据；MSAA resolve 产出单采样 R32F 深度 |
| `GtaoHistory` | 两个 half-resolution RG16F 目标，Graph 仅 import 借用；read/write 交换由成功提交决定 |

## M1 正确性修复

不把已知错误输出冻结为迁移参考。以下修复与后续所有权迁移分开保存于 `m1-correctness.patch` 和源清单：

1. **MSAA resolve 顺序。** 生产 estimate 原来仅依赖 SceneSurfacePass，实际执行顺序可在 resolve 前读取旧深度/法线。`m1-before-runtime.log` / `m1-before-xml/` 保留真实首帧失败及原执行顺序；显式连接实际 resolve producer 后，首帧、移动和奇数尺寸 resize 通过。
2. **共享法线编码。** 表面生产者写 signed-oct RG16F，GTAO 将其当作 unsigned-oct 解码。`m1-normal-before-xml/` 保留实际世界/视图法线比较失败。修正解码输入区间，GTAO 自己的 unsigned normal cache 保持原合同。
3. **MASK 顶点 alpha。** 表面与独立深度路径原来只乘贴图和材质 alpha，漏掉 PBR 顶点 alpha。`m1-mask-before-xml/` 保留零顶点 alpha 仍造成隐形遮挡的失败；补齐 shared/instanced varying 与 masked uniform。修复后带不可见 MASK 对象与不带该对象的表面法线、AO 和线性 HDR 逐值一致。
4. **Sampler 隔离。** GTAO 的 raw texture binding 会继承前一材质的 sampler，造成同场景不同前序绘制状态下的输出变化。各 GTAO 输入显式恢复纹理自身的采样参数。现有 `CommandBuffer.bindSampler` 增加 null→解绑语义，使用已有 typed opcode，不新增全局状态旁路；原材质 Texture2D+null-sampler 入口已有同样含义。污染 sampler 的真实 GPU 回归要求 AO 逐值一致。
5. **停用绑定。** PBR Shader 在 AO 关闭时也明确设置 uGtaoEnabled=0、解绑 AO texture/sampler，避免跨 Pipeline 或运行时关闭残留旧状态。

最初测试编写阶段的 `m1-before.log` 是编译失败（RenderPipeline 不是 AutoCloseable），不计为生产缺陷证明。`m1-after.log` 的旧 A/B 用例零差异及后续诊断保留原身份；定位 sampler 状态后修复，临时 trace 已移除，没有降低原像素断言。

## 修正后参考与容差

M1 冻结源指纹：`6e5a7282ef44853b475eaad982b611ec87b2283bbb177563e35b9192c3f940db`，1821 个源码/配置文件。`m1-frozen.log` 退出 0，用时 22 秒：15 GL、10 JVM，零失败、错误、跳过。XML、源清单、像素及 SHA256 分别为 `m1-frozen-xml/`、`m1-source-files.json`、`m1-frozen-pixels/`、`m1-frozen-pixel-hashes.json`。

主场景使用真实 PBR、固定 studio-small/testQuality IBL、三个接触面与稳定方向光，无随机输入。原生 96×64，NONE/TAA/MSAA4；每种采样覆盖初始帧、相机平移至 (2.1,1.4,4)、resize 至 97×65。原相机为 (2,1.4,4)、yaw=-116、pitch=-15。捕获 GTAO R8 输出和实际线性 HDR，float32 以 little-endian 保存。修复后的三种采样、三种状态是迁移对照，不冒充完整发布画质矩阵。
