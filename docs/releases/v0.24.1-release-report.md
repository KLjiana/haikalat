# v0.24.1 统一 Scene Buffers 与原生 TAA 发布报告

状态：`0.24.1`

日期：2026-09-10

## 已落地

- 共享场景表面：`SceneBufferRequirements`/`SceneBufferView`、R32F、多重采样纹理、
  共享深度附件与外部 history 借用；`SceneSurfacePass` 单采样与 MSAA 双路径生产
  depth/normal/velocity/previous-depth/validity，MSAA 由 `SceneSurfaceResolvePass`
  按最近设备 sample 一致解析，Forward Geometry 共享深度并保持 LEQUAL 一致。
- 成功帧协议：`TemporalFrameState`/`TemporalSceneState`/`TemporalDrawBinding` 的
  prepare-finalization 与统一发布；失败帧不推进历史、相机、Model 或 previous 上传，
  退场对象按 membership 剪枝，共享绑定不被误失效。
- 原生 TAA：`TaaHistory` 颜色+R32F 深度双缓冲、`taa-resolve.frag` 重投影/深度校验/
  邻域 clamp/reactive/背景方向重投影，HDR 与 LDR 两条路径；`Material.temporalReactive`
  与 `SceneReactivePass` 提供真实 reactive 生产者。
- 消费者迁移：GTAO estimate/temporal 使用公共 depth/normal/velocity/previous-depth/
  validity 与 jitter 修正，删除重复 depth prepass 与法线重建。
- 验收入口：`Render3dTemporalDemo`、`runRender3dTemporalIntegration`、
  `runRender3dTemporalDemoIntegration`、`runRender3dTemporalBenchmarks`、
  `runRender3dTemporalQuality`、`localTemporalVerification`。
- 已知边界：内建风动/自定义变形上一帧参数协议、体积雾帧状态与雾区降权、离线高采样
  参考序列未纳入本版本；见 `docs/planning/v0.24.1-scene-buffers-and-taa.md` 第 0 节。

## 性能与画质证据

CPU 预算按录制/提交分段判定；4K 的 2 ms 墙钟增量已定位为驱动反压而非 CPU 工作，
测量帧前 `glFinish` 隔离后 recordΔ 为 0.02 ms 量级。完整数据见
[`docs/performance/v0.24.1-temporal-cpu-attribution-2026-09-10.md`](docs/performance/v0.24.1-temporal-cpu-attribution-2026-09-10.md)。

| 分辨率 | CPU recordΔ p50 | TAA resolve GPU p50 | 预算 | 结论 |
| --- | ---: | ---: | --- | --- |
| 1920×1080 | 0.0221 ms | 0.3625 ms | 0.5 ms / 1.0 ms | 通过 |
| 3840×2160 | 0.0157 ms | 1.8053 ms | 0.5 ms / 3.0 ms | 通过 |

画质门禁：抗锯齿能量 ratio 0.420（门限 0.85）、边缘锐度 ratio 0.712（门限 0.65）、
切镜残影 0 帧（门限 ≤8），报告写入 `build/reports/temporal/<candidate>/quality/`。

## 发布偏差

完整 `releaseReadiness` 在 `comparePerformanceBaseline` 失败：
`static-all-visible` CPU 中位数（3.27–3.35 ms）超过 v0.17.2 基线
（2.977 ms）的 5% 容差。同机 A/B 显示 HEAD（v0.24.0）在同一环境同样为
3.5 ms，候选没有回归；失败来自当前机器的换页/内存压缩导致的整机变慢。
按项目所有者决定带偏差发布，完整证据与后续处理见
[`docs/performance/v0.24.1-release-deviation-2026-09-10.md`](docs/performance/v0.24.1-release-deviation-2026-09-10.md)。

人工复核使用同一固定曝光对照 NONE/TAA 单帧与固定路径序列；截图不替代真实 GL 门禁。
远端 GPU/驱动差异由 CI 记录为独立环境风险。
