# v0.18.2 纹理化 HDR VFX 与 Bloom 合成发布验收报告

状态：`0.18.2`，正式发布

日期：2026-07-26

环境：Windows、Java 21、LWJGL 3.3.3、OpenGL 4.6.0 NVIDIA 576.88、
NVIDIA GeForce RTX 3050 Laptop GPU。

## 发布范围

本版本合并 v0.18.1 的曲线、over-life 和动画过渡内部验收候选，并完成 v0.18.2 纹理化 HDR VFX。
范围只包含 Haikalat 本体，不包含 HaikalatHost、Minecraft、宿主事件、网络或模组适配。

## 主要能力

- 新增无 GL 依赖的 `VfxMaterial/VfxVisualSet/VfxUvRegion`，支持显式 mask、Alpha/Additive、
  emissive、billboard、velocity stretch、soft-particle distance 和逻辑纹理引用。
- renderer 独占 R8/sRGB texture cache；particle、camera-facing Ribbon 和 surface Decal 均使用 UV quad；
  Ribbon stretch UV 沿整条路径反向累计，最新头部采亮端；相邻段共享 miter 边界且没有 additive overlap，
  纹理方向与无亮缝连接已通过纯 trail 连续窗口验收。
- `RenderPipeline.hdrVfx` 在 tone mapping 前合成 VFX；自动曝光读取 base HDR，Bloom 读取 VFX composite，
  UI 保持在最终 backbuffer 阶段。
- scene depth 支持遮挡和 soft-particle fade；MSAA 使用 typed depth blit resolve，不做 CPU readback。
- VFX 采用“类型 / 作者 / 素材包 / 资源”单层目录；完整素材包与许可记录进入 JAR，
  代码直接引用素材包内文件。
- VfxDemo 提供 legacy、fire/smoke、impact、trail/all 入口；Showcase 覆盖 MSAA 与自动曝光组合。

性能和资源数据见
`docs/performance/v0.18.2-textured-hdr-vfx-2026-07-26.md`。

## 明确限制

本版本不包含 flipbook、Ribbon repeat UV、VFX fog shader、Bloom scatter/highlight clamp、VFX batching、
编辑器、JSON effect schema 或 GPU 粒子重写。完整 VFX 素材进入 JAR，发布时必须保留
`vfx/licenses` 中的 Luos/WrizFX 来源与授权说明并遵守其条款。
