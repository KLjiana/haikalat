# v0.22.2 共享 GLB 动画补丁正式版验收报告

> 主题：共享骨架的外部 GLB 动画与多模型绑定

## 执行摘要

v0.22.2 将“模型 glTF + 独立动画 GLB/JSON”作为稳定资产管线的一部分。新增不可变
`GltfAnimationSet`，允许同一套骨架动画绑定到多个 Mesh、UV、材质或贴图不同的模型；
GLB 清单入口可按 clip 名称选择动画，既有 JSON sidecar 和紧凑外部 clip 入口继续兼容。

## 版本范围

- `GltfAnimationSet` 只保留 Rig 签名和不可变动画定义，不复制关键帧数组，也不持有动画源
  的 Mesh、材质、图片或 sampler。
- 绑定严格校验节点名唯一性、节点顺序与父节点、bind TRS、skin joint 顺序和 inverse-bind
  matrices；目标 Mesh、UV、材质和贴图可以不同。
- `haikalat.gltf-animation-library/1` 的 `animations[].file` 支持 `.glb`。单 clip GLB 可
  省略 `clip`，多 clip GLB 必须显式指定 `clip`；输出名称仍由清单条目控制。
- `GltfSceneAsset`/`GltfSceneInstance` 提供共享动画集实例化入口；实例继续独立维护播放时间、
  PoseBuffer、Animation Graph、marker/window 和蒙皮 palette。
- Demo task `runGltfSharedAnimationIntegration` 纳入动画 JVM 验证和 `localGltfVerification`。

## 兼容性与明确限制

旧的 `GltfAssetLoader.load(...)`、JSON animation sidecar、`AnimationPlayer` 和
`AnimationGraph` 入口保持兼容。共享动画只接受严格相同 Rig；不支持把不同骨架、不同关节
顺序或不同 inverse-bind matrix 强行绑定。GeckoLib 原始 Molang、声音、粒子和 timeline 仍
不在核心 glTF 解析范围内，应在导出阶段烘焙或由宿主适配。

本补丁没有新增稳定公共渲染类型、shader 分支或窗口/GL 上下文职责；动画 GLB 的 GPU 资源
不会被共享动画集接管或重复释放。
