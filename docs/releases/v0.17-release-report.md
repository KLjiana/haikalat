# v0.17 正式版验收报告

状态：`0.17.0`，正式版
日期：2026-07-19
环境：Windows 11、Java 21、LWJGL 3.3.3、OpenGL 4.6

## 已完成

- revision 驱动的 Transform/fixed model 与 world-bounds cache，任意 updater 保持每帧一次语义。
- forward/shadow 独立完整 matrix key；稳定帧复用，camera/light/resize/mutation 分别失效，TAA jitter
  不参与 visibility key。
- `CommandBuffer` mat4 快照进入可复用 primitive arena，保持录制时复制语义；geometry/shadow
  使用 pass-local shader/material/mesh binding cursor。
- 项目自有多 node/primitive/material glTF fixture、共享 GPU 资源扩容、100/1k/10k 四种布局与真实像素验证。
- diagnostics Overview/JSON 增加 static/dynamic、model/bounds hit/miss、queue reuse/rebuild、command
  record、matrix snapshot 和 object payload。
- allocation、静态 all-hidden、100 compatibility 与 camera-motion 门槛均达到；五轮结果见
  `docs/performance/v0.17-scene-submission-2026-07-19.md`。
- `Scene.add(SceneObject)` 为每个对象创建独立的可变 `MaterialInstance`；同一 `Material` 的对象不再
  串扰 override，同时无 override 的相邻实例仍可安全折叠 binding。
- `recordedMatrixSnapshotCount()` 与 `recordedObjectPayloadCount()` 已正式记录为 advanced diagnostics
  API，并由可见性、reset 和公共签名测试覆盖。
