# v0.18.1 VFX 曲线动画、缓动与过渡验收报告

状态：`0.18.1-SNAPSHOT`，内部候选验收完成；经审批合并进入 v0.18.2
基线：`v0.18.0`
日期：2026-07-25

## 范围

- `core.curve` 纯 CPU 曲线、track、gradient、空间路径与 LUT。
- particle/Ribbon/Decal over-life 属性，保留未配置 asset 的 0.18.0 行为。
- `AnimationMixer` base cross-fade、layer fade、incoming-only 事件与根运动混合。
- VfxDemo/Showcase 可见证明、10,000 粒子性能 A/B、public API 与架构边界。

明确不包含 AnimationGraph、编辑器、JSON VFX 资产、GPU 粒子重写或 glTF sampler 修改。

## 发布门禁

| 门禁 | 结果 |
| --- | --- |
| `check --rerun-tasks` | 通过 |
| `publicApiGuard` | 通过 |
| `architectureGuard` | 通过 |
| `localGlVerification --rerun-tasks` | 通过：62 个任务，8 分 41 秒 |
| `localReleaseVerification --rerun-tasks` | 通过：49 个任务，7 分 27 秒 |
| `comparePerformanceBaseline --rerun-tasks` | 未通过：`static-all-visible` CPU median 超过 5% 门槛 |

功能验收同时覆盖 `runAnimationIntegration`、curved 模式的 `runVfxIntegration`、
`runShowcaseIntegration` 和 3,600 帧 `runShowcaseStabilityIntegration`。VFX 集成产生 68 次
primitive draw 并通过 resize；Showcase 产生 230,400 个非黑像素和 2 个 incoming events，
稳定性运行中预热后的资源集合保持不变，关闭后资源计数归零。

性能原始条件与结果见 `docs/performance/v0.18.1-vfx-curves-2026-07-25.md`。真实 GL 使用
NVIDIA GeForce RTX 3050 Laptop GPU / OpenGL 4.6 / 驱动 576.88；输出中只有已知的 NVIDIA
MEDIUM shader recompilation 与 pixel-transfer performance 消息，没有 HIGH、`GL_INVALID_*` 或资源泄漏。

正式 `releaseReadiness -PreleaseVersion=0.18.1 --rerun-tasks` 在完整 staged candidate 上执行时，
编译、测试、public API、架构和资源生命周期阶段通过，但结构化性能比较阻塞了后续发布图。
同日 `0.18.0` readiness 的 `static-all-visible` CPU median 为 `2.703 ms`，固定门槛为
`3.126 ms`；本候选连续复测为 `3.775 ms`、`3.680 ms`，高优先级和 P-core 限制下最佳为
`3.295 ms`，临时高性能电源方案下仍为 `3.567 ms`。候选没有修改 scene submission 路径，
但门禁没有通过，因此不切换正式版本号。维护者于 2026-07-26 审批取消独立的
`v0.18.1` release commit/tag，将本候选完整合并进入 v0.18.2 单一发布候选；本报告继续作为
v0.18.1 内部功能验收边界和性能例外证据。
