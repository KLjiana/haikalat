# v0.24.2 Clustered Forward 发布准备报告

状态：版本号已准备，待最终提交与 Git 标记；尚未完成完整发布验收。

## 本版内容

- 统一局部灯表、Clustered Forward compute 分簇、inline 灯索引与 overflow 全灯回退。
- 灯光容量与阴影槽预算分离，删除旧 LightingBinder 和固定 2/8/4 数组路径。
- compute-only RenderGraph pass、独立统计 pass、异步诊断与 resize 生命周期修复。
- lab/town/stress demo、质量序列、性能矩阵及专项 GL 回归。

## 待关闭或明确接受的限制

1. 正式 benchmark 入口仍默认 CPU 隔离，尚缺最终候选的正常非隔离正式报告。
2. 已有 benchmark 指纹不对应当前源码；本次更新 build.gradle 版本也会改变指纹。
3. 跨轮晚到及最后一轮尾部 GPU 样本回收仍有缺陷；现有覆盖率达到 95% 门槛。
4. 同灯数 full-scan 性能对照、零局部灯 CPU 增量及完整 HDR/集成矩阵尚未闭环。
5. 1024 灯场景 Geometry p95 约 108 ms，需保留高覆盖/overflow 性能退化说明。
6. 版本准备阶段已补跑 check；releaseReadiness 尚未执行，不沿用 v0.24.1 的通过状态或硬件偏差豁免。
