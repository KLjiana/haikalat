# v0.24.3 渲染收尾与视觉基线发布候选报告

状态：`0.24.3` 候选；专项性能、视觉与本地回归已通过，但完整 `releaseReadiness` 于 2026-09-23 在旧 GTAO 性能门禁失败。尚未发布、提交或创建 tag；不能把专项通过等同于发布就绪。

日期：2026-09-23

## 本版内容

- 按提交身份归档异步 GPU query，支持跨轮晚到、尾部回收、逐轮覆盖率和同帧完整 pass 配对；正式正常运行与 CPU 隔离归因分离。
- 增加 test-only full-scan PBR 参考、同几何零灯 CPU 对照、1080p/4K 资源统计和 round-major A/B 交错矩阵。
- 将 Outdoor 构图、帧状态与历史资源拆到 generation 内唯一 owner，保留 resize、失败回滚和成功帧事务。
- 增加版本化视觉 profile、严格/原子 properties codec、方向光/IBL/曝光/Bloom/Outdoor typed 热更新，以及晨雾、黄昏、夜镇固定路径重放。
- 三场景分别冻结 60/240/420 线性 HDR float 回归参考，并输出误差图与 final/fog-off/Bloom-off/固定曝光灰模对照；修复 TAA 外部颜色目标让 Bloom 首级提取静默跳过的错误。
- Outdoor 在相同三帧输出散射、透射率、历史拒绝附件图，并与 96-step、全分辨率、history-off 线性 HDR 参考做数值比较；夜镇输出 light-count/overflow/shadow-slot 三种真实 shader 诊断视图。
- Outdoor 可见面板接入 profile 选择、完整配置保存/重载、手动曝光、雾/Bloom 对照、路径暂停和截图；profile 与借用 IBL 在同一候选事务中应用。

## 完整发布门禁状态

2026-09-23 两次执行 `releaseReadiness -P releaseVersion=0.24.3`，均未到达最终
`writeReleaseReadiness` 汇总，因此没有可宣称通过的 `readiness.json`。首次在
`runDiagnosticsIntegration` 发现导出器误拒绝合法的 0×0 COMPUTE/EXTERNAL pass；已修复并添加
`FrameDiagnosticsTest` 回归，定向测试和完整链路中的该集成任务均通过。第二次在
`runRender3dGtaoBenchmarks` 失败：1080p disabled CPU p50 为 1.3708 ms，相对
`v0.23.1@4cc6d44` 的 0.645 ms 回退 112.5%，超过既有 2% 门槛。隔离复测本候选为
1.3654 ms，未调整预算。同机对上一提交 `daff1ab` 的隔离复测为 1.3477 ms，亦未通过该门槛；
当前候选不是此次历史对照不匹配的唯一原因。现有测量还显示 1080p enabled/disabled CPU
增量约 0.59 ms，高于既有 0.35 ms 预算。需要另行厘清可比基线和 GTAO 开销，不能仅豁免
第一项后直接宣称门禁通过。完整发布验证须在修复或明确决策后重新执行。

2026-09-23 的 GTAO 优化尝试让时域 pass 直接绘制到双缓冲 history 候选，移除半分辨率
RG16F 临时目标及逐帧全图 blit，并将 estimate shader 每个射线 tap 的逆投影矩阵乘法改为
同一射线上的齐次增量。保持 history 成功提交/失败丢弃协议。完整 `glSmoke`、
`runRender3dGtaoIntegration`、`assetManifestGuard` 和 `check` 通过。优化后 1080p A/B
测得 GTAO 链 GPU p50 0.6021 ms、开启相对关闭 CPU p50 增量 0.5352 ms（预算 0.35 ms），
关闭路径对 v0.23.1 历史 CPU/GPU 对照分别回退 109.3%/52.4%；4K 开启-only 测得 GTAO
链 GPU p50 2.2211 ms（独立预算 4 ms）。这些样本不证明整体性能改善，也未通过默认
`runRender3dGtaoBenchmarks`；没有重跑完整 `releaseReadiness` 或刷新本版正式矩阵指纹。

三场景九张线性 HDR 参考采用 tone mapping/Bloom 前的 RGBA16F 读回，按 4×4 线性平均
保存 320×180 RGB float；独立重跑的 RMSE 与逐像素 p95 均为 0，误差图在
`build/reports/render3d-v0243/visual/hdr-error/`。阈值固定为 RMSE <= 0.015、p95 <= 0.035。
这验证同机候选回归，不把冻结图当作高采样物理真值。

另由 history-off、96-step 全分辨率体积模式按同一保存 profile/路径独立生成六帧线性 HDR；与
常规基线比较的 RMSE 为 0.0027–0.0038、p95 为 0.0039–0.0057，低于 0.015/0.035 门槛。
三种 Outdoor 内部附件来自实际 RGBA16F/R16F 图目标，不由最终 PNG 反推。

## 版本边界与后续工作

1. 本版接受同一 GPU/驱动下的 HDR 回归与较高采样 Outdoor 质量对照作为发布证据，不将其宣称为解析物理真值或跨 GPU 保证。TAA 硬切镜序列会立即失效历史，误差曲线为零；运动、遮挡、灯变后的完整恢复曲线留待后续专项验证，不据此宣称无残影。
2. Outdoor 面板已验证渲染与挂接，鼠标按钮操作尚未自动化；小镇 profile 选择仍通过固定文件和 Demo 参数执行。这些属于已记录的验证范围限制，不改变已通过的数值、资源和场景门禁。
3. `v0.24.3` annotated tag 仅在完整候选 staged、`releaseReadiness -P releaseVersion=0.24.3` 成功、提交后 `releaseCleanTreeGuard` 通过时创建；当前门禁失败，因此不创建提交或标签。
