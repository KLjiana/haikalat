## 性能解释

原完整五配置 run `44a6224f-7450-4862-ac29-42848cea4429` 原始状态仍为 failed。900 帧正常 1080p 整体 GPU/CPU 增量 p95 曾为 1.752064/0.2914 ms，逐轮首轮超限。
