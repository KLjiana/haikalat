# v0.18.0 Haikalat OpenGL 4.6 路线图发布验收报告

状态：`0.18.0`，正式版

日期：2026-07-25

环境：Windows、Java 21、LWJGL 3.3.3、OpenGL 4.6.0 NVIDIA 576.88、
NVIDIA GeForce RTX 3050 Laptop GPU。

## 发布范围

本版本完成 `docs/planning/haikalat-future-opengl46.md` 中 Haikalat 本体的 Milestone 1A 至 4。
范围明确不包含 HaikalatHost、Minecraft、模组事件、网络同步或宿主适配；无 GL 调用的动画、
资源、UI 动画和 CPU VFX 能力均位于 `subsystems`。

## 主要能力

- 建立无 GL 骨骼动画、glTF skin/animation、CUBICSPLINE、四权重 GPU 蒙皮、动作事件、
  Bone Mask、双层混合、根运动与 Two-bone IK 闭环。
- 建立 OpenGL 4.6 capability contract，以及带 generation 和过期结果拒绝的异步 CPU 资源协议。
- 新增 Color Grading LUT、距离/高度雾、UI Tween/Transition 与确定性动画诊断。
- 新增有界 CPU 粒子、Ribbon、Decal，点光/聚光阴影及方向光级联矩阵方案。
- 新增 Compute/SSBO GPU 粒子和固定步数体积光受控实验；正式 GPU 粒子路径没有 CPU readback。
- `HaikalatShowcaseDemo` 同帧组合上述能力；3,600 帧验证预热后 GL 资源集合和估算显存不漂移，
  所有资源关闭后归零。

性能数据与硬件边界见
`docs/performance/v0.18.0-haikalat-roadmap-2026-07-25.md`。
