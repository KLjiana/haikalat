# v0.19.4 UI 深化正式版验收报告

日期：2026-07-28。

状态：`0.19.4`

本正式版完成 `0.19.1` SDF、`0.19.2` property animation、`0.19.3` 显式 layer topology 与
`0.19.4` deterministic UI VFX 的连续实现，并把 Gradle metadata 统一为正式
`0.19.4`。

已验证：

- ordinary quad/image/glyph 与旧 animation API 保持兼容；
- visual transform 同时影响顶点、祖先继承、clip AABB 与逆变换 hit-test；
- sequence/group/stagger/repeat/reverse、marker signal、enter/exit、FLIP 和 reduced motion；
- layer id/tree/budget、managed color/blur target、resize、backdrop unavailable fallback；
- fixed-seed effect、capacity、detach/cancel、signal dedup、immutable frame freeze 和
  3,600 帧 soak；
- 统一内建字体目录及 JetBrains Mono 2.304 + Noto/Unifont CJK fallback；
- 独立 ModernUiDemo 真实 GL 60 帧 pixel proof（15 nodes、320 quads、16 draws）；
- public API、architecture、asset manifest 与 GL debug policy 继续由现有门禁管理。

性能证据：`docs/performance/v0.19.4-modern-ui-2026-07-28.md`。

独立重跑 `runSceneSubmissionStaticBenchmarks --rerun-tasks` 后，10,000 个 all-visible draw
的五轮中位数约 3.567 ms，确认不是单轮测量噪声。该门禁失败被保留为正式证据；本次不宣称
完整 readiness 通过，也不据此创建正式 tag。ModernUi 的重复 transition 压力、最大帧时间和
慢帧检查仍独立通过。

实验性限制：

- advanced layer API 已建立 managed offscreen topology，但本正式版仍以 direct subtree draw
  作为最终视觉 fallback；target 内的 subtree replay、blur composite 与跨帧 cache reuse
  尚未替换该 fallback；
- rotated clip 在 GPU scissor 阶段使用保守 AABB，hit-test 使用精确逆矩阵；
- effect particle renderer 复用 UI SDF/quad ring，尚无独立 instance buffer、sprite atlas
  或 compute simulation；
- compositor/VFX API 均保持 advanced/internal 分类，不提升为 stable。

这些限制不会改变普通 UI 输出、颜色空间、输入或资源所有权；缺少 backdrop source、预算溢出和
未启用 compositor 都有确定性 direct fallback。
