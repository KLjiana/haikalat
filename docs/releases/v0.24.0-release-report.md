# v0.24.0 室外环境与体积阳光发布报告

状态：`0.24.0`

日期：2026-09-08

## 已落地

- `OutdoorEnvironmentSettings`、天空预设、主太阳、全局高度雾和最多 8 个球/盒局部雾体；
- HDR CSM 感知体积阳光积分、独立半分辨率历史、邻域裁剪和深度感知上采样；
- OPAQUE/MASK + 主太阳 CSM 的样板林地与 `runOutdoorEnvironment*` 验证入口；
- IBL diffuse 归一化的 JVM 数值回归，以及 PBR forward/shadow-budget shader 同步修正；
- resize/代次关闭路径、MSAA/TAA/FXAA/Bloom 组合的短跑 GL 验证。
- 独立 R16F 深度历史与上一帧 VP 重投影、深度拒绝和邻域裁剪；质量档切换会重建正确的
  半/四分之一分辨率目标。
- 纯 JVM Beer–Lambert、均匀介质散射和 Henyey–Greenstein 参考测试；高采样、历史关闭的
  reference 档可复现。
- 3,600 帧稳定性、100 次预设/尺寸切换和 10 次颜色/深度历史失败注入；五轮 1080p/4K
  enabled/disabled 配对基准。
- 可见 demo 的 `OutdoorEnvironmentOverlay` 调试面板：预设、质量、体积参数、历史/对比
  开关、深度/CSM/散射/透射率/历史诊断，以及 properties 配置保存/重载；隐藏门禁不附加 UI。

性能明细见 [`docs/performance/v0.24-outdoor-environment-2026-09-08.md`](../performance/v0.24-outdoor-environment-2026-09-08.md)，包含五轮配对的稳定 CPU/GPU p50/p95、分配与预算结论。

人工复核画面使用同一固定曝光，分别保存 `morning_fog`、`clear_day`、`golden_hour` 的
volume off/on 截图，并使用 `--route --frames=600` 观察树冠/树干遮挡、进入局部雾体、
相机转向和历史拒绝；`build/reports/outdoor-overlay2.png` 记录了带面板的可见复核画面。
截图不替代真实 GL 门禁；未覆盖的远端 GPU/驱动组合仍由 CI 记录为独立环境风险。使用
`--capture` 时 NVIDIA 可能报告像素读回的 `131154` 性能提示，该提示来自截图工具，
不属于正常渲染门禁路径。

正式候选执行 `releaseReadiness -PreleaseVersion=0.24.0 --rerun-tasks --console=plain`；
tag 必须指向该门禁通过的最终提交。
