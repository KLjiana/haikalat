# v0.17.1 正式版验收报告

状态：`0.17.1`，正式版

日期：2026-07-21

环境：Windows 11、Java 21、LWJGL 3.3.3、OpenGL 4.6

## 已完成

- RenderGraph attachment 与显式注册 cubemap 已接入 F2 Graph 页面、Demo、实时 diagnostics、
  FrozenDiagnostics 和纯值 JSON；选择、显示参数和发布结果以 revision 对齐，迟到帧不能覆盖新选择。
- GPU-only conversion 支持 LDR/sRGB/HDR/R/RG/depth、cubemap face/mip，以及有明确 read attachment
  的 MSAA color resolve；生产路径没有同步 readback。
- `DEPTH24_STENCIL8` 使用匹配的 depth-stencil resolve target；HDR MSAA 优先复用管线现有 resolve，
  使 1080p HDR 不再被 8 MiB 专用预算错误拒绝。
- preview 作为 UiOverlayPass 的前缀命令执行，不改变 RenderGraph 拓扑；关闭态为 0 preview draw、
  0 preview blit、0 preview resource，有效帧最多增加 1 draw/1 blit。
- UI snapshot 只保存逻辑图片 id，并在 render-record 边界重新解析。面板关闭、graph rebuild 或资源释放后，
  旧异步 snapshot 会跳过图片 batch，不会绑定已释放纹理。
- render3d preview 不依赖 UI subsystem；UI 适配只存在于 Demo overlay，依赖方向由架构测试保护。
- 新增 JVM contract、真实 GL smoke、F2 integration、JSON contract 和 1080p/4K 五轮性能入口。
- fixed-only scene 在首帧建立 model/bounds cache 后不再逐帧扫描全部 immutable source；membership
  变化仍强制重建，Transform 和 animated updater 的 revision/逐帧更新语义保持不变。
