## 执行摘要

v0.23.1 在不更换 Forward/PBR 主架构的前提下完成多局部光阴影纵向闭环。默认 runtime 继续使用
v0.23.0 的 1 point + 1 spot shader/uniform/逐帧更新合同；显式 balanced runtime 支持同帧
1 directional + 2 point + 4 spot、确定性预算、稳定 atlas 槽位、HARD/PCF 3×3/PCF 5×5、统一
base/normal bias 和逐 tile depth cache。

`ShadowFramePlan` 是 scheduler、深度 pass、sampling UBO、forward binding 与 diagnostics 的共同事实。
灯光 stable ID、priority/相机评分/迟滞、拒绝原因、slot owner、cache miss reason 和资源估值均可诊断；
静态 balanced 帧稳定复用 20 tile，单 point/spot 变化只重画 6/1 tile。

## 兼容性与资源合同

- 普通 `GltfRuntimeLibrary.create()` 继续编译原 `pbr-forward.frag`，不分配 binding 5 UBO；高级
  `createShadowBudget()` 才选择 1,392-byte `ShadowSamplingBlock` shader。
- OPAQUE/MASK 可投影，BLEND/ADDITIVE 默认不进入 depth pass；MASK alpha cutoff、instancing、skin 和
  morph deformation 均进入 cache key 与真实 GL 回归。
- 两个 point 3×2 block、四个 spot tile 与四级 CSM 均有 filter-aware guard；PCF tap 不跨 atlas tile。
- atlas/UBO 走 candidate-first generation，失败保留旧 generation；fixed atlas 不随窗口 resize 重建，
  重复 close 保持幂等。

## 性能与人工验收

专项数据见 `docs/performance/v0.23.1-render3d-shadows-2026-08-19.md`。相同 legacy 能力相对 v0.23.0
在 1080p/4K 五轮 A/B 的最差变化是 4K GPU `+0.2%`，满足不超过 5% 的发布阈值。balanced 静态帧
为 `0 redraw / 20 reuse`，估算 depth memory 为 20 MiB；legacy 为 11 MiB。

窗口化 `runRender3dShadowBudgetDemo` 已用于多局部光、预算边界、MASK/skin/morph、缓存和接缝检查。
室内 floor/ceiling/三面 wall 接收面上可见多色局部光和 caster 阴影；相机连续后退、横移时选择始终
保持 `D/P/S 1/2/4`，停稳后恢复 `0 draw / 20 reuse`。近景检查未见明显 acne、peter-panning、
point face、spot tile 或 CSM split 接缝；诊断标题可同时回答选择、重画/reuse、cache 和 filter。

## 明确限制

本版本不提供第二盏方向光 CSM、无限阴影灯、透明/面积光阴影、VSM/EVSM/PCSS、Deferred、
Forward+/Clustered、GPU-driven shadow culling 或通用空间索引。普通 light 数组没有迁移到 UBO；高级
sampling block 只服务内置 shadow-budget shader 与遵循同一 binding 合同的自定义 shader。
