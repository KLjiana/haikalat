## 2. 本版本改动

**协作指引**：根级、Gradle、测试、Render3D 四份 `AGENTS.md`；`docs/guides/testing.md` 收敛为
当前命令索引。

**验证组合**：

- `check` 不再重复执行 4 个过滤 JUnit 子集（54 次重复 case），任务图 32→28，guard 仍可单独运行。
- 新增 `glLeafVerification`（仅 GL 守卫类，排除 soak/benchmark）与 `verify.ps1 -Mode Gl`。
- 新增 [测试合同索引](../guides/test-contracts.md)：合同组、主叶子入口、成本、审计结论。
- 5 组同域单 case 测试 `MERGE` 进领域测试（断言全保留，测试类 252→247，case 仍 1150）。

**构建职责**：无桌面门禁迁到 `gradle/verification-tasks.gradle`（根文件 324→181 行）；
GL 策略解析迁到 `gradle/gl-policy.gradle`（发布脚本 1335→1205 行）；四行 JUnit 管道在 28 个
Test 任务中的重复声明合并为一处（删 104 行）；版本坐标统一由 `build.gradle` 派生。

**证据门禁**（复审 P1／P2 与后续阻塞项）：

- 全跳过或空运行不能通过：`glLeafVerification` 在 `doLast` 校验 JUnit XML；`verify.ps1` 要求
  `executed>0`，`-Mode Gl` 还要求 `skipped==0`；`releaseVerificationContracts` 断言该门禁。
- 报告绑定候选内容：`workingTreeSha256`／`workingTreeFileCount` 计算工作树全部跟踪/未跟踪文件的
  内容指纹；`workingTreeSha256After`／`candidateStable` 比较运行前后；JUnit XML 归档到
  `<runId>/junit/` 并记录 `evidence.sha256`。
- GPU 证据不复用：`-Mode Gl` 固定 `--rerun-tasks`，UP-TO-DATE 的旧 XML 判 FAIL。
- 失败分类：`FAIL`／`TIMEOUT`（exit 124）／`INVALID`（exit 2）／`NOT_RUN` 均不能算 PASS。

## 4. 未完成与边界

- 正式性能矩阵、完整视觉基线、多硬件与 Minecraft／HaikalatHost 真实宿主视觉未在本版本执行。
- Linux／远端 CI 的超时、取消与 artifact 行为未验证（配置已加入 `.github/workflows/ci.yml`）。
- 断言级 `RETIRE` 为 0；按 diff 自动选测与证据缓存未实现。
- 测试对 Demo 的编译依赖未拆分（同包测试依赖其余 Demo 类型，尝试后已回退）。
- `candidateStable` 是运行开始／结束两次快照的比较；改动若在结束前被还原则不报错。
- 本版本不代 0.27.3／0.27.4 的性能、视觉与宿主签收。

## 5. 结论

0.27.5 交付的协作指引与验证组合可执行且有正负例证据：入口去重、默认 GL 叶子、合同索引、
失败/超时/环境无效分类、候选内容指纹、归档证据绑定，以及“全跳过、证据复用、验收期改候选”
三类误判均已被门禁拒绝。**本记录只签收治理范围**，不扩大为渲染功能或发布就绪。

复审状态：独立验收的 P1（全跳过仍成功）与 P2（报告未绑定内容与归档）已修复；复验中剩余的
“运行期间候选变化仍可 PASS”由本轮 `workingTreeSha256After`／`candidateStable` 关闭，
负例见 §3。复验提出的非阻塞项（`-Mode Gl` 全局 `--rerun-tasks` 成本、根 `AGENTS.md` 中
“check 仍有重复 case”的旧描述、身份采集失败时 `candidateStable=null`）尚未处理，其中根指引
旧描述已在本次提交前修正为当前事实。
