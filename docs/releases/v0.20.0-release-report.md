# v0.20.0 代码收敛与外部 glTF 动画正式版验收报告

日期：2026-07-29

状态：`0.20.0`

环境：Windows、Java 21、LWJGL 3.3.3、OpenGL 4.6.0 NVIDIA 576.88、
NVIDIA GeForce RTX 3050 Laptop GPU。

## 发布范围

本正式版完成 v0.20 M0～M8 的内部收敛：公共 facade 与 public API allowlist 保持兼容，
UI、动画和渲染资源职责拆分到 package-private 组件；静态 UI display-list、hit-test 和
virtual-list 快路径消除无效增量工作；RenderGraph、framebuffer、TAA history 与 UI GL
资源统一采用 candidate-first 替换、失败回滚和聚合关闭。

本版同时完成 `haikalat.gltf-animation-library/1` 外部动画库链路：

- `GltfAssetLoader` 可直接读取导出 ZIP，也可通过 `AssetRef` 加载解包后的
  `animation-library.json`；
- 主模型已有 animation 与多个外部 `.animation.gltf.json` clip 按清单合并，保留
  marker、插值方式、时间与目标动画起始偏移；
- sidecar/model 节点索引和名称双重校验，动画名全局唯一；绝对 URI、目录逃逸、
  ZIP 重复条目和超限输入会在 CPU 导入阶段拒绝；
- 序列化场景把清单、主模型、动画 sidecar 与外部 buffer 注册为热重载依赖；
- `player_wild` Demo 循环播放外部 `animation` clip；25 个节点、1 个 skin 和
  11 条 rotation channel 已通过运行时映射与真实 GPU 蒙皮验证。

外部动画格式、加载示例与边界见
`docs/guides/geckolib-blockbench-gltf.md`。

## 性能与 GL 证据

v0.20 热路径与五轮性能数据见
`docs/performance/v0.20-m7-2026-07-28.md`。

- 十个静态 UI 容量测量窗口不再发布 display-list，也没有 layout、shape、paint 或
  upload 增量工作；
- 静态 all-visible CPU 五轮平均值中位数为 `2.984 ms`，与 `2.977 ms` 原始基线基本持平；
- 10,000 quad 仍约 `255 KiB/frame`，明确保留为 render/GL submission 预算；
- NVIDIA `131218` 仅为隔离 context 冷启动时按 GL state 进行合法 shader specialization；
  `131154` 仅出现在明确登记的 correctness readback；没有未授权 HIGH/MEDIUM、
  `GL_INVALID_*`、资源 use-after-close 或线程悬挂。

## 发布边界

- GeckoLib 原始 `.animation.json` 的 Molang、声音、粒子、timeline 和自定义 easing
  不由 glTF 运行时重新解释；支持的是插件导出的标准 glTF animation sidecar。
- advanced UI compositor 的 offscreen subtree replay/cache reuse 仍使用 direct fallback；
  rotated clip 的 GPU scissor 使用保守 AABB。
- UI VFX 尚无独立 instance buffer、sprite atlas 或 compute simulation。
- 当前仓库没有配置 Git remote，因此正式交付边界为本地 release commit 和 annotated
  `v0.20.0` 标签；远端推送与托管平台 Release 需在配置远端后完成。
