## 开工时的实际生产链

| 路径 | 原始需求与分配 | 消费和历史 |
|---|---|---|
| 体积雾单独开启 | 深度。没有其他表面需求时为 depth-only | 单采样 guide；MSAA 原始样本复合。雾私有历史 |
| 非时域 GTAO | 深度、法线，实际分配全部四个颜色附件 | estimate 从共享深度、normal 读取。兼容深度路径单独绘制 |
| 时域 GTAO | 深度、法线、运动组 | estimate 明确依赖实际单采样生产者。私有双缓冲 history |
| TAA | 深度和运动组，有实际生产者时再读 reactive。原表面仍分配法线 | 屏幕 TAA 读出前合并透明／雾等 reactive。TAA 单独管理历史 |
| 解析雾单独开启 | 深度。原来进入固定四颜色附件路径 | 读当前设备深度。没有雾私有历史 |

共享 surface 的四个固定颜色槽依次为 normal、velocity、previous-depth、validity。MSAA 完整 resolve 同深度保留第一个样本，无遮挡或 `bestDepth >= 0.999999` 输出背景值。旧体积雾 depth-only resolve 使用原始最小值与 clear depth 1。主场景墙面条纹和性能欠账沿用 0.27.1 的记录。

`SceneBufferView` 开工时没有生产消费调用点。GTAO 的 graph lease 参与实际绑定，体积雾输入主要携带名称，TAA 在后处理中直接引用逻辑名。新组合及生命周期应通过 GPU 验证，18 份固定场景像素只作为相同输入的迁移对照。[合同](../architecture/v0.27.2-shared-scene-surface-contract.md)
