# v0.22.1 文本与灯光缓存加固正式版验收报告

> 版本：`0.22.1`
> 状态：`0.22.1`
> 发布日期：2026-08-09
> 基线：`0.22.0`
> 定位：纯加固版本，不增加新的 stable public 类型

## 执行摘要

v0.22.1 固化了灯光 revision 的缓存失效合同、CommonMark parser 驱动的受控 Markdown
显示子集和可重复的文本性能基线。补丁保持 `Scene.lightingRevision()`，不删除兼容入口；
`TextSystem` 继续保持 GL-free，`MarkdownDocument` 不泄露 CommonMark 实现类型，UI 仍仅经
`UiTextEngine` 适配共享文本系统。

## 加固范围

- `Scene.lightingRevision()` 的 add/set/失败 topology/连续替换 JVM 回归完整；真实 GL 验证
  方向光替换会刷新 shadow light cache 与 light-space matrix，同时复用不相关 RenderGraph target。
- Markdown 正式支持 H1-H3、paragraph、quote、list 文本、fenced/indented code、strong、
  emphasis、inline code 和 soft/hard break；H4-H6 映射 H3，link 只保留显示文本，image、URL、
  list 层级/序号、fence language、HTML、table 和 thematic break 不作承诺。
- Markdown 输入上限为 1,048,576 字符；空文档、unsupported top-level 和扁平化语义均有测试。
- UI 默认字体切换只使继承节点重新布局，显式字体节点保持稳定；字体注册失败不会留下半注册
  family，初始化失败、重复 close 和 atlas lease 延迟释放均有回归。
- 普通 UI 文本不准备特效参数或进入额外 shader path；全部现有文字路径均在 1080p/4K 下建立
  CPU、GPU、allocation、cache、atlas、batch/state-break 与 GL debug 基线。

## 性能与 GL 证据

完整专项结果见 `docs/performance/v0.22.1-text-2026-08-09.md`。

- 1,000 与 10,000 glyph cache hit 均为约 0.047 KiB，不随文本长度线性增长。
- 字体切换允许一次重建，此后 shaping、layout 和 glyph upload 保持稳定。
- 普通文本为单 batch、单 draw、零 state break；效果关闭时不准备额外效果 uniform。
- 文本基准无 HIGH、`GL_INVALID_*` 或未授权 MEDIUM；NVIDIA 131218 冷启动消息受精确策略约束。
- 灯光缓存真实 GL 回归确认矩阵变化、graph identity 保持且 debug ring 无错误。
