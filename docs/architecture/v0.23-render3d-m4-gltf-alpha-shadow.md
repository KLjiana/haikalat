# v0.23 Render3D M4 glTF alpha 与 MASK shadow 合同

`GltfAlphaMode` 支持 OPAQUE、MASK、BLEND。decoder 保留 glTF 默认 OPAQUE、`alphaCutoff=0.5` 与
`doubleSided` 语义；非法输入在 CPU decode 阶段失败。runtime 将 BLEND 映射到 ALPHA queue，将 MASK
映射到 MASKED queue。

MASK 主 pass 和 shadow variant 读取同一 base-color alpha 与 cutoff。masked depth shader
只绑定剪影所需输入，不复制 PBR lighting。OPAQUE/MASKED 只有在 renderer `castShadows=true` 时进入
caster 路径；ALPHA/ADDITIVE 在方向光、点光和聚光中都被通用 caster policy 排除，避免默认 `SceneObject` 把透明物体写成
不透明阴影。透明阴影若未来引入，必须是独立策略和 shader 合同。

证明入口：`GltfAssetLoaderTest`、`MaterialTest`、`GltfRuntimeGlTest`、
`SceneVisibilityGlTest.defaultTransparentSceneObjectsDoNotEnterTheOpaqueShadowQueue` 和
`runRender3dV023Integration`。
