# v0.23 Render3D M0 基线与合同清单

> 日期：2026-08-18
> 基线：v0.22.2（commit `3380cc3`）

M0 冻结既有入口和所有权，不进行包级重命名。普通调用继续通过 `Scene`、`SceneObject`、
`MeshRenderer`、`RenderSettings` 与 `RenderPipeline` 工作；GL 资源仍由创建它的 runtime/cache/
pipeline owner 关闭，borrowed presentation attachment 不由 Haikalat 释放。

基线限制为：普通 forward queue 尚未完整表达 MASKED/BLEND，Fog 不能消费 MSAA depth，方向光阴影
默认单级，pass callback 仍可能观察可变状态。v0.23 的验收必须分别证明透明最终像素、MASK shadow、
Fog + 4x MSAA、2/3/4 级 CSM、resize、embedded 与失败清理。

稳定边界：不改变 `Scene.add/remove` 核心用法，不删除 `BlendMode`，不改变 opaque 默认，不把内部
generation/frame snapshot 强迫给调用方创建。公共 API 变化只允许增加不可变值或配置入口，并受
`publicApiGuard` 与 render3d allowlist 审核。

基线与后续空间索引决策的代表数据见
[`v0.23 Render3D M7 可见性与空间索引结论`](../performance/v0.23-render3d-visibility-index-decision-2026-08-18.md)。
