# v0.23 Render3D M5 MSAA depth resolve 合同

Fog 始终采样单采样 scene depth。启用 MSAA 时，RenderGraph 在 geometry 与 Fog 之间插入显式 depth
resolve；`DepthResolveDescriptor` 校验 source 为 multisample、target 为 single-sample、depth format
兼容且 extent 完全一致。非法组合在执行 blit 前失败。

非 MSAA 路径直接读取 geometry depth，不创建 resolve pass 或 target。resize 通过 candidate
generation 同时替换 color/depth resolve target；构建失败保留旧 generation。embedded target 的
借用 depth 还要满足 sample compatibility，Haikalat 不接管宿主 attachment 生命周期。

诊断记录 resolve 是否执行、source/target sample 和 extent。证明入口：
`DepthResolveDescriptorTest`、`FogPassTest`、`ScenePipelineTest`、`RenderPipelineGlTest`、
`runPostProcessEffectsIntegration` 与 `runRender3dV023Integration`。
