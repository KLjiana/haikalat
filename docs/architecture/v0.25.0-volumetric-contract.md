## 输入与坐标

- 世界单位沿用 Scene；正视深度 `z=-viewPosition.z`。
- 网格使用 stable/non-jittered projection；设备深度还原使用对应 draw 的投影。
- 有限 `far=min(fogDistance,cameraFar)`，要求 `0<near<far<=1024`。支持标准透视和正交，拒绝斜裁剪及含缩放的相机变换。
- 透视边界 `b0=0`；`bk=near*(far/near)^((k-1)/(Nz-1))`，`k=1..Nz`。
- 正交边界 `bk=far*k/Nz`，射线从相机平面对应 XY 发出；透视路径长度为深度差除以 `abs(ray.z)`。
- 关闭体积历史使用区间中点；启用时使用成功帧驱动的 depth jitter，phase 在 [0.15,0.85]。边界和 ds 不随 jitter 移动。
- 对数层历史按实际采样深度插值；越界先拒绝，禁止依赖 clamp-to-edge 伪造有效历史。
- 每点重新转换到 lighting cluster；近裁剪前段及 overflow 使用正确的全灯 fallback。

## 介质与积分

`sigma_s=sigma_t*albedo`，`sigma_t>=0`，albedo 在 `[0,1]`；emission 是非负单位路径长度源。
重叠介质分别相加 extinction/scattering/emission。最多 8 个局部球/轴对齐盒；盒 extent 是半尺寸。
全局一个 `g∈[-0.9,0.9]`。`L` 指向灯，`V` 指向观察者，`mu=dot(-L,V)`。

```text
q = emission + sigma_s * sum(lightRadiance * HG(mu,g) * visibility * volumeIntensity)
tau = sigma_t * ds
Tseg = exp(-tau)
factor = (1-Tseg)/sigma_t
Snext = S + T*q*factor
Tnext = T*Tseg
```

小 tau 用 `ds*(1-tau/2+tau*tau/6)`；零消光仍积分 emission。prefix 存 `Nz+1` 个边界，
查询任意深度时从前边界补算最后部分区间。XY 四列分别在同一物理深度查询后插值。
采用单次散射，不计算灯到采样点的介质衰减。方向/Point/Spot 复用现有灯单位，空气不乘 GTAO。

## 格式与有限范围

| 资源 | 格式 | 尺寸 / 内容 |
| --- | --- | --- |
| medium | RGBA16F | Nx×Ny×Nz；sigma_s RGB / sigma_t A |
| emission | RGBA16F，可选 | 同网格；单位长度 emission RGB |
| current-source | RGBA32F | 同网格；FP32 当前 q RGB / 从 RGBA16F medium 复制的 sigma_t A |
| history-read/write | 各 RGBA16F | 同网格；过滤 q / 对应帧 sigma_t |
| prefix / guide / selector | RGBA16F | Nx×Ny×(Nz+9)；前 Nz+1 层为边界 S RGB / T A；后续一层 opaque 深度、三层区间 mask、四层近灯索引 |
| reject | R8 | 同网格；拒绝或低置信度 |
| reactive-prefix | R8 | Nx×Ny×(Nz+1)；沿射线累计的可见照明变化 |
| light-off-reactive | R8 | Nx×Ny×Nz；已知关灯事件的局部强响应，下一稳定帧清零 |
| fog-reactive | R8 | render size，graph 颜色链借用 |
| opaque-composite | RGBA16F | render size / 对应 sample count；graph 所有 |

无默认 mip。`Texture3D` 当前接受 RGBA16F/RGBA32F/R8，单级 immutable DSA storage；资源使用前检查生命周期。
layered image3D 绑定整个卷；非 layered image2D 绑定明确单层，两者是不同命令。

输入和诊断界限冻结在 [verification.properties](../../config/volumetric-fog/verification.properties)：
相加后的 sigma_t ≤64、emission 各分量 ≤16、q 各分量 ≤4096、累计 S 各分量 ≤32768、
高度指数绝对值 ≤16。半精度有限最大值 65504。所有源项在 float32 计算，写入前检查有限范围。
这些是独立存储界限，并不保证任意组合均合法；积分仍需检查累计界限。
正常验收越界/限幅计数须为 0；压力输入明确拒绝或报告降级，不得夹值后宣称数值通过。
M2 量化实验若需修改界限，在正式候选前保留新旧值与原因。

## 绑定与同步

逐 shader 的机器可读合同为 [bindings.tsv](../../config/volumetric-fog/bindings.tsv)。
PBR reactive fragment variant 当前声明 20 个 sampler；prefix/filtered-source 使用 14/15，reactive 查询使用 16/17/18/19/20，FP32 current-source 使用 21。各链接 variant 的实际活跃数量和 binding index 分别核对设备限制。
现有 IBL 8/9/10、CSM 7、Point 11、Spot 12、GTAO 13 保留。自定义材质组合在 M4 验证。
UBO 7 为 volume parameters，当前使用 1232 bytes（4096 bytes 分配大小保持不变）；compute SSBO 4/5/6 可在不同程序中复用，必须各 pass 重绑。
GPU hints 与 `frameLightIndex` 对齐，每条 16 bytes：float intensity、uint flags、两个保留 uint。
原有 80-byte 灯记录不变。

近灯修正的 opaque / MSAA 片元使用 SSBO 0 / 4 / 6 / 7；标准透明与 HDR VFX 使用同一灯表的借用绑定 13，
hints / diagnostics / local volumes 为 4 / 5 / 6。PBR 原有片元灯表 0、cluster 2/3 和顶点 palette 7、morph 8/9 保留。
细化区间恢复当前粗源项时读取完整照明，包括方向灯、同 cluster 的其他局部灯和发射项。标准透明与 HDR VFX 明确重绑现有 cluster headers / indices 于 SSBO 2/3、参数于 UBO 6，与 PBR 同源；binding 14 继续只借用 reactive 脏域，不依赖上个 pass 的残留状态。
共享现有 shadow samplers 7/11/12 和 UBO 5，不新建阴影资源。可见灯变化响应借用原脏域 SSBO 于 binding 14；
PBR fragment 此时有 10 个活跃 SSBO block，cluster 的两组只读 block 共享相同的 2/3 缓冲；实际链接回归分别核对 binding 和 stage 引用。宿主恢复覆盖 indexed bindings 0～15，
13/14 的缓冲 ID、range offset 和 size 均有原生回归。

Sampler/image/UBO/SSBO 分别核对 binding index 上限和各 stage 的活跃资源计数，不能相互抵扣。
M0 查询真实限制证明容量；实际 variant 的编译、反射和 draw 由 M1～M5 证明。

| 前序访问 → 后继访问 | barrier |
| --- | --- |
| cluster SSBO write → lighting SSBO read | SHADER_STORAGE |
| imageStore → sampler/texelFetch | TEXTURE_FETCH |
| imageStore 或上一轮 sampler read → 后续 imageLoad/store | SHADER_IMAGE_ACCESS |
| imageStore → texture readback/copy | TEXTURE_UPDATE，并按实际其他消费者补充 |
| shader SSBO write → buffer readback | BUFFER_UPDATE |

barrier 根据后继访问选择。跨帧 scratch 写入前覆盖上一轮读取；同一 dispatch 不读写同一历史。
依据 [Khronos glMemoryBarrier](https://raw.githubusercontent.com/KhronosGroup/OpenGL-Refpages/main/gl4/glMemoryBarrier.xml)
和 [glBindImageTexture](https://raw.githubusercontent.com/KhronosGroup/OpenGL-Refpages/main/gl4/glBindImageTexture.xml)。

## 合成与 AA 矩阵

不透明/MASK/背景先完成并合成 `S(d)+T(d)*C`，随后透明和 HDR VFX 按自身深度消费同一 prefix/source。
标准 premultiplied ALPHA 输出 `T*Cp+alpha*S`，alpha 不变，ONE / ONE_MINUS_SRC_ALPHA；
straight alpha 先乘 alpha。ADDITIVE 只输出 `T*Cemit`。UI 不查询雾。保持既有透明排序。

| AA | 要求 | 当前阶段状态 |
| --- | --- | --- |
| NONE | 单采样 opaque composite → transparent/VFX | 解析与自身深度专项通过 |
| FXAA | 同 NONE，输出 AA 在 tone map 后 | 合成专项通过 |
| TAA | 同 NONE，reactive max 合并后 TAA，再曝光/Bloom | 三种历史组合与关灯恢复通过 |
| MSAA 2×/4× | 逐 sample color/depth 加雾；透明之后一次 resolve | 原始逐样本读回与宿主恢复通过 |

MSAA 与 TAA 互斥。MSAA composite 不挂正在采样的 depth；透明再借用同 sample count depth。
sample shading 状态必须恢复。自定义 shader/VFX 在构建时明确检查支持或显式 opt-out。

## 所有权、事务与历史

PipelineGeneration 唯一拥有 VolumetricPassBuilder，后者拥有 resources/frame state。
3D 纹理不注册成 graph 的第二所有者；graph 只借用并记录依赖。输出视图携带 generation、执行身份、
grid 和可用状态；禁止跨帧缓存 raw ID。关闭雾不分配卷、不上传参数、不运行 volume pass。

构建/resize 全部候选分配和格式/绑定检查成功后一次发布；失败关闭候选并保留原资源。
历史只过滤 q，积分 alpha 用当前 sigma_t；整 graph 成功才交换和提交相机/revisions。
失败不发布部分写入的历史。双 pipeline/双相机隔离。
灯/雾体变化拒绝旧与新影响域并集；熄灯/删除保留旧域。shadow 内容与相机重拟合分开。
曝光/Bloom 不清除体积历史。最终 TAA reactive 与雾低置信度按 max 合并，分别测三种历史组合。

恢复为 -1 后正常注光恢复。完整消融使用 v2-shared-native-queries 协议，旧 opaque-only 结果单独保留。
连续诊断读回使用显式分配/释放的原生 staging，返回 float 数组后立即释放，异常路径同样释放，不等待 heap GC。

关灯事件将旧有效灯的脏域标为强响应；方向灯或脏域溢出时保守扩展为全卷事件，诊断原因枚举保持原值。

## M6 近灯重建增量

prefix 的物理积分边界保持 Nz+1；辅助八层每帧覆盖后才发布可用身份。三层 mask 存 96 个区间位，
四层 selector 存最多 16 项 frame light index。字节与 index+1 均使用 half 可精确表达的整数；空项为 0，
溢出为负哨兵，索引大于 2046 或超过 16 项时回退完整局部灯表。selector 覆盖实际像素射线和四列重建 footprint。

Point 使用 min(1,lightRange)，Spot 使用 min(2,lightRange) 的细化半径；selector 与原生积分使用同一支持。每个实际细化区间先且仅先扣除存储的过滤后 prefix/source 贡献，恢复当前粗源项；随后扣除待细化灯的当前四列贡献，加入原生射线的 8 点 atan 重要性求积。有效分配阴影的 Spot 使用四个角度区间；仅 Point 在原生射线未进入核心时使用平滑中点。
细化区间中的其他灯和发射项仍按当前粗采样保留，未细化区间继续使用过滤后的 source 历史。这项局部替换防止用当前灯源项扣除历史总源项导致负 S 或残余双计；不增加每灯历史存储。T、当前 extinction 和成功帧历史协议保持原义，额外粗照明查询成本需要代表性能证明。
这是解决近灯积分与横向欠采样的局部重建，单次散射和阴影单位不变；仍使用 4096 / 32768 数值界限与诊断计数。
标准 ALPHA 与 HDR VFX 在自身深度使用同一修正，ADDITIVE 继续只乘 T。

当前保守 4K balanced 自有资源 108,151,568 bytes，单采样总量 182,801,168 / 双代次 365,602,336，
4× 为 381,866,768 bytes。9 个 texture / 5 个 buffer 和全部 14 处分配失败回滚位置保持不变；原预算未调整。
上文 M5 与早期 guide 数字保留为阶段演进记录，当前分配与预算以本段和机器可读配置为准。

Clustered 的双槽诊断计数器复用既有 stats compute 程序在 GPU 清零，取消逐帧 CPU 写入持久映射缓冲。
清零后使用 SSBO barrier，最终读回使用 client-mapped barrier 和本帧 fence；零灯帧也提交 fence。
失败帧撤销候选身份，禁止用旧 fence 证明部分新写入已完成。

近灯修正能采到粗网格遗漏的局部雾体。native reactive 检查灯关掉、移动/内容变化和非累积快速灯的可见射线。
脏域第二个 vec4 的 w=0 表示介质、1 表示关灯、2 表示其他灯响应；coarse temporal 仅将 1 识别为关灯强响应。
灯球域的 extent.x 保留真实灯半径；coarse 使用原 padded radius，native 使用真实半径及一像素重建 footprint，
避免将墙后的闪光因粗网格插值扩张误报到前景。native 仍裁剪于消费者自身深度并要求正透射和散射介质；
只有 emission 而无 scattering 的介质不会因灯变化置位。方向灯/脏域溢出时，UBO 原生全域标记提供保守响应。

参数 UBO 在 offset 704 增加 ivec4：x 为实际介质域数，y 为原生灯全域响应，z/w 保留；offset 720 起保存
16 条 32-byte 实际介质边界（最多 8 个上一成功帧及 8 个当前球/盒）。移动、修改或移除的散射介质保留旧/新域，
不继承 coarse 插值 padding，也不受 coarse 域溢出清空影响；失败重试继续比较上一成功帧。
介质域按一像素 footprint 扩张并查询可见深度。下一稳定帧事件清零；非累积快速灯每个可见帧响应。
Opaque MRT 保留粗网格响应，原生 fullscreen 重放、MSAA、标准透明和 HDR VFX 共用 helper。
9 个纹理、5 个缓冲及 14 个分配失败注入点保持不变；原有 4096-byte UBO 的预留空间承载新增边界。

TAA 投影以 clip.xy -= jitterNdc * clip.w 平移：透视投影改变 m20/m21，正交改变 m30/m31，
偏移不随深度放大。CameraUniforms 与成功帧参数共用 TemporalJitter；不同深度及非对称透视均核对实际 UV 位移。

## 当前源项精度与介质遍历

current-source 使用 RGBA32F 保存即时 q，alpha 仍从 RGBA16F medium 复制；history/prefix 的半精度合同未改。原生细化按 sampler 21 读取四列当前源项缓存。上文 M6 分阶段资源数字保留为历史；当前默认容量下 4K balanced 的保守自有资源为 124,740,368 bytes，单采样含目标为 199,389,968 bytes / 双代次 398,779,936 bytes；4× 稳态为 398,455,568 bytes。实际 128 灯压力配置的 hint/dirty 容量更小，具体值以本轮原始结果为准。原预算未调整。

## 原生零光照求积点

原生近灯 helper 先求原灯光辐射。诊断关闭且三个通道都等于零时直接返回零；此时介质散射不会改变灯光贡献。诊断开启时继续执行原介质函数，保留原有限性、限幅计数。非零/非有限灯光路径仍执行原介质和源项有限性处理。未减少节点、面板、阴影采样或质量档；未新增资源或更改绑定/精度/所有权。见 [优化报告](../performance/v0.25.0-zero-radiance-fast-path.md)。
