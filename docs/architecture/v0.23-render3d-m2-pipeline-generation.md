# v0.23 Render3D M2 PipelineGeneration 合同

`PipelineTopology` 是所有会改变 RenderGraph/pass/resource 结构的稳定 value key，包括 extent、AA/sample、
HDR/Bloom/exposure、LUT/Fog、三类 shadow、directional cascade count/atlas、PBR、HDR VFX 与 embedded。
动态 uniform 或对象 transform 不进入 topology key。

`PipelineGeneration` 独占其 RenderGraph、managed target、framebuffer 与 generation-local pass 状态。
`PipelineFeaturePolicy` 在分配 GL 资源前拒绝非法组合。topology/extent 变化遵循
build candidate → validate → atomic activate → retire old 的顺序；candidate 初始化失败时 active
generation 保持可用，已创建的 candidate 资源逆序关闭。

standalone backbuffer 与 embedded borrowed target 共享同一 generation 协议；borrowed attachment 只
引用、不释放。fixed shadow atlas 不随窗口 resize 重建，window/relative target 由新 generation
事务式替换。`close()` 可重复，且不会让旧 callback 在 owner 关闭后继续运行。

证明入口：`PipelineTopologyTest`、`RenderPipelineTest`、`RenderPipelineGlTest`、
`EmbeddedPresentationGlTest`、resize/failure integration 和 GL resource lifecycle gate。
