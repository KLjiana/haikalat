# v0.23 Render3D M6 阴影与 CSM 合同

默认方向光阴影保持单级。`DirectionalCascadeSettings` 可选 2～4 级 fixed atlas，并限定正 atlas
尺寸、practical split lambda 与 blend range。cascade 使用相机 near/far 分段、world-texel snapping、
固定 tile viewport 和相邻 split blend；窗口 resize 不重建 fixed atlas。

PBR shader 把 cascade-local UV 映射到当前 atlas tile。3x3 PCF 的每个 tap clamp 到 tile 的半
texel内边界，防止内部边缘读取相邻 cascade。MASK caster 走 alpha-cutoff shadow variant；透明
ALPHA/ADDITIVE 不进入 opaque caster queue。

camera/light/caster revision 只刷新必要矩阵或 caster queue。首版 cascade caster 采用保守全集，
不按 cascade 建空间索引；M7 数据未达到引入 CPU spatial index 的门槛。

证明入口：`DirectionalCascadeSettingsTest`、`ScenePipelineTest`、`RenderPipelineGlTest`、
`SceneVisibilityGlTest` 与 `runRender3dV023Integration`。
