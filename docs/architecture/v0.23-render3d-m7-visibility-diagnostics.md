# v0.23 Render3D M7 可见性与诊断合同

`SceneFrameBuilder.VisibilityStatistics` 和 `Render3dDiagnostics` 提供有界计数：scanned/visible/culled、
bounds update/cache、四类 forward queue、shadow candidates/visible、透明排序、revision/invalidation、
generation、cascade、depth resolve、cache hit/miss 与 failure stage。snapshot 不保留逐对象列表、矩阵、
renderer 或 native GL id。

通用 diagnostics schema-v1 增加 `maskedDraws`。计数必须满足
`opaqueDraws + maskedDraws + additiveDraws + alphaDraws == forwardVisible`；visibility 或 frame
build 失败时导出 unavailable，不复用上一成功帧。详细字符串只在显式 capture 时生成。

100/1,000/10,000 对象和 10,000 全静态代表场景表明 O(N) culling + queue scan 未持续超过 2 ms，
静态 queue cache 将 queue build 压到 0.08 ms 以下，因此 v0.23 不实现 CPU BVH/AABB tree。数据见
[`v0.23 Render3D 可见性与空间索引结论`](../performance/v0.23-render3d-visibility-index-decision-2026-08-18.md)。

证明入口：`FrameDiagnosticsTest`、`ScenePipelineTest`、`RenderPipelineTest`、
`runSceneScalabilityBenchmarks`、`runSceneSubmissionStaticGate` 与 `runRender3dV023Integration`。
