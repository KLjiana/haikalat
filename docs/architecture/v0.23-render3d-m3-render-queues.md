# v0.23 Render3D M3 Render Queue 合同

普通 3D forward draw 被内部 `RenderQueueClass` 明确分类为 OPAQUE、MASKED、TRANSPARENT_ALPHA、
TRANSPARENT_ADDITIVE。公共材质 API 保持原有 `BlendMode`；MASKED 由 PBR alpha-mode/cutoff 判定。

- OPAQUE/MASKED：depth test/write 开、blend 关，按 shader/material/mesh 与 insertion index 稳定排序。
- ALPHA：depth test 开、write 关，按 camera-space depth back-to-front，insertion index 稳定打破平局。
- ADDITIVE：depth test 开、write 关并保持提交顺序。

opaque-only 帧不执行透明排序。camera/transform/material revision 只在会改变分类或深度 key 时重建
相应 queue。统计分别记录四类 draw、透明排序耗时与稳定深度平局，不暴露内部 renderer 引用。

对象级排序不能解决单 mesh 内部自相交；内容应拆分为独立对象。本版本不提供 OIT、折射或透明
阴影。状态与内容制作建议见
[`Render3D 材质、透明与阴影指南`](../guides/render3d-materials-and-shadows.md)。

证明入口：`RenderQueueClassTest`、`RenderQueueSorterTest`、`ScenePipelineTest`、
`SceneVisibilityGlTest` 和 `runRender3dV023Integration`。
