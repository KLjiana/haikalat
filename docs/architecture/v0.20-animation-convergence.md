# v0.20 动画运行时收敛

状态：M4 进行中。

本轮先固化不改变 public API 的运行时部件：

- `AnimationSignalQueue`：有界 signal、单调序号和 HIGH 优先级淘汰策略；用显式扫描替代
  每次溢出时创建 stream pipeline。
- `AnimationCursor`：复用 clip local time/loop 结果，供状态机的 source/target 两条游标
  共用，不再使用 controller 内部匿名结果类型。
- `UiAnimationRunList`：UI owner-thread active run 的容量复用和 index-based 删除，更新帧
  不创建 iterator。

```text
AnimationController
├─ AnimationCursor ×2
└─ AnimationSignalQueue

UiAnimationSystem / UiTimeline
└─ UiAnimationRunList
```

### 保持的语义

- `pendingSignals()`、`drainSignals()` 顺序和不可变返回值不变；
- signal capacity 满时，HIGH 可以淘汰最早 NORMAL；没有可淘汰项时 HIGH 也会计入 dropped；
- UI active run 仍保持插入顺序，cancel、finish、close 都是幂等的；
- reduced-motion、transition interruption、queued transition 和 marker 顺序没有改动。

### 后续收敛

动画 controller、layer stack 和 UI timeline 仍各自拥有领域状态；在没有跨包 public
扩张的前提下，后续只抽取共享的时间单调性/暂停策略。任何新的 public 类型必须先更新
API allowlist 和迁移记录。
